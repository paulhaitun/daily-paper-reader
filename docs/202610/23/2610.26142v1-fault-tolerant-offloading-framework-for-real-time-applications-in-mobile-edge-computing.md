## 摘要
本文研究了回传网络赋能的移动边缘计算（MEC）系统中一个截止时间约束的任务卸载与资源分配问题（DOAP），该系统同时受带宽和计算资源约束。目标是在所有任务上最大化总推理精度提升。我们将该问题（记为 $\mathbf{P}$）建模为整数线性规划（ILP）问题，并通过从最大权三维匹配问题归约证明其是 NP-hard 的。为解决 $\mathbf{P}$，我们提出了 $\mathtt{FastSA}$，一种基于局部比值技术的线性时间 $\frac{1}{10}$-近似算法。据我们所知，$\mathtt{FastSA}$ 为回传网络赋能的 DOAP 提供了首个常数因子性能保证。此外，我们引入了一个故障检测与恢复框架，使 MEC 在回传链路和边缘服务器故障下能够鲁棒运行。使用经剖析的图像分类工作负载和真实出租车轨迹进行的实验表明，在无故障条件下，$\mathtt{FastSA}$ 相比基准算法平均实现 $25.6\%$ 的精度提升，同时保持最低运行时间。在注入故障的场景下，我们的框架将性能退化平均降低 $12.8\%$，证明了其在故障处理方面的有效性。

## Abstract
This paper studies a Deadline-constrained task Offloading and resource Allocation Problem (DOAP) in a backhaul-network-enabled Mobile Edge Computing (MEC) system with both bandwidth and computational resource constraints. The goal is to maximize the total inference accuracy improvement across all tasks. We formulate this problem, denoted as $\mathbf{P}$, as an Integer Linear Programming (ILP) problem and show it is NP-hard via a reduction from the maximum-weight three-dimensional matching problem. To address $\mathbf{P}$, we develop $\mathtt{FastSA}$, a linear-time $\frac{1}{10}$-approximation algorithm based on the local-ratio technique. To the best of our knowledge, $\mathtt{FastSA}$ provides the first constant-factor performance guarantee for backhaul-network-enabled DOAPs. In addition, we introduce a fault detection and recovery framework that enables robust MEC operation under backhaul link and edge server failures. Experiments using profiled image classification workloads and real-world taxi traces show that $\mathtt{FastSA}$ achieves an average accuracy improvement of $25.6\%$ over benchmark algorithms under fault-free conditions while maintaining the lowest runtime. Under fault-injected scenarios, our framework reduces performance degradation by an average of $12.8\%$, demonstrating its effectiveness in fault handling.

Abstract 

We study the classical single-machine scheduling problem of minimizing the sum of com-pletion times of jobs in a non-clairvoyant setting, where the processing time of each job remains unknown until its completion. This is a hard problem for which no constant com-petitive algorithm is possible. Inspired by robust optimization and learning-augmented algorithms, we introduce a novel robustness framework that leverages structural informa-tion provided by a classification model to overcome this limitation. Specifically, we assume that jobs are partitioned into classes and we have access to the confusion matrix of the classifier, whose entry (k, ℓ ) indicates the number of jobs predicted to belong to class k but that actually belong to class ℓ. In this manner, we are able to characterize uncertainty as a set of permutations within each predicted class, rather than as a collection of discrete numerical scenarios, avoiding the computational difficulty of classical robust metrics, such as Min-Max and Min-Max Regret. In addition to these worst-case metrics, we also consider the expected objective over all scenarios. We first propose an optimal non-adaptive strat-egy that is oblivious with respect to all three robust criteria. We then investigate adaptive and randomized algorithms, showing that they can outperform the optimal non-adaptive strategy when the matrix exhibits particular structural properties. 

Keywords: Scheduling, Robustness, Non-Clairvoyant, Classification, Confusion Matrix 

1arXiv:2610.01343v1 [cs.LG] 1 Oct 2026 1 Introduction 

Scheduling problems, where one seeks to schedule a set of jobs on a set of resources in order to optimize a given objective function, are known to be particularly sensitive to uncertainty. The various applications of scheduling are often subject to different sources of variability, making the perfect knowledge of input parameters extremely challenging. Typically, it is common that the exact processing time of a task cannot be known with full precision before its completion. As a consequence, algorithms leveraging this information are more difficult to use in practice. Several approaches have been proposed to deal with this uncertainty, among which online/non-clairvoyant optimization [1, 2, 3], stochastic optimization [4, 5, 6, 7, 8], robust optimization [9, 10, 11], or learning-augmented algorithms [12, 13, 14, 15, 16]. In the latter approach, one has access to an oracle that predicts the values of the unknown parameters. These predictions are subject to errors, typically summarized by a single scalar 

η, which represents the “overall quality” of the oracle on a given instance. The goal is then to design an algorithm with a formal guarantee (e.g., a competitive ratio) that depends on η. The oracle is often seen as a black box, in the sense that no assumptions are made about its behavior. However, in many practical applications, predictions may exhibit specific patterns that could be exploited by optimization algorithms. For example, an expert may specialize in recognizing a particular class of items, providing near-perfect predictions for the corresponding parameters while producing less accurate predictions for other types of items. Similarly, an oracle may be guaranteed never to overestimate (or underestimate) parameters values. Unfortunately, the single-scalar error representation used in the classical learning-augmented framework is generally too coarse to capture such structured prediction patterns in optimization problems. In this paper, we introduce a novel robustness analysis framework based on classification models , which assign objects to discrete categories. If we note X ⊆ Rn the features describing the objects to classify and Y = {c1, c 2, . . . , c K } a finite set of K class labels (representing the possible categories for our objects), a classifier is a function C : X → Y mapping each vector 

x ∈ X to a class label y ∈ Y . Such classifiers may be obtained through (un)supervised machine learning methods (e.g., Support Vector Machines, Decision Trees, Neural Networks, k-Nearest Neighbors, etc.), probabilistic data structures (e.g., Bloom Filters, Count-Min Sketch, etc.), or represent a human expert predicting the category of an object from simple observation. What makes classifiers interesting in our context is that they are typically evaluated through their 

confusion matrix , which is obtained by running the model on the testing set. For a classifier 

C on K classes, a confusion matrix is a K × K matrix EC where each entry eij indicates the number of items of class cj that C predicted as ci. In other words, the rows of EC correspond to the predicted classes, while the columns correspond to the true classes of the items 1. Fig. 1 illustrates the confusion matrix of a binary classifier. Interestingly, it is possible to infer the performance of a classifier on unlabeled data [17, 18], and in particular to estimate its confusion matrix. We therefore propose to leverage such confusion matrices in scheduling problems. Suppose we are given a set of jobs partitioned into 

K classes, where all jobs within the same class have identical processing times. The objective is to schedule these jobs non-preemptively on a single machine so as to minimize the sum of completion times. In the clairvoyant setting, it is well-known that the Shortest Processing Time (SPT) policy is optimal [19]. In the non-clairvoyant setting, the class of each job is unknown, and since preemption is not allowed, the best strategy is simply to execute the jobs in an arbitrary order [20]. The worst case outcome is then a Longest Processing Time (LPT) schedule. Now suppose we have access to a classifier C that predicts the class of each job, and that its

Knowledge model. We consider that we do not know the class of a job in advance: this information is revealed only at full completion of the job. However, we have access to a classifier 

C that is able to predict the class of a job before executing it. Each request to the classifier is free, and it is deterministic in the sense that it always gives the same answer for a given job. The classifier is not perfect and may respond with the wrong class. Although we do not have any information for each individual job, we consider that, for any instance of the problem, we know in advance the confusion matrix EC of the classifier C, which consists in a K × K integer matrix where each entry ekℓ on row k and column ℓ gives the number of jobs that the classifier believes to be in class k whereas they are in reality in class ℓ. For each k, we note Rk the set of jobs that the classifier believes to be in class k; the number of jobs in Rk is equal to the sum of entries in row k of the confusion matrix EC . We also have ekℓ = |R k ∩ J ℓ| for all k, ℓ . We assume that we systematically begin by executing the classifier on each job (as requesting the classifier is free) in order to build the sets Rk. Again, we do not know the class of each individual job, but we do know the distribution of each set Rk thanks to the a priori knowledge of the confusion matrix. This knowledge may seem to be a strong assumption; however, recent approaches in the field of Machine Learning have demonstrated the possibility to estimate the performance of a trained classifier on unlabelled data, even in the case of distributional shift [17, 18]. In particular, it is possible to provide an estimation of confusion matrices. In this paper, we propose to evaluate the 3gain that a perfect “unsupervised performance estimation” technique would permit on scheduling algorithms, and we leave the analysis of inaccurate confusion matrices for future work. Interestingly, this knowledge model can be seen as a generalization of the classical clairvoyant and non-clairvoyant models. We say that a classifier C is clairvoyant if and only if each row of its confusion matrix EC has at most one nonzero entry. Indeed, since all jobs within a given class share the same processing time, knowing that all jobs in Rk belong to a single true class ℓ

is sufficient to determine the processing time of each job prior to its execution. On the opposite side, any classifier C whose confusion matrix EC has only one row with nonzero entries does not help at all, as it will predict that all jobs belong to the same class. Hence, we say that such a classifier is non-clairvoyant . All the other classifiers are in between of these two extremes. Fig. 2 gives several examples of matrices. 2 0 0 0 4 0 0 0 3

Uncertainty model. While the classifier allows to partition J into K subsets R1, R2, . . . , RK ,the permutation of the jobs in each Rk remains completely unknown. In other words, the uncertainty of the problem is on the ordering of each set Rk, and we do not make any assumption about it. We argue that, from a worst-case point of view, it seems completely unfair to compare to the optimal strategy of the clairvoyant case, which consists in scheduling jobs in non-decreasing order of processing times (the SPT policy): our decisions can always be subject to an adversary giving us large jobs first, whereas the optimal clairvoyant algorithm is never constrained by this malicious ordering. Hence, in the following of this paper, we compare to an optimal solution that is also subject to the fixed ordering of jobs in each set Rk. Our objective is to ensure robustness to the uncertain ordering of these sets. In these settings, the sets Rk may be seen as queues from which an algorithm must pull jobs: at each decision step, the job that is in front of the chosen queue is immediately executed. σk is denoted by σk[j], and for any 1 ≤ j1 ≤ j2 ≤ |R k|, we note σk[j1 : j2] the subchain of jobs 

σk[j1], σ k[j1 + 1] , . . . , σ k[j2]. Let S denote the set of all possible scenarios. We define a sequence r to be an ordered list r = ( k1, k 2, . . . , k n) of queues Rk from which pulling and executing jobs. Note that a given queue may be chosen several times in a sequence, unless it contains a single job or is empty. For example, the sequence (1 , 1, 2, 2, 2, 1, 1, 2, 2)

Note that an optimal strategy is defined by a sequence optimizing some criterion, respecting however the actual scenario as for any sequencing algorithm. Contributions and organization. The paper is organized as follows. Section 3 is devoted to related work. In Section 4, we give a very simple algorithm, called Min-Cost , and we prove that it is the best possible non-adaptive algorithm for the three considered robustness criteria (Theorems 1-4). Interestingly, we demonstrate that adaptive or randomized algorithms cannot do better for the Min-Max problem (Lemma 1). We also show that, for binary classifiers, no deterministic adaptive algorithm can perform better than Min-Cost for the Min-Max Regret problem (Lemma 3). However, we prove in Section 5 that for Min-Max Regret and binary classifiers, a simple randomized algorithm outperforms Min-Cost for specific structures in the confusion matrix (Theorem 5). Moreover, for Min-Expectation , we give an optimal adaptive dynamic program, which is polynomial when the number of classes K and the entries of the confusion matrix are bounded above by a constant (Theorem 6). Finally, by giving a specific family of classifiers, we show that the relative gap between Min-Cost (i.e., optimal non-adaptive) and this optimal adaptive algorithm is asymptotically bigger than 4/3 (Theorem 7). 

# 3 Related Work 

In the offline case where all jobs are fully known in advance, 1|| P Cj can be solved in polynomial time by applying the Shortest Processing Time (SPT) policy [19]. In the online case where the jobs are revealed according to an adversarial order (online over list), the LPT order corresponds to a worst-case scenario for any no-idling algorithm. Moreover, in the case where the instance is composed by only two classes of jobs with processing times λs, λL, with λs < λ L, considering a random ordering leads to an expected competitive ratio of O

pλL/λ s



[22]. In the online case where the jobs arrive over time, Hoogeveen and Vestjens [23] showed that no deterministic algorithm can have a competitive ratio better than 2, and they proposed the delayed-SPT algorithm which attains this ratio. In the non-clairvoyant model where the processing time of each job becomes known only at its completion, no (randomized) algorithm can achieve a constant competitive ratio [20]. In order to deal with non-clairvoyant data, several works consider the learning-augmented setting, where non-necessarily accurate predictions are provided. Kumar et al. [16] were the first to study the sum of completion times objective when preemption of jobs is permitted and predictions on the processing times are available, and they proposed an algorithm being robust (bounded perfor-mance for any quality of predictions) and consistent (good performance on accurate predictions). Since then, a series of papers has appeared, mainly handling the preemptive case [24, 25, 15, 26]. Closer to our setting but still in the preemptive case, Lindermayr and Megow [27] consider predictions on jobs permutations implying a priority order among the jobs. Our framework differs in that the uncertainty is captured by a full confusion matrix rather than a single priority order. Another way to circumvent the non-clairvoyant model is to treat processing times as random variables whose distributions (or at least their first moments) are known in advance. Then, the objective is to minimize the expected sum of completion times E [P Cj ]. On a single machine, the Shortest Expected Processing Time (SEPT) policy, which executes jobs in non-decreasing 6order of E[pj ], is optimal, and this is also the case on parallel machines if processing times follow an exponential distribution [19]. For general distributions, the approximation ratio of SEPT is Ω( n1/4) [4], but is almost linear in the squared coefficient of variation of processing times, which indicates that SEPT performs well if there is not much variability among jobs [6]. The dependence on this squared coefficient of variation is also characteristic of several proposed LP-based strategies [6, 8]. Other works consider the online stochastic model, in which the processing times are random variables and jobs stay unknown before their arrival in the system [5, 7]. The problem 1|| P Cj has also been studied in the classical robust optimization setting [28]. In order to represent the uncertain information, in the discrete uncertainty model, a finite set of different realization scenarios for the processing times of the jobs is available, while in the 

interval uncertainty model, only a lower and an upper bound of them are provided. In both cases, commonly used metrics include Min-Max, Min-Max Regret and Min-Max Relative Regret, similarly to the metrics used in our work. All of them seek to guarantee a robust solution, that is a solution with good performance even in the worst-case realization of the input parameters. Yang and Yu [29] have proved that 1|| P Cj under discrete uncertainty is NP-hard for all the three metrics. For the Min-Max criterion, Mastrolilli et al. [10] have shown that it is NP-hard to approximate it within a factor less than 6/5, and they give a 2-approximation algorithm for the weighted case with precedence constraints. Moreover, they propose a dynamic programming algorithm running in polynomial time if the number of scenarios and the values of processing times are bounded by a constant. When considering interval uncertainty, both the Min-Max Regret [30] and the Min-Max Relative Regret [31] are known to be NP-hard. Note that our work introduces a new model to represent uncertain data, which is of a completely different nature with respect to the known ones. Kahan [32] proposed a model in which an oracle is queried to reveal the real values of some uncertain data at a given cost. Adapting this idea in scheduling problems, Dürr et al. [33] consider the query to be an additional job to be executed on the same machines as the other jobs. Querying a job is decided by the scheduler and may lead to a reduction of its processing time. Without a query, the processing time of a job is equal to a given upper bound. In this context, they propose deterministic and randomized results in different settings of 1|| P Cj .Moreover, adaptive and non-adaptive algorithms in this model are proposed in [34] for instances consisting of two types of jobs. Finally, Bampis et al. [35] proposed a probabilistic prediction model for permutation problems, which tries to limit the number of predictions used to optimize an objective. The authors showed that their model also applies to 1|| P Cj for which any no-idling solution corresponds to a permutation of jobs.

14 6 Conclusions and Perspectives 

We proposed a novel robustness model based on classification and confusion matrices, applied on the basic scheduling problem 1|| P Cj . This allowed us to refine the analysis in non-clairvoyant setting: instead of being forced to rely on a random ordering of the jobs, we were able to leverage additional information provided by the classifier to derive new robustness guarantees, both in worst ( Min-Max Regret ) and average ( Min-Expectation ) cases. We think this model might constitute a new approach to analyze combinatorial optimization problems subject to uncertainty. One logical next step consists in designing algorithms giving optimal results when the clas-sifier provides perfect predictions (e.g., diagonal matrices), while being robust no matter the confusion matrix, in the same spirit as learning-augmented algorithms. In particular, we plan to study how the structure of the matrix impacts robustness. Another direction could be the generalization of the model to multi-label classification, where an object is categorized according to several attributes. For example, we could analyze the 1|| P wj Cj problem, where each job is assigned one class for its weight, and a second class for its processing time. 15 References

Definition 2 ( Half-and-Check (HC ) policy). Let L be a list of jobs (initially empty), and let MK,x be an instance as described in Definition 1. For each queue R1, R2, . . . , RK do: 1.

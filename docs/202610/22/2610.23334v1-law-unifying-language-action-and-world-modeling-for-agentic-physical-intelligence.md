## 摘要
世界-动作模型能够联合预测动作与未来世界状态，但长时程操作还进一步需要语言推理来规划子任务目标、评估执行进度并指导动作选择。我们提出 LAW，一个闭环 VLM-WAM 框架，通过语义子任务进度统一语言推理、动作生成与世界建模。在 LAW 智能体中，混合专家视觉-语言模型规划剩余子任务，估计世界-动作模型所提动作的价值并对其进行融合，同时异步评估执行状态，以支持持续执行和子任务切换。在世界-动作模型中，Mixture-of-Transformer Experts 集成模态特定计算与共享计算，用于联合视频-动作建模。双流分层视觉记忆为两个模型维护时序上下文，而子任务局部价值学习使动作评估与语义目标对齐，并保留来自失败轨迹中成功前缀的监督信号。LAW 在 50 项 RoboTwin 任务上取得 94.21% 的平均成功率。将 WAM 主干替换为 OpenWAM-α 后，平均成功率进一步提升至 95.56%，在 RoboTwin 上建立了新的开源最优结果。尽管我们的 VLM 仅有 2B 参数，其性能仍优于使用 Embodied-R1.5 和 GPT-5.5 High 的变体。在三项长时程真实机器人任务上，LAW 取得 65% 的平均成功率，而 π_{0.5} 为 28.33%，Fast-WAM 为 25%。

## Abstract
World-action models jointly predict actions and future world states, but long-horizon manipulation further requires language reasoning to plan subtask objectives, assess execution progress, and guide action selection. We present LAW, a closed-loop VLM--WAM framework that unifies language reasoning, action generation, and world modeling through semantic subtask progress. Within the LAW agent, a hybrid-expert vision-language model plans the remaining subtasks, estimates the values of and fuses actions proposed by a world-action model, and asynchronously assesses execution status to support continued execution and subtask transitions. Within the world-action model, Mixture-of-Transformer Experts integrates modality-specific and shared computation for joint video--action modeling. Dual-stream hierarchical visual memory maintains temporal context for both models, while subtask-local value learning aligns action evaluation with semantic objectives and preserves supervision from successful prefixes of failed trajectories. LAW achieves 94.21% average success across 50 RoboTwin tasks. Replacing the WAM backbone with OpenWAM-$alpha$ further raises the average success rate to 95.56%, establishing a new open-source state of the art on RoboTwin. Despite having only 2B parameters, our VLM also outperforms variants using Embodied-R1.5 and GPT-5.5 High. On three long-horizon real-robot tasks, LAW achieves 65% average success, compared with 28.33% for $pi_{0.5}$ and 25% for Fast-WAM.

## 一、核心问题与研究动机

- **背景定位**：视觉-语言-动作（VLA）策略把语义表征接到控制上；世界-动作模型（WAM）学习“动作条件下的场景演化 + 可执行行为”。二者各自都显著提升了动作生成质量，但在**长时程部署**中暴露出一个系统性问题——**推理与控制必须随任务演进而保持对齐**。
- **核心痛点**：长时程操作本质上是**语义子任务的序列**，而非更长的电机指令序列。机器人必须判断“抓取是否真的成功”、识别“任务已进入新阶段”、并依据当前目标在多个物理可行的动作中做选择；任一步判断出错都会随时间累积放大。
- **既有方案的三处接口缺失**：
  - 只在开头生成一次的语言计划**无法判断中间步骤是否完成**；
  - 仅以当前观测为条件的动作生成器**不知道哪些视觉变化对整体目标重要**；
  - 把 planner 简单放在 policy 前面，未定义“执行进度如何回写计划”“候选动作如何按当前语义目标评判”“相关历史如何保留而不压垮模型”。
- **核心主张（Insight）**：应以**语义子任务进度（semantic subtask progress）**作为语言推理与世界-动作建模之间的**时间接口**。子任务不仅是指令分解，它还定义了：何时推进计划、候选动作应优化哪个结果、哪些观测应在记忆中被保持显著。
- **推论**：不同计算应以**不同频率**运行——状态评估持续异步进行、候选动作评估在每个动作块生成时进行、规划在语义尺度上进行；难点在于**协调**，而非每步调用更大的推理器。

## 二、方法论

### 1. 总体框架：LAW 智能体
- 将长时程控制分解为**进度感知的语义控制环**（VLM）与**短时程动作环**（WAM），以当前子任务 $c_t$ 为连接点。
- 每步输入 $o_t=(I_t,p_t)$：多视角 RGB + 本体状态；VLM 用 RGB + 视觉记忆 $M^V_t$，WAM 用 RGB + EEF 状态 + 视觉记忆 $M^W_t$。
- **闭环流程**（对应 Algorithm 1）：
  1. Planner 预测剩余子任务序列 $S_t=(s_{t,1},\dots)$，取 $c_t=s_{t,1}$；
  2. WAM 以 $c_t$、观测、记忆为条件采样 $N=32$ 个候选动作块（horizon $H=32$，独立噪声初始化保证多样性）；
  3. Value expert 打分，取 top-$K=8$ 温度加权融合为 $\hat A_t$，机器人执行其前缀；
  4. State expert **异步**估计当前子任务是否完成 $\hat d_t$，0.5 二值化；
  5. $\hat d_t\ge0.5$ → ADVANCE：记录子任务边界观测、子任务实例号 $u_t{+}1$、重新规划；否则 CONTINUE，保持 $c_t,u_t$ 与计划不变。
- **异步一致性机制**：每条完成预测携带时间戳与子任务实例标识 $u_t$，仅当标识匹配且时间戳新于上次消费结果时有效，被更新预测取代的结果丢弃；不排队历史帧、不阻塞动作执行。

### 2. 混合专家 VLM（Hybrid-Expert VLM）
- 以 **Qwen3-VL-2B-Instruct** 为共享**冻结**主干，用三个 LoRA 适配器 + 专用头实现三种控制功能，按**控制功能（而非 token 级路由）**选择专家，避免功能间干扰与多份全模型开销：
  - **Planner**（r=64）：自回归生成剩余子任务序列，损失为子任务序列的负对数似然 $L_{plan}$；仅在 episode 初始化与语义决策事件调用。
  - **State expert**（r=64）：子任务完成监督 + **辅助失败预测**双查询 token，$L_{state}=\lambda_d \mathrm{BCE}(\hat d,d)+\lambda_f \mathrm{BCE}(\hat f,f)$；辅助失败头迫使共享表征区分“未完成”与“已完成”。
  - **Value expert**（r=128，从 state 适配器初始化）：将候选动作块编码为 token 与上下文联合输入，经可学习 query 聚合到 **101-bin 类别价值头**，$Q_\theta=\sum_b z_b p_\theta(b\mid x_t,A_t)$；只训练该适配器、动作编码器、query 与价值头。
- 三专家总计新增约 **100M 参数**。

### 3. MoTE：混合 Transformer 专家（WAM 侧）
- 原始 MoT 只在混合注意力中交换信息，后续变换仍模态私有，**共享建模不足**。
- MoTE 在**混合注意力表示之后**加一层稀疏 MoE 残差：
  - 路由：$w=\mathrm{TopKSoftmax}(W_r \mathrm{LN}(H))$，路由权重 $W_r$ **按模态区分**；
  - 更新：$\tilde H = H + \alpha \sum_{e} w_e E_e(\mathrm{LN}(H))$。
- 默认配置：每模态 2 个私有专家 + 1 个两模态**共享专家**，top-1 路由（同一 token 不会同时用私有与共享），$\alpha=0.1$。
- 训练目标：$L_{WAM}=\lambda_v L_{video}+\lambda_a L_{action}+\lambda_{bal}L_{balance}+\lambda_z L_z$，$\lambda_v=\lambda_a=1$，$\lambda_{bal}=\lambda_z=10^{-4}$。

### 4. 双流分层视觉记忆
- VLM 与 WAM 各自维护独立记忆流（token 空间不同：VLM 视觉 token vs. WAM VAE token），共享同一批时间戳：
  - **近期窗口**：过去 5 帧、步长 4（$o_{t-20},\dots,o_{t-4}$），全分辨率；
  - **子任务边界帧**：控制环切换处记录的观测，全分辨率，仅存一次；
  - **长期历史**：当前子任务内每 4 步采样、已完成子任务内每 16 步采样，经**空间平均池化压缩为单 token**；
  - 所有选中时间戳共享相位 $t \bmod 4$。
- 记忆拼接形式：$M^X_t=[\{\bar x^X_{c_i}\};\{x^X_{\beta_i}\};\{x^X_{t-4j}\}]$，即“压缩长期 + 全分辨率边界 + 全分辨率近期”。

### 5. 子任务局部价值学习（Subtask-Local Value Learning）
- **动机**：episode 级回报会丢弃“已完成若干子任务后才失败”轨迹中的正监督。
- **奖励设计**：每个成功完成子任务的**终止动作**给 reward 1，其余为 0；最终失败子任务无正奖励，未观测子任务排除。
- **TD 目标**：$y_t=\sum_{i=0}^{h_t-1}\gamma^i r_{t+i}+b_t\gamma^{h_t}\bar Q_{\bar\theta}(x_{t+h_t},A^{data}_{t+h_t})$；动作块在**首个语义边界处截断**，$h_t$ 只计有效动作，越界动作从目标中 mask；仅当后继块在同一子任务内且不含终止动作时 $b_t=1$。
- **训练**：值裁剪后用归一化高斯核构造软标签（101 bins over $[-0.01,1.01]$，$\gamma=0.99$，HL-Gauss 宽度 $\sigma=0.0075$，EMA 率 $\tau=0.005$），类别交叉熵损失。
- **推理期融合**：top-K 候选取 $w_n\propto\exp(Q_\theta(\cdot)/T)$，位置与夹爪指令线性加权平均，四元数用**加权 Markley 均值**（$M=\sum w_n q_n q_n^\top$ 的最大特征向量），对符号翻转 $q_n\mapsto -q_n$ 不变。

### 6. 训练流程
- **两阶段**：① 依次训练 planner、state 专家（语义子任务标注），WAM 独立以视频-动作对训练；② 冻结上述组件，用成功示范 + 标注失败轨迹按子任务局部目标训练 value 专家。评测时全部冻结。
- **失败数据构造**：回放成功示范并在特定操作阶段注入任务相关扰动（漏抓、提前释放、错放、漏接触、对位不准等），每任务 1–3 种失败模式，目标每“任务-失败类型”35 条干净 + 100 条域随机化轨迹，再人工/规则过滤语义无效、视觉模糊、低质量样本；失败轨迹占 value 训练样本 **25%**。
- **WAM

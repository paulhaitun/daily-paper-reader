## 摘要
近期的世界动作模型为机器人操作提供视觉预见与未来预测，但缺乏用于组合式技能复用的显式机制。智能体机器人将基于代码的规划与推理同可复用技能相结合，但往往缺乏在物理动力学中的预测性基础。我们提出 AW-0，一个智能体化世界动作模型框架，将基于代码的规划与视频和动作联合预测相结合。我们在统一的混合 Transformer 架构中，将代码、未来视频和机器人动作作为三个耦合的生成流进行联合建模。在该架构中，代码专家生成参数化技能例程与控制逻辑，而视频专家和动作专家生成未来视觉状态与底层运动指令。代码承担两个互补角色：它在世界模型中组织多步预测与控制，并将技能表示为可供后续智能体执行复用的程序。我们进一步引入自动化数据整理流程，用对齐的程序标注机器人和人类视频轨迹，并将重复出现的例程整合为可复用技能库。在 RoboTwin 2.0 和真实双臂操作任务上的评估表明，相较于 VLA 和 WAM 基线，任务性能有所提升，同时在语言遵循、语义推理和鲁棒性方面也取得增益，表明智能体代码能够在 WAM 中连接规划、预测与执行。

## Abstract
Recent world action models provide visual foresight and future prediction for robot manipulation, but lack explicit mechanisms for compositional skill reuse. Agentic robotics combines code-based planning and reasoning with reusable skills, but often lacks predictive grounding in physical dynamics. We introduce AW-0, an agentic world action model framework that integrates code-based planning with joint video and action prediction. We jointly model code, future video, and robot actions as three coupled generative streams within a unified mixture-of-transformers architecture. Within this architecture a code expert generates parameterized skill routines and control logic while video and action experts generate future visual states and low-level motor commands. Code serves two complementary roles: it structures multi-step prediction and control within the world model and represents skills as reusable programs for subsequent agentic execution. We further introduce an automated curation pipeline that labels robot and human video trajectories with aligned programs and consolidates recurring routines into reusable skill libraries. Evaluations on RoboTwin 2.0 and physical bimanual manipulation tasks show improved task performance over VLA and WAM baselines, alongside gains in language following, semantic reasoning and robustness, demonstrating that agentic code enables connection between planning, prediction and execution within WAMs.

## 1. 核心问题与整体含义（研究动机与背景）

- **背景两条技术脉络**：
  - **世界动作模型（WAM）**：将未来视频预测与动作生成耦合，为操作提供物理动力学层面的"预见"，但预测出的视频与动作块本身**不指定长时程任务应如何分解**——调用哪些可复用技能、如何参数化、如何跨子任务组合。
  - **智能体机器人（Agentic Robotics）**：以代码/程序作为策略表示，显式选择技能与工具、绑定当前场景、跟踪进度并重规划，具备组合性与可复用性，但**缺乏对真实物理动力学的预测性基础**，且执行受限于所调用的底层原语。
- **核心矛盾**：WAM 有"物理直觉"但缺"结构化规划"；智能体有"认知结构"但缺"预测落地"。通用地世界建模/动作预测代价高，难以界定需建模的自由度上限。
- **论文主张**：将二者融合——把代码作为**结构化规划接口**嵌入世界动作模型内部，让代码同时指导多步预测与执行，并可作为可复用程序在智能体框架中复用。据此提出 **AW-0**（Agentic World Action Model）。
- **意义**：为 WAM 补上"组合式技能复用"的显式机制，为智能体机器人补上"物理动力学预测"的落地基础，形成规划—预测—执行闭环的范式基础。

## 2. 方法论

### 2.1 核心思想
- 将**代码 C、未来视频 Z、动作 A** 视为三条耦合生成流，在统一的**混合 Transformer（Mixture-of-Transformers, MoT）** 架构中**联合去噪**：
  $$p_\theta(C_0, Z_0, A_0 \mid C_t),\quad C_t=\{O_t, L, S_t, M_t\}$$
  条件为多视角观测、语言指令、机器人状态与前序程序切片记忆。
- 每个去噪步统一预测：代码 token logits $\ell^c_\theta$、视频速度 $v^v_\theta$、动作速度 $v^a_\theta$：
  $$(\ell^c_\theta, v^v_\theta, v^a_\theta)=F_\theta(\tilde C_r, Z_{\sigma_v}, A_{\sigma_a}, \sigma_v, \sigma_a; C_t)$$
- **代码的双重角色**：① 在世界模型内部组织多步预测与控制；② 作为可复用程序供后续智能体执行。

### 2.2 关键技术细节
- **MoT 三专家**：
  - **代码专家**：预训练语言骨干 + 冻结 Qwen3-VL ViT，采用 LLaDA 式**离散掩码 token 扩散**（吸收掩码损坏，$r\sim U(0,1)$ 独立伯努利掩码）；以 SDAR-1.7B 初始化词嵌入/LN/FFN/词表头（冻结），仅训练 MoT 注意力投影与调制参数。
  - **视频专家**：Cosmos-Predict2.5-2B 初始化的视频 DiT，建模 Wan2.2 VAE（48 通道）编码的未来帧，多视角 3D RoPE。
  - **动作专家**：从零初始化的动作 DiT，生成连续动作块（真实世界 64 维、RoboTwin 14 维，horizon=32）。
  - 各专家保留独立 QKV/O 投影、LN、FFN，通过**掩码联合注意力**通信：专家内双向，专家间**块级因果（C→V→A）**。
- **模态特定损坏**：视频/动作用连续 flow matching，噪声水平 $\sigma_m=\phi_{\gamma_m}(u_m)=\frac{\gamma_m u_m}{1+(\gamma_m-1)u_m}$，$\gamma_m=5$；视频用 $u_v=0.999b,\ b\sim\text{Beta}(7,1)$，动作用 $u_a\sim U(0,1)$；代码用吸收掩码。
- **噪声重采样以提供预测引导**：$u_v\sim q=\alpha p_{\text{pre}}+(1-\alpha)p_{\text{ref}}$（$\alpha=0.5$），并用重要性权重 $\bar w_v,\bar w_g$ 平衡视频学习与预测引导，损失为
  $$\mathcal L=\mathbb E_{u_v\sim q}[\lambda_v\bar w_v\ell_v+\bar w_g(\lambda_a\ell_a+\lambda_c\ell_c)]$$
- **自动标注管线（三阶段）**：
  1. 用 Gemini 3.1 Pro 针对预定义声明式 API 为每任务一个 episode 写子任务级技能程序；Claude Code（Opus 4.8）作为协调者蒸馏跨任务可复用技能；
  2. 冻结技能库（YAM 23 个 + 自我中心人类 27 个，共 50 个），用最终词表重标注采样子集，形成"子任务→程序"缓存；
  3. 对其余语料：接触与运动模式匹配则复用缓存，否则由编码智能体新写并回写缓存。
- **记忆缓存**：历史切片压缩为 K 个可学习记忆槽，作为前缀 token 读回；训练时以概率 $p$ 用模型自身预测替换真实前序切片。
- **混合执行（Hybrid Actions）**：每个重规划点，代码通道需通过**阶段门、依赖门、语法/白名单/非空门**（及失败重试限制）才执行，否则用同一次前向的动作块驱动；代码执行时丢弃该次动作块。
- **训练配方**：约 2,000 小时 YAM 机器人数据 + 约 1,000 小时自我中心人类操作数据联合预训练（共享 64 维状态—动作空间），下游每任务 100 条演示联合微调代码/视频/动作三目标。

### 2.3 算法流程（文字版）
- 预训练：随机采样三模态噪声水平 → MoT 联合预测代码 logits 与视频/动作速度 → 加权损失回传。
- 推理：每个重规划点重建提示并追加 G 个掩码 token 画布 → 与视频/动作状态联合去噪 T 步（每步提交最自信的 G/T 个位置）→ 解码切片作为子任务计划条件化动作专家（默认）或经门控后由 CaP 执行（混合模式）。

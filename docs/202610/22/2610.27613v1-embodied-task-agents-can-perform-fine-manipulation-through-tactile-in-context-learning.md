## 摘要
具身任务智能体能否在没有任务特定模型训练的情况下，利用触觉经验执行精细操作？我们通过 Tactile-ETA 研究这一能力，该系统通过上下文学习将触觉经验融入具身任务智能体。成功的专家演示展示了操作过程中接触如何变化。我们将每次记录的机器人运动与其相机视图和双侧触觉观测配对。我们保留每次运动开始和结束时的触觉观测，并在其间触觉图像发生显著变化时加入两个相邻时间点。智能体将这些演示与当前视觉、触觉观测和本体感觉相结合，通过通用机器人工具选择动作，而不更新模型参数。在四个仿真操作任务中，在保持当前传感与执行接口不变的情况下，将触觉观测加入同样的两个专家演示，可使平均成功率从 15.75% 提高到 24.00%。进一步实验表明，性能取决于演示的感官内容与表征；而在相同系统配置下比较 Lift Bottle 任务上的智能体模型，则显示出显著差异。在真实机器人任务中，具有对齐视觉与触觉观测的演示将任务成功率从 0% 提高到 60%。这些发现证明了在上下文中利用触觉经验进行精细操作的可行性，并提出了将具身任务智能体扩展到更多感官输入的路径。

## Abstract
Can embodied task agents use tactile experience to perform fine manipulation without task-specific model training? We investigate this capability through Tactile-ETA, a system that incorporates tactile experience into an embodied task agent through in-context learning. Successful expert demonstrations show how contact changes during manipulation. We pair each recorded robot movement with its camera views and bilateral tactile observations. We keep tactile observations at the start and end of each movement and add two neighboring time points when the tactile images change markedly in between. The agent combines these demonstrations with current vision, tactile observations, and proprioception to select actions through general-purpose robot tools, without updating model parameters. Across four simulated manipulation tasks, adding tactile observations to the same two expert demonstrations increases average success from 15.75% to 24.00%, with current sensing and execution interfaces held fixed. Further experiments show that performance depends on the sensory content and representation of demonstrations, while comparing agent models on Lift Bottle reveals substantial differences under the same system configuration. On the real-robot tasks, demonstrations with aligned visual and tactile observations increase the task success rate from 0% to 60%. These findings demonstrate the feasibility of using tactile experience in context for fine manipulation and suggest a path toward extending embodied task agents to additional sensory inputs.

## 1. 核心问题与研究动机

- **背景**：ETA、Show-Harness、RoboDawn 等"具身任务智能体"已证明通用基础模型可以通过观察—推理—机器人指令的流程执行任务；但**精细操作（fine manipulation）仍是明显短板**，真实机器人评测显示 pick-and-place 与精细插入任务之间存在巨大性能差距。
- **痛点**：精细操作需要根据**接触状态**实时调整动作（姿态、退让、阶段切换），而这类信息仅靠视觉难以可靠推断；触觉恰好提供互补信息。
- **核心问题**：*具身任务智能体能否在不做任务特定模型训练的前提下，利用"触觉经验"完成精细操作？*
- **思路定位**：把触觉经验放进**上下文（in-context）**而非参数中——专家演示提供"接触如何随动作演化"的参照，当前观测与执行反馈描述"正在发生的接触"，二者共同支撑冻结模型的动作选择。这被作者视为"向智能体扩展新感官模态"的一条可行路径。

## 2. 方法论

### 2.1 核心思想
- 构建 **Tactile-ETA**：不更新任何模型参数，通过上下文把**动作对齐的视觉—运动—触觉专家演示**注入冻结的具身任务智能体；智能体仍通过 OpenETA 的通用机器人工具（`move_to` / `observe` 等）输出运动与夹爪指令，底层控制器负责执行。

### 2.2 形式化
- 记 $\mathcal{C}_K$ 为由 $K$ 个专家 episode 构造的有序上下文，$\ell$ 为任务指令，$\mathcal{I}$ 为工具描述与静态任务约束，$H_t$ 为当前 episode 的历史（观测、历史工具调用、执行反馈）。在第 $t$ 次工具调用前：
  $$u_t \sim \pi_\theta(\cdot \mid \ell, \mathcal{I}, \mathcal{C}_K, H_t)$$
  其中 $\theta$ **全程冻结**；演示上下文在 episode 开始时一次性给出并保持不变，之后仅由新观测与反馈扩充 $H_t$。

### 2.3 演示上下文构造（关键技术细节）
- **按动作边界切分**：每个成功专家 episode 在记录的动作边界处切段；每段包含前后头部/腕部相机视图、同步的**双侧触觉序列**、以及由机器人状态计算的实测运动（末端平移、相对旋转、手指位置变化）。三者严格指向同一动作区间。
- **紧凑触觉序列（本文最核心的工程贡献）**：
  - 对每根手指，在触觉图上取 $3\times4$ 的 patch 网格，在下一帧邻近区域做整数位移搜索（最小化 MSE）匹配，得到每个 patch 的位移；取位移幅值的 **75 分位数 $d_{75}$** 作为变化度量，换算回原图像素后除以 2 像素阈值得到归一化变化分数；匹配可靠 patch 过少（tracking quality < 0.35）时退化为 ROI 内灰度绝对差 / 255。
  - 段内对每个采样间 $n$ 取两指中较大的归一化分数 $c_n$，令 $n^\star=\arg\max_{1\le n<N} c_n$，保留时间索引：
    $$\mathcal{S}=\begin{cases}\{0,\,n^\star-1,\,n^\star,\,N-1\}, & c_{n^\star}\ge 1\\ \{0,\,N-1\}, & c_{n^\star}<1\end{cases}$$
  - 即：**端点必留**（把触觉外观与前后视觉状态绑定），**仅在变化超过阈值时额外保留一对跨越峰值变化的相邻帧**；左右指共用索引，去重排序后每指最多 4 帧，按左右两条时间条带呈现并标注 step 编号。
- **上下文装配**：每段将触觉条带与视觉观测、运动记录配对，段内保序，附 episode 结果；$K$ 个完整 episode 组成 $\mathcal{C}_K$。

### 2.4 执行时的触觉反馈
- 每个运动段结束后，系统返回最新相机图像、机器人状态、是否到达目标及偏差反馈；运动过程中记录的触觉观测按上述同一规则筛选后以左右条带呈现，并追加进交互历史。因此智能体既能参照**演示中的接触演化**，也能参照**自己动作的最新反馈**，形成闭环。

## 6. 主要结论与发现

- **触觉演示经验确有增益**：在同样的两个演示、同样的当前传感下，加入演示触觉使四任务平均成功率从 **15.75% → 24.00%**（+8.25 个百分点）；作为参照，无演示时仅视觉 3.00%、视觉+当前触觉 6.25%。
- **任务间贡献结构不同**：Insert Tube 上视觉—运动演示相对"当前触觉"基线**毫无增益**，全靠演示触觉才提升（15%→32%）；Lift Bottle 与 Pull Out Key 上视觉—运动已有增益，触觉再进一步（27%→36%，18%→26%）；**Lift Can 在所有配置下都很难**。
- **触觉经验影响"接触后的调整"与"阶段切换时机"**：Insert Tube 中"持续前推至早停"的失败模式从 48/100 降至 13/100；成功案例显示智能体报告"明显形变"后执行退让 + 侧向修正；Pull Out Key 中触觉演示使智能体在第三次正转后判断"尚无明确停止信号"再多转一次，然后才反转上拉。
- **表征方式比信息量更关键**：Selected 36% > Endpoints 27% ≈ 无触觉 27% >> All frames **2%**——**塞入全部触觉帧反而灾难性变差**；端点采样会漏掉中间接触模式（如图 4 中更宽的蓝色条带）。
- **演示数量非单调**：1/2/4-shot 平均 22.50% / 24.00% / 19.00%；4-shot 使 Pull Out Key 26%→48% 却使 Lift Bottle 36%→2%。
- **强依赖底层智能体**：相同配置下 Lift Bottle 上 GPT-6 36%、GPT-5.6 Sol 21%、Terra 3%、Luna 0%。
- **真机可迁移**：单个多模态演示使两个任务各从 **0/5 → 3/5**（0% → 60%）。

## 7. 优点

- **问题切口清晰且实用**：把"触觉"从"训练新策略"转向"上下文经验"，无需参数更新、无需任务特定数据采集流程，工程落地门槛低，可直接插到现有 tool-based 智能体框架上。
- **触觉上下文的表示设计有巧思**：patch 位移的 75 分位 + 阈值归一化 + "端点必留、峰值变化加一对"的选择规则，是一个**信息密度与 token 预算之间的显式折中**；All frames 崩溃（2%）与 Selected 最优（36%）的对照有力地证明了"上下文组织方式"本身是一等公民。
- **受控比较干净**：Tactile-ETA vs Visual–motion 严格只差"演示中是否有触觉"，把混杂因素压到最低。
- **定量 + 行为学 + 定性案例三层证据**：不仅报成功率，还统计初次抓取策略（1/100 vs 100/100）、前推失败模式计数，并给出带原文引述的 rollout 对照，说明"增益来自哪里"。
- **诚实的实验报告**：披露补测（114 个缺失组合）及原因（初始化不可用 104、基础设施 6、取消 4）、说明定性案例非因果对照、给出完整 prompt 与参数表。

## 8. 不足与局限

- **绝对性能仍然很低**：最优配置平均仅 24%，Lift Can 几乎不 work（2%–3%），距"可用"很远；"可行性证明"的意味强于"有效性证明"。
- **统计功效不足**：100 trials/格、无置信区间与显著性检验，多个比较的差距（如 3% vs 2%、24% vs 26%）落在噪声范围内；4 任务 × 多配置的大规模比较存在多重比较问题。
- **触觉仅用于"段间决策"**：作者自认当前系统主要在运动段之间用触觉做决策，**没有把触觉用于执行中的高频连续反馈控制**，因此对滑移、微力控等真正"接触密集"的精细操作帮助有限。
- **表征消融覆盖太窄**：Selected vs Endpoints vs All frames 只在 Lift Bottle 上做（1 任务 100 trials），而 All frames 的 2% 与 4-shot 的 Lift Bottle 2% 都是极低值，可能受个别失败模式的偶发影响，结论稳健性存疑。
- **对底层模型高度敏感**：GPT-5.6 Terra/Luna 几乎为 0，说明方法**没有解决"模型本身不会用触觉"的问题**；这既是发现也是限制——方法的收益高度依赖不可控的第三方闭源模型。
- **演示数量与选择不稳健**：4-shot 反而大幅掉点（Lift Bottle 36%→2%），且演示固定为 episode 0/1，未做演示随机化或多样性分析，存在"挑到好演示"的偏差风险。
- **真机证据薄弱**：仅 2 任务、每条件 5 trials、人工评定成功、单一平台与单一触觉夹爪，泛化性证据有限。
- **算力与成本不透明**：未报告 API 调用量、token 消耗与推理费用；考虑到每 episode 需注入多 episode × 多段 × 多帧图像，上下文成本可能相当可观，但文中未量化，影响可复现性与实际部署评估。
- **可复现性受闭源模型制约**：核心结果依赖 GPT-6 等商用模型 API，社区难以完全复现与横向验证（作者亦呼吁"broader community evaluation"）。

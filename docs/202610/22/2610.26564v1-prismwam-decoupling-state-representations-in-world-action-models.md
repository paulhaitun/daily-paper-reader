## 摘要
世界动作模型（WAMs）通常通过预训练视频模型的潜在嵌入来表示世界，而这些嵌入纠缠了世界的异质方面，从世界看起来如何（例如纹理和颜色）到其物理构型如何（例如占据和位姿）。这引出了一个尚未充分探索的问题：WAM 的状态应由什么构成？我们认为，世界状态应将世界如何呈现与在动作下世界如何演化区分开来：前者捕获语义上下文，后者由物理状态支配。为此，我们提出 PrismWAM，它在联合建模状态与动作的同时将物理与语义解耦。PrismWAM 将具身任务分解为“语义规划→物理推演→可执行动作”的流水线：仅给定初始 RGB 观测，语义规划学习预测最终目标图像，而物理推演在深度空间中预测朝该目标的细粒度演化；随后由深度推演生成可执行动作。无需任何具身动作预训练或额外数据增强，PrismWAM 在仿真和真实世界中均取得了强操作性能。值得注意的是，PrismWAM 甚至超越了大量具有大规模具身动作预训练的模型（例如 OpenWAM-α）。更广泛地，我们将世界动作模型从建模世界看起来如何，重新定义为建模世界如何响应动作，为以动作为中心、基于占据、流、触觉感知、本体感觉等的世界模型铺平了道路。

## Abstract
World Action Models (WAMs) typically represent the world through latent embeddings from pretrained video models, which entangle heterogeneous aspects of the world, from how it looks (e.g., texture and color) to how it is physically configured (e.g., occupancy and pose). This raises an underexplored question: $\textbf{what should constitute the state of a WAM?}$ We argue that the world state should separate how the world appears from how the world evolves under action: the former captures semantic context, while the latter is governed by physical state. To this end, we propose $\textbf{PrismWAM}$, which decouples physics from semantics while jointly modeling state and action. PrismWAM factorizes an embodied task into a $\mathrm{Semantic\ Planning}\rightarrow\mathrm{Physical\ Rollout}\rightarrow\mathrm{Executable\ Action}$ pipeline: given only the initial RGB observation, semantic planning learns to predict the final goal image, while physical rollout predicts the fine-grained evolution toward this goal in depth space; executable actions are then generated from the depth rollout. Without any embodied action pretraining or additional data augmentation, PrismWAM achieves strong manipulation performance in both simulation and the real world. Notably, PrismWAM even surpasses a broad range of models with large-scale embodied action pretraining (e.g., OpenWAM-$α$). More broadly, we reframe World Action Models from modeling how the world looks to how it responds to action, paving the way for action-centric world models grounded in occupancy, flow, tactile sensing, proprioception, and beyond.

## 1. 核心问题与研究动机

- **背景**：世界动作模型（World Action Models, WAMs）通过联合建模未来状态与动作来支撑机器人操作，主流做法是直接复用预训练视频模型的潜表征（video latents）作为“世界状态”。
- **核心质疑**：视频潜表征把两类性质完全不同的因素纠缠在一起——
  - **语义上下文**：纹理、颜色、物体身份、可供性等，用于“理解被操作的是什么”；
  - **物理状态**：几何、位姿、占据、接触等，决定“动作会让世界如何变化”。
- **关键观察**：动作通常改变几何与位姿，而颜色、纹理等外观属性在动作下往往保持不变。因此用统一视频潜表征作为状态，会让表征“比建模动作响应所需的信息丰富得多”，迫使模型从外观变化中反推物理变化，造成精度与泛化上的浪费。
- **研究命题**：WAM 的“状态”应当**区分世界如何呈现（语义）与世界在动作下如何演化（物理）**，从而把世界动作模型从“建模世界看起来如何”转向“建模世界如何响应动作”。

## 2. 方法论

### 2.1 核心思想
将具身任务分解为三段式因果流水线：

> **语义规划（Semantic Planning）→ 物理推演（Physical Rollout）→ 可执行动作（Executable Action）**

- 语义规划：从 RGB 历史与当前观测推断“最终应该发生什么”（任务意图、目标场景构型）；
- 物理推演：在**深度空间**中预测朝目标演化的细粒度几何轨迹（“世界如何物理地变化”）；
- 可执行动作：由深度推演特征直接映射为连续动作（“如何做到”）。

### 2.2 概率形式化
- 原始 WAM 形式：策略 = ∫ p(a₁:ₕ | x₁:ₚ, x₀, c) · p(x₁:ₚ | x₀, c) dx₁:ₚ，即在未来世界状态上边缘化。
- 解耦后形式：π(a₁:ₕ | r≤₀, d₀, c) = ∫∫ p(a | z_D, c) · p(z_D | d₀, z_R, c) · p(z_R | r≤₀, c) dz_R dz_D，其中 z_R 为语义规划表征、z_D 为物理推演特征，c = (ℓ, s) 为语言指令与本体感知。

### 2.3 架构（基于 Wan 视频骨干的 Mixture-of-Transformers）
- **RGB 流（语义规划）**：输入历史/当前 RGB 潜变量 + 单个**稀疏未来目标帧** r_F 的噪声潜变量，预测其流速度；仅提供任务级语义监督。
- **深度流（物理推演）**：输入当前深度 d₀ 的干净潜变量 + 未来深度序列 d₁:ₚ 的噪声潜变量，预测**稠密**几何演化。
- **动作塔（可执行动作）**：对加噪动作块做线性投影为动作 token，预测每步动作速度。
- **链式注意力（Chain Attention）**：用结构化掩码约束信息流——
  - 视觉流内部：未来 token 可读观测 token 与彼此，观测 token 不可读未来；
  - 深度 token 额外只读**观测 RGB**（不读未来 RGB）；
  - 动作 token 读彼此 + 观测/未来深度，**不能直接访问 RGB**；
  - RGB 不读深度/动作，深度不读动作。三支各自有独立噪声等级嵌入，视觉块共享参数、动作块独立参数。
- **模态非对称监督**：RGB 用稀疏（单帧）目标、深度用稠密（序列）目标，从而把“任务语义”和“物理动力学”分配到不同表征空间。

### 2.4 训练流程
1. **深度 VAE 预训练**：以 Wan 预训练 RGB VAE 初始化单通道深度 VAE（48 / 16 潜通道，空间压缩 16× / 8×），在约 **2,300 小时**深度数据（AgiBotWorld-Beta 0.75 + RoboTwin 0.25）上训练，损失为 L1 + L2 + 极小 KL；训练后冻结。
2. **深度空间适配**：仅用深度预测损失把 Wan 骨干适配到深度序列预测。
3. **联合训练**：RGB 流、深度流、动作塔与条件投影联合优化，采用**联合流匹配目标** L = L_R + L_D + L_A，各模态独立采样噪声与噪声等级，Lₘ = E[w(σₘ)·MSE(v̂ₘ, vₘ)]；条件为 R≤₀、D₀、C。T5 文本编码器与两个 VAE 全程冻结。
4. **推理**：RGB 流只编码一次并缓存特征作为语义引导，**不生成未来 RGB 帧**；未来深度潜变量与动作块从高斯噪声联合去噪，执行动作前缀后重规划。深度图可解码用于可视化，但动作生成不依赖解码。

## 6. 主要结论与发现

- **无动作预训练下的强性能**：RoboTwin-C2R 随机场景 53.16%（starVLA 3.16%、FastWAM 1.90%）；平均 70.57%（FastWAM 39.85%）；PrismWAM\* 达 83.67%，比 FastWAM 高 43.82 pp，比 OpenWAM-α 高 14.62 pp。
- **超越大规模预训练模型**：RoboDojo 总分 36.23 vs OpenWAM-α 17.18、starVLA 6.40、G0.5 20.23、Xiaomi-Robotics-1 20.07；Precision 类 39.82 vs OpenWAM-α 18.45（+21.37）。
- **精度与泛化收益显著**：LIBERO-Plus 布局扰动 81.70%（OpenWAM-α 77.38%、FastWAM 66.49%）；LIBERO-Pro 物体属性扰动 88.65%（84.45% / 73.00%）；说明物理状态预测的收益**不止于外观鲁棒性**，还支撑空间泛化与精细控制。
- **数据高效**：仅约 2,300 小时深度数据、零具身动作预训练即可对标 6,400–100,000+ 小时动作预训练模型，提示“架构与状态表征设计”是独立于数据规模的另一条扩展路径。
- **深度损坏鲁棒**：三级损坏下平均性能最大仅下降 2.45 pp；轻度损坏在干净场景甚至有轻微提升。
- **真实世界**：ID 88.9% vs OpenWAM 74.1%（+14.8 pp），OOD 68.6% vs 48.6%（+20.0 pp）；但 Open Microwave 的 ID 上 OpenWAM 反而更优（90.0% vs 80.0%）。
- **消融结论**：去掉深度流损失最大（−28.05 pp，随机场景几乎崩溃），去掉 RGB 流 −11.15 pp，去掉深度-only 预训练阶段 −13.75 pp；允许 RGB 直连动作提升干净场景（89.10%）但显著损害迁移（40.30%），支持“链式路由”的必要性。

## 7. 优点

- **问题提出清晰且具原则性**：把“WAM 的状态该是什么”作为一个可操作的设计问题提出，并给出语义/物理的二分判据，而非单纯堆模块。
- **架构与监督信号高度匹配**：稀疏 RGB 目标（任务级）+ 稠密深度序列（物理级）+ 链式有向注意力，使三个分支的信息流与“因果顺序”一致，且避免未来 RGB 泄漏到动作。
- **推理高效**：语义规划仅在训练期作教师，推理时只编码一次 RGB 并缓存，不生成未来 RGB，也不需要解码深度即可出动作——规避了视频生成式 WAM 的测试时开销。
- **数据效率与可迁移性主张有实证支撑**：零动作预训练对标大规模预训练模型，并在多基准一致成立，而非单点超越。
- **鲁棒性评估有工程价值**：按真实传感器规格设计三级深度损坏，验证了“深度表征”路线的部署可行性。
- **可扩展性表述克制**：明确指出深度只是该原则的一种实现，可推广到占据、光流、触觉、本体感知。

## 8. 不足与局限

- **算力信息缺失**：未报告 GPU 型号/数量/训练时长，无法评估训练成本与“高效”主张的计算侧代价（6B/15B 视频骨干的训练开销实际不低）。
- **深度数据规模受限**：作者自承同步深度的真实操作数据稀缺，深度预训练仅约 2,300 小时，规模远小于动作预训练模型；这既是限制也是其“数据高效”叙事的双刃剑。
- **对深度传感器的依赖**：方法成立前提是可获得度量深度（或高质量深度估计）；真实场景中部分构型只能用头部单视角深度 VAE，腕部深度缺失会削弱物理推演。
- **真实世界实验统计力弱**：每条件 5–15 次试验、仅一个对比基线、单一机器人平台（Piper-X），

……未覆盖不同自由度、不同末端执行器或跨本体迁移，外部效度有限；同时未报告多次运行间的方差或置信区间，ID/OOD 的提升幅度（+14.8/+20.0 pp）虽大，但在如此小的样本量下仍应视为趋势性证据而非稳定估计。

- **深度分支的“世界模型”质量缺少独立诊断**：论文证明了深度流对动作预测不可或缺（去掉后 −28.05 pp），但未报告深度预测本身的精度指标（如深度 RMSE、轨迹 Chamfer 距离、接触区域误差），也未分析“深度预测得好不好”与“动作成功率高不高”之间的相关性。因此无法判断深度流是真正学到了物理推演，还是仅作为一种结构化的辅助表征/正则项在起作用。
- **深度 VAE 与深度来源的替代方案未充分探索**：深度 VAE 由 RGB VAE 初始化后冻结，但文中未给出深度重建质量对比、不同潜通道数（48 vs 16）的消融，也未与“直接用现成单目深度估计模型（如 Depth Anything 类）替代度量深度”的路线做正面对照。考虑到真实部署中腕部深度常缺失，这一缺失使“无度量深度时方法退化到什么程度”成为未解问题。
- **推理效率仅停留在定性主张**：作者强调不生成未来 RGB、不解码深度即可出动作，但未报告去噪步数、单步推理延迟、控制频率、显存占用等可核验指标，也未做去噪步数与成功率的权衡曲线。对于一个以“规避视频生成测试时开销”为卖点的框架，这使效率主张难以与 FastWAM、π0.5 等基线做量化对比。
- **关键设计超参缺少敏感性分析**：稀疏未来目标仅取“单帧”，但取第几帧、帧间隔如何影响语义规划的粒度未做消融；链式注意力的掩码是硬约束，未讨论放宽（如允许动作读取少量 RGB 摘要 token）是否存在更优折中；损失权重 w(σ) 的具体形式与模态间平衡策略也未展开。
- **缺少失败模式与错误归因分析**：所有基准仅报告成功率，未对失败案例分类（如抓取失败、目标定位错误、长程记忆丢失、接触力控制不足）。这削弱了“语义规划 vs 物理推演”解耦框架的解释力——读者无法判断性能瓶颈究竟落在哪一段流水线。
- **模型规模与方法的效应混杂**：6B 与 15B 结果并列呈现，PrismWAM\* 还额外做了视频预训练，因此“本方法带来的增益”与“更大骨干 + 更多预训练带来的增益”未被分离；缺少同骨干下与纯视频 WAM 的严格对照（同等数据、同等步数、同等参数量）。
- **真实任务覆盖偏窄**：三个任务均属桌面级刚体操作（拾放、排序、开门），缺少柔性物体、可变形物、多物体堆叠、需要力反馈的接触密集型任务，而这类任务恰恰最依赖“物理状态”而非“语义上下文”，是本方法最应受益的场景，未加验证略显遗憾。

## 9. 启示与可借鉴之处

- **“状态表征设计”本身是一条独立的扩展轴**：在数据规模难以继续膨胀的现实中，明确区分“世界看起来如何”与“世界如何响应动作”，比单纯扩大视频预训练更具性价比。这一判据可迁移到任何以视频潜表征为世界状态的模型。
- **模态非对称监督是一个通用技巧**：对语义用稀疏监督、对物理用稠密监督，本质上是用监督密度控制表征的信息瓶颈，使不同分支被迫承载不同抽象层级的信息。该思路可推广到触觉、力/力矩、本体感知等模态的组合。
- **链式有向注意力可作为“因果先验”的轻量实现**：通过掩码而非额外模块来编码“语义→物理→动作”的因果顺序，既防止未来信息泄漏，又几乎不增加参数，工程上易于复现。
- **推理期把生成式教师降级为一次性编码器**：训练时用未来 RGB 提供语义监督，推理时只编码当前观测并缓存，这一“训练重、推理轻”的非对称设计对实时机器人控制很有参考价值。
- **鲁棒性评估应对齐真实传感器规格**：按 Orbbec Gemini 335 / RealSense D435 的实际噪声特性设计分级损坏，比抽象的加噪实验更能支撑部署结论，值得作为此类工作的评估范式。

## 10. 开放问题与后续方向

- 将“物理状态”从深度推广到占据栅格、场景流、接触图或触觉表征，并比较不同物理状态选择对精度类任务的影响。
- 在缺少度量深度时，用单目深度估计或跨模态蒸馏替代，量化性能退化曲线。
- 引入失败检测与在线重规划，把“语义规划—物理推演”的解耦用于错误归因与局部重试。
- 在柔性物体、接触密集任务与跨本体迁移上验证该原则的普适性。
- 补齐算力、延迟、方差与 scaling 曲线，使“数据高效”与“计算高效”的主张可被独立核验。

## 11. 总体评价

PrismWAM 的贡献主要不在于刷新若干基准数字，而在于提出了一个清晰、可操作且可反驳的设计命题：世界动作模型的状态应当把语义上下文与物理状态解耦，并用监督密度与注意力路由把这一解耦落实到架构中。其方法论自洽（概率分解 → 架构 → 掩码 → 非对称监督 → 联合流匹配），实验覆盖面上乘，消融能够支撑核心因果链，深度损坏实验具备工程说服力。主要短板在于可核验性：算力与推理效率指标缺失、真实世界统计力薄弱、深度分支缺少独立的物理预测诊断、模型规模与方法的效应未分离。总体而言，这是一篇“观点比数字更有价值”的工作——它把 WAM 的研究重心从“生成更逼真的未来视频”推向“预测动作真正会改变的量”，其原则大概率会比其具体实现产生更持久的影响；但若要作为“数据高效替代大规模动作预训练”的强主张被接受，仍需补齐成本核算、失败分析与更广任务域的验证。

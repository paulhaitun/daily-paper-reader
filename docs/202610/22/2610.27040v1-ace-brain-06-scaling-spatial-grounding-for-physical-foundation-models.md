## 摘要
包括 GPT-6 Astra 和 Claude Opus 5.5 在内的通用多模态模型在具身操控中展现出广泛能力。我们的分析表明，这种通用性伴随着强大的空间感知能力，例如 Astra 能够在视觉干扰物中确定应与任务相关实体交互的位置。由于空间感知将高层推理与物理场景连接起来，我们研究扩展视觉定位，以增强通用具身操作的感知基础。我们开发了一个统一的数据流水线，将机器人操控记录与来自多种来源的互补视觉数据相结合。在自动标注机器人记录后，该流水线将收集到的数据转换为可验证的定位监督。在此流水线生成的约 150 万个样本上微调 Qwen3.5-9B，得到了 ACE-Brain-0.6。该模型在七个公开定位基准中的四个上优于 GPT-6 Astra，总体平均得分为 75.41，而 Astra 为 73.68。在固定的 Qwen3.5-9B 微调设置下，随着后续数据发布不断扩大训练集以覆盖更广泛的定位场景，总体定位性能稳步提升。这些结果表明，扩展来自多样来源的可验证定位监督，可以增强一个开放 9B 模型在通用具身操作中的空间感知能力。

## Abstract
General-purpose multimodal models, including GPT-6 Astra and Claude Opus 5.5, demonstrate broad capabilities in embodied manipulation. Our analysis indicates that this generality is accompanied by strong spatial perception, as Astra can determine where to interact with task-relevant entities amid visual distractors. Because spatial perception connects high-level reasoning to the physical scene, we investigate scaling visual grounding to strengthen the perceptual foundation of general embodied operation. We develop a unified data pipeline that combines robot manipulation recordings with complementary visual data from diverse sources. After automatically annotating the robot recordings, the pipeline converts the collected data into verifiable grounding supervision. Fine-tuning Qwen3.5-9B on approximately 1.5 million samples produced by this pipeline yields ACE-Brain-0.6. The model outperforms GPT-6 Astra on four of seven public grounding benchmarks, with an overall average score of 75.41 compared with Astra's 73.68. Under a fixed Qwen3.5-9B fine-tuning setup, aggregate grounding performance improves steadily as successive data releases expand the training collection to cover a broader range of grounding scenarios. These results show that scaling verifiable grounding supervision from diverse sources can strengthen the spatial perception of an open 9B model for general embodied operation.

- **研究问题**：在**固定模型架构与训练配方**的前提下，仅通过扩展定位监督的**规模与覆盖范围**，一个开放的 9B 视觉语言模型能否匹配甚至超越 Astra 的定位能力？

## 2. 方法论

### 2.1 核心思想
- 将**所有定位任务统一为条件文本生成**：输入一张或多张图像 + 自然语言查询，输出五种形式之一：
  - 单点 `(x, y)`；点列表 `[[x1,y1],...]`；边界框 `(x1,y1,x2,y2)`；整数计数；类别 token（`yes`/`no`/`none`）。
  - 坐标归一化为 `[0,1000]` 整数；点列表不带逐点标签。
- 该统一接口覆盖：按类别/属性/位置/关系/功能指称、全实例指向与计数、空间关系判断与自由空间定位、部件/接触区域/放置目的地/末端轨迹定位、机器人场景跨视角对应。

### 2.2 基座模型与训练设置
- 基座为 **Qwen3.5-9B**；**全量微调语言模型参数，冻结视觉编码器**，禁用多 token 预测头。
- 采用**非思考模式**：对话模板在答案前产生空推理块，其模板 token 从损失中屏蔽，模型不会在答案中学到输出该块。

### 2.3 数据管线（三源合一）
- **机器人操作数据**（30+ 数据集族，单臂/双臂/移动/人形）：覆盖目标域，但普遍缺少物体标签，需自动标注。
- **自我中心人–物交互数据**：提供第一人称视角、手–物掩码与接触区域。
- **通用指向/定位数据**：补齐穷尽实例集（计数）、部件掩码（功能定位）、3D 标注（空间关系与自由空间）；另加少量通用 VQA 以保持多模态能力。

### 2.4 机器人轨迹自动标注（三步）
1. **关键帧选择**：依据动作信号，偏好夹爪状态切换与大动作变化，并保留轨迹首/中/尾（示例中每段约 20 个关键帧）。
2. **开放词表构建**：用 VLM 为每个 episode 与每个相机列出可见物体的短名与外观描述，形成与场景、视角绑定的词表。
3. **检测 + 语义重标注**：Grounding DINO 检测、SAM 3 精化框；另一条 SAM 3 识别分支对每个框做最佳重叠概念检测并**重命名**（IoU ≥ 0.5 时采用 SAM 3 标签），**保持框数量与几何不变**（示例：5 个框、2 个标签被纠正、0 个框被新增）。

### 2.5 问题生成与防捷径规则
- 全部由模板生成 QA，答案必须**可对标注验证**。
- 计数与“所有实例”类问题仅在**实例集完整**时生成；负样本问题需对照图像词表核验“确实无一正确”；自由空间目标仅标**未占据的 2D 区域**，不声称 3D 可行。
- 去捷径约束：单一模板内任一答案形式占比不超过 70%；yes/no 答案平衡；返回点数与问题要求一致。

### 2.6 质量控制与数据规模
- 机器人场景中每个检测框由 VLM 核验，标签与区域不符则丢弃。
- 通过匹配**排除所有评测基准的图像与 episode**，防止训练–测试重叠。
- 最终约 **154 万样本**、**341 万 QA 对**、约 **139 万条不同图像路径**。

### 2.7 优化细节
- 损失：仅对答案 token 计算 token 平均交叉熵（问题与图像 token 无损失，空推理块 4 个 token 亦屏蔽）。
- 序列打包为 16,384 token，使用 variable-length attention 保证不同对话互不注意力；每个 global step 含 16 条序列（约 140 样本）。
- AdamW，β=(0.9, 0.95)，ε=1e-8，weight decay 0.1；学习率 50 步线性 warmup 至 1e-5，再余弦衰减至 1e-7。
- 峰值学习率由早期数据版本上的四点扫描一次性确定，此后所有 run 固定，使差异仅来自数据；每次 run **只训练 1 个 epoch**。
- 主权重 fp32；使用 FSDP + activation checkpointing + FlashAttention-2。

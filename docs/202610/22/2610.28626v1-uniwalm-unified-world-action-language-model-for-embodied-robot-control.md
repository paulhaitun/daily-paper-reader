## 摘要
受人类能够整合语言、感知和动作经验的能力启发，我们提出 UniWALM，一种统一的世界-动作-语言模型，它在单一共享表示中学习视频、动作和语言，其中每种模态既作为条件信号，又作为监督目标。我们提出：联合生成语言能否丰富这一共享表示，从而改进操作并支持依赖记忆的行为？与先前将推理模型或视觉-语言模型附加到视频-动作骨干上并作为不同阶段运行的方法不同，UniWALM 在单一 mixture-of-transformers 骨干内统一三种模态，其各模态扩散头同步协同去噪，在与动作相同的一次前向中解码子任务和文本记忆，无需单独的规划阶段；生成的语言在下一步被重新使用，从而在没有外部规划器或记忆库的情况下形成“语言即记忆”闭环。为在这一更丰富的目标下保持动作流可靠，我们进一步提出带校正的流匹配（Flow Matching with Correction, FMC），这是一种训练目标，无需推理时开销即可教会模型从受扰动的动作轨迹中恢复。UniWALM 在组合式拾放（MolmoSpaces）以及 RMBench 中依赖记忆的子集上持续优于同骨干基线（例如 FastWAM），在没有任何预训练语言或推理模型的情况下达到 34.5%，并且仅使用单个锚帧就超过了 Mem-0 配备关键帧的设置（28.5%）。在真实世界的 Find-the-Item 任务上，生成文本记忆将成功率从 11.1% 提升到 61.1%，而最先进的 VLA 仍处于或低于随机水平（<=33.3%）。

## Abstract
Motivated by the human ability to integrate experience across language, perception, and action, we introduce UniWALM, a unified world-action-language model that learns video, action, and language in a single shared representation, where each modality is both a conditioning signal and a supervision target. We ask: can jointly generating language enrich this shared representation, improving manipulation and supporting memory-dependent behavior? Unlike prior approaches that attach a reasoning or vision-language model to a video-action backbone and run them as distinct stages, UniWALM unifies all three modalities inside a single mixture-of-transformers backbone whose per-modality diffusion heads co-denoise synchronously, decoding subtask and textual memory in the same pass as action with no separate planning stage; the generated language is re-consumed on the next step, closing a language-as-memory loop without an external planner or memory bank. To keep the action stream reliable under this richer objective, we further introduce Flow Matching with Correction (FMC), a training objective that teaches recovery from perturbed action trajectories at no inference-time cost. UniWALM consistently improves over same-backbone baselines (e.g., FastWAM) on compositional pick-and-place (MolmoSpaces) and across the memory-dependent subset of RMBench, where it reaches 34.5% without any pretrained language or reasoning model and exceeds Mem-0's keyframe-equipped setup (28.5%) using only a single anchor frame. On a real-world Find-the-Item task, generating textual memory lifts success from 11.1% to 61.1%, while state-of-the-art VLAs stay at or below chance (<=33.3%).

- **背景割裂**：现有具身模型通常只覆盖"视频—语言—动作"三元组中的部分方向。VLA（如 π0.5）把语言当作固定条件但不生成语言；CoT-VLA 类方法自回归生成中间语言，但动作必须等待 token 解码，且生成文本不跨步复用；世界动作模型（FastWAM、DreamZero）联合建模视频与动作却完全丢弃语言；记忆增强系统（Mem-0、π0.7、MEM）则外挂检索缓冲或独立规划器。
- **核心疑问**：能否在**单一共享表示**中让语言、视频、动作互为条件与监督目标，并让模型自己生成的语言充当跨步工作记忆？
- **生物学类比**：作者引用后顶叶/前运动皮层的感觉—运动融合、海马体同时承担回忆与想象功能，以及人类用"默念/复述"作为工作记忆的现象，论证"生成语言即记忆"的合理性。
- **两个研究问题**：(i) 联合生成语言是否丰富视频-动作模型的共享表示并提升操作？(ii) 策略能否把自己生成的、跨步回灌的语言当作工作记忆，解决记忆依赖任务？
- **对既有混合架构的批评**：WAM + VLM 式流水线使用两个为不同目标优化的视觉骨干、松耦合、把语言当外部隐状态、把记忆当外挂模块，规划与控制异步执行。

## 2. 方法论

### 2.1 总体形式化（WALM）

- 定义 World Action Language Model：输入当前观测 $O$（k 个 RGB 视角）、机器人状态 $S$、视觉记忆 $F$（一个或多个帧）、任务提示 $T$，联合生成
  $$V_{1:H},\ (A,\beta)_{1:N},\ L := \text{UniWALM}(O,S,F,T)$$
  其中 $V_{1:H}$ 为 H 帧未来视频，$(A,\beta)_{1:N}$ 为 N 步动作块及 1 维任务完成信号 $\beta$，$L$ 为紧凑字符串（子任务 ∥ 文本记忆），在下一步作为提示回灌。
- **推理时关闭视频生成**，语言 DiT 与动作 DiT 同步运行。

### 2.2 架构：Mixture of Transformers（MoT）

- 以 Wan2.2 视频 DiT 为骨干（30 层），复制其结构、缩小隐藏维度得到**动作 DiT（1B，hidden 1024）**与**语言 DiT（0.5B，hidden 512）**，二者**从零初始化**，不使用任何预训练语言/推理模型。
- 每个模态专家层：独立 AdaLN 时间条件 → 各自 Q/K/V 投影 → 三模态 token 沿序列维拼接做**统一自注意力**（带 RoPE）→ 再对 T5 编码的任务指令与本体感觉做**跨注意力**。
- 训练时随机以 10% 概率丢弃本体感觉；约束推理 token 只关注视觉特征与输入提示，动作 token 可关注语言 token；视频骨干用 **LoRA（rank 256）** 微调。

### 2.3 语言专家：离散扩散

- 采用离散语言扩散：按扩散时间步对真值文本做随机替换 $L_t := \text{RandomReplace}(L_{GT}, t)$，模型预测正确 token 嵌入，用交叉熵监督：
  $$\hat{L} := \text{DiffusionStep}(L_t, t),\quad \mathcal{L}_{lang} := \text{CrossEntropy}(\hat{L}, L_{GT})$$
- 每次扩散前向生成 64 个语言 token；语言与动作在**同一次去噪过程**中协同细化，无需单独规划阶段。

### 2.4 协同训练目标

$$\mathcal{L} := \mathcal{L}_{video} + \mathcal{L}_{action} + \alpha \mathcal{L}_{lang}$$
- $\mathcal{L}_{video}$、$\mathcal{L}_{action}$ 为流匹配损失，采用 **ℓ1**（作者称比 ℓ2 更稳定）。
- 两层抽象并行监督：视频损失提供**帧级预测结构**（短期稠密 RGB），语言损失提供**任务级预测结构**（下一子任务与任务状态），动作损失把两者锚定到物理行为。

### 2.5 三种记忆机制

- **文本记忆回灌**：语言头在每次前向中输出"子任务 ∥ 文本记忆"，下一步作为提示重新输入，形成闭环，无外部规划器/记忆库。
- **视觉记忆**：可选锚帧（实验中为回合起始单帧），经同一 VAE 编码后拼入视频 token 流；对锚帧 RoPE 坐标做宽度 $W$ 的偏移以避免与当前观测位置编码重叠；设计上支持任意帧数。
- **任务完成信号 $\beta$**：1 维通道拼接进动作向量，在子任务完成时刻由 0 跳变为 1，用于门控文本记忆更新，避免每步重写导致进度被覆盖；因属于动作向量，直接由 $\mathcal{L}_{action}$ 监督，无需额外损失项。

### 2.6 Flow Matching with Correction（FMC）

- 标准流匹配学习速度场 $v_t = \epsilon - x$，但生成过程常有微小偏差导致轨迹不精确。
- FMC 构造扰动动作 $x_0^p := x_0 + \epsilon_1$（$\epsilon_1 \sim \mathcal{N}(0, sI)$），在同一噪声 $\epsilon$ 下得到偏离名义轨迹的点 $x_t^p := (1-t)x_0^p + t\epsilon$，并令校正目标满足"一步 $\Delta t$ 反向回到名义轨迹"：
  $$v_{corr} := \frac{x_t^p - x_{t-\Delta t}}{\Delta t} = (\epsilon - x_0) + \frac{1-t}{\Delta t}\epsilon_1$$
  即标准速度加一项抵消扰动的修正项，$\epsilon_1=0$ 时退化为标准目标。
- **关键实现细节**：因修正项随 $(1-t)/\Delta t$ 放大，仅在 $t \ge 0.5$ 时启用校正分支；校正概率 $p=0.5$，扰动尺度 $s=0.2$（主算法）/ 扫描最优 $s=0.4$；**推理完全不变**，无额外条件、采样步数或模型容量。

## 3. 实验设计

### 3.1 仿真：MolmoSpaces（操作）

- 221K 轨迹、DROID 风格 Franka，5 个任务（Pick、Pick-RandCam、Pick&Place、Pick&Place-NextTo、Pick&Place-Color），每任务 **1000 个 OOD episode**，Filament 渲染器，报告 95% 置信区间。
- 对比：π0.5-Finetuned、MolmoBot-Pi0、FastWAM、MolmoBot-Img、MolmoBot（with history）。

### 3.2 仿真：RMBench M(n)（记忆）

- 4 个记忆依赖任务：Press Button、Blocks Ranking Try、Cover Blocks、Battery Try；双 AgileX 臂 + RoboTwin 2.0/SAPIEN；每任务 50 专家演示、**100 rollout episode**。
- 对比：DP、ACT、π0.5、X-VLA、Mem-0（无关键帧）、FastWAM、Mem-0（有特权关键帧）、并发工作 WLA-0。
- 该基准上启用锚帧 + $\beta$ + 文本记忆，但**不使用历史关键帧**（比 Mem-0 信息更少）。

### 3.3 真实世界：双臂灵巧操作

- 两台 Flexiv Rizon 臂 + 灵巧手（Sharpa Wave / Paxini），三任务：Cube Pick&Place（44-DoF 简单）、Empty Container（双臂复杂）、Find the Item（记忆，中途遮挡物品）。
- 每任务 20 rollout，记忆任务 18 rollout；对比 π0.5、GR00T-N1.7、FastWAM、MolmoBot。
- 为公平起见，真实实验（含 Find-the-Item）**不启用锚帧与 $\beta$**，记忆信号完全来自模型自生成语言。

### 3.4 消融

- **Pick&Place 消融**（38K 子集，1000 OOD episode）：基线≈FastWAM 31.0% → +R 35.9% → +FMC 38.9% → +LoRA 41.0%。
- **RMBench Press Button 记忆消融**：无语言无视觉记忆（≈FastWAM，100k 步）0%；仅视觉记忆 1%；仅语言生成 15%；两者结合 30k 步 18%、100k 步 51%。
- **FMC 超参扫描**：7 类 2D 机器人轨迹（圆、星、螺旋、线、弧、8 字、方），每配置 200k 步，500 生成 vs 1000 真值轨迹的对称 Chamfer 距离；最优配置 $s=0.4, d=0.3, t\ge0.5$，平均 −4.0%，7 类中赢 5 类。

## 4. 资源与算力

- **主训练**：8-bit AdamW，**12 个 H200 节点 × 8 GPU = 96 块 H200，训练 44 小时**；batch size 3840，学习率 4e-4，15k 步，221K 轨迹混合数据。
- **RMBench 专用模型**：单独训练 100k 步，batch 448，**10 个 H100 节点，约 36 小时**。
- 输入分辨率：仿真 224×448（两视角），真实 224×672（三视角）。
- **推理速度**：32 步动作块、10 步去噪，无语言 76 ms，含语言专家 123 ms（未优化）。
- ⚠️ **配置描述存在小矛盾**：3.5 节一处写"推理 20 步动作与语言去噪"，同节延迟数据处写"10 denoising steps"，文中未澄清。

## 摘要
具身智能的快速发展使机器人能力日益增强，能够遵循语言指令并操作多种物体。然而，结构化环境中的优异结果并不能自动迁移到开放世界条件；在开放世界中，杂乱、遮挡和变化的视角可能掩盖动作所需的空间关系。为弥补这一感知差距，本文引入一种虚拟主动感知范式。AWAM 是一种主动世界-动作模型，它在执行动作之前主动规划观察位置，并想象沿规划轨迹将会看到的景象。该方法预测与任务相关的虚拟相机运动，并将其作为结构化查询输入几何条件化的世界模型，生成可用于操作的可复用空间先验；随后该先验被压缩为固定记忆，并通过交叉注意力与实时观测融合，用于基于扩散的动作预测。AWAM 取得了具有竞争力的成功率：在 LIBERO-Occ 上为 75.9%，在 LIBERO-Plus 上为 62.4%，在 RLBench-OG Occlusion1 上为 76.5%，在真实机器人试验中为 94.4%。这些结果表明，其对所评估的遮挡和分布偏移具有更强的鲁棒性，并在一定程度上缩小了结构化操作与受控程度较低环境之间的差距。

## Abstract
Rapid progress in embodied intelligence has enabled increasingly capable robots to follow language instructions and manipulate diverse objects. However, strong results in structured environments do not automatically transfer to open-world conditions, where clutter, occlusion, and changing viewpoints can obscure the spatial relationships required for action. To address this perceptual gap, a virtual active-perception paradigm is introduced. AWAM, an Active World-Action Model actively plans where to observe and imagines what will be seen along the planned trajectory before acting. Task-related virtual camera motion is predicted and used as a structured query into a geometry-conditioned world model, producing a reusable spatial prior for manipulation, which is later compressed into a fixed memory and fused with live observations through cross-attention for diffusion-based action prediction. AWAM achieves competitive success rates with 75.9% on LIBERO-Occ, 62.4% on LIBERO-Plus, 76.5% on RLBench-OG Occlusion1, and 94.4% in real-robot trials. These results support improved robustness to the evaluated occlusions and distribution shifts, addressing part of the gap between structured manipulation and less controlled environments.

## 1. 核心问题与研究动机

- **感知瓶颈而非动作建模瓶颈**：现有 VLA（视觉-语言-动作）与扩散策略在结构化环境中表现优异，但一旦进入开放世界（杂乱、遮挡、视角变化），关键物体或交互区域被遮蔽，动作模型再强也无法凭空恢复输入中缺失的场景证据。
- **现有方案的不足**：
  - *物理主动感知*：通过移动相机/机器人获取新证据，但引入额外执行步骤，且可能改变机器人或场景状态。
  - *虚拟视角方法*：候选视角只能从预定义相机中选取；基于重建的渲染无法揭示初始几何中不存在的表面；预测式世界模型多围绕“动作诱发的未来”建模，而非“主动的视角查询”。
- **核心命题**：将任务条件化的虚拟主动感知形式化为**轨迹条件化的视角想象**——预测一条虚拟相机轨迹（不实际执行），用它作为结构化查询，把场景中已有证据与学习到的空间先验提取为可复用的表征，从而把“感知探索”与“机器人运动”解耦。

## 2. 方法论

### 2.1 整体框架

- 输入：初始双视角 RGB-D（静态相机 + 腕部相机）、标定参数、语言指令。
- 流程分三阶段：**任务引导视角规划**（每回合一次）→ **视角想象与世界记忆构建**（每回合一次）→ **记忆条件化闭环控制**（每次重规划）。
- 核心解耦：记忆 $M_0$ 在回合开始时构建一次并固定；动作策略实时融合当前观测与记忆检索内容。

### 2.2 任务条件化虚拟视角规划

- 用演示中的腕部相机轨迹作为任务相关虚拟查询的代理监督。
- 轨迹参数化为相对于初始腕部位姿的变换 $T_i = (T_0^w)^{-1}T_i^w$，使预测对全局场景原点不变。
- 相对位姿离散化为轨迹 token（平移、旋转、轨迹尺度），用因果 Transformer 自回归预测，损失为教师强制下的负对数似然（式 5）。
- 推理时用初始腕部位姿还原为度量相机位姿；按累积相机运动（平移 + 旋转增量归一化后合并）选取 $K=21$ 个代表性视角，避免视角预算浪费在近似静止段。

### 2.3 几何条件化世界记忆

- 将初始双视角 RGB-D 反投影为彩色点云 $P_0$（式 6）；在预测位姿下渲染可保留已观测表面，但未观测区域出现空洞（LIBERO-Occ 平均空洞率 39.29%，峰值 74.47%）。
- 采用 **WorldStereo** 作为几何条件化世界模型，输入粗渲染、缺失掩码、相机信息与参考视角，沿虚拟轨迹生成视角一致的表征；生成目标为**同一初始场景在不同相机位姿下的观测**（物体与机器人保持静止），即“视角条件化的场景想象”而非动作诱发的未来。
- **不直接使用生成 RGB**，而是提取中间世界模型特征（每视角 16×16 空间池化，$Z \in \mathbb{R}^{21\times256\times5120}$）。
- 记忆压缩：每个虚拟视角用少量可学习 query 做空间注意力聚合，同槽 query 再经视角间注意力交换信息，展平为固定大小记忆 $M_0$（参考实现 294 个 token、宽度 384）。

### 2.4 记忆条件化闭环控制

- 实时静态/腕部 RGB 经共享视觉骨干 + 语言条件化 resampler 得到实时 token $L_t$。
- 残差交叉注意力检索：$F_t = L_t + \mathrm{CA}(L_t, M_0)$，$L_t$ 作 query，$M_0$ 作 key/value；记忆固定但检索内容随观测变化，残差保留实时感知直通路径。
- 条件扩散 Transformer 生成短时域动作块（式 8），训练用标准扩散去噪目标。
- **避免训练-测试失配**：策略训练与评估时 $M_0$ 均由 $G_\phi$ 预测轨迹构建，而非演示轨迹。

### 2.5 训练流程

- 顺序训练而非端到端：轨迹预测器（冻结视觉/语言骨干，仅训投影层与因果 Transformer）→ 世界模型适配（特征可预计算缓存）→ 动作策略（先接口对齐、后适配扩散去噪器）。

## 6. 主要结论与发现

- **主结果**：LIBERO-Occ 平均 75.9%（Spatial 84.6 / Object 93.2 / Goal 84.8 / Long 41.0）；LIBERO-Plus 62.4%；RLBench-OG Occlusion1 76.5±1.1%（平均排名 2.05 最优）；真实世界 85/90 = 94.4%。
- **分布偏移下的增益集中**：LIBERO-Plus 上相机视角（53.4%）、机器人状态（48.9%）、布局偏移（73.0%）提升最明显，说明方法对几何扰动最有效。
- **长时程是短板**：Long suite 上 Fast-WAM（44.2%）优于 AWAM（41.0%），原因是记忆从初始场景构建后不再更新，物体状态大幅变化后部分记忆过时。
- **消融结论**：
  - 去掉整个预测分支：−11.5 个百分点（64.4%），说明增益不能仅由闭环策略解释。
  - 仅给策略预测轨迹、不生成视角/记忆：67.3%，说明轨迹本身含弱规划先验，但无法替代显式预测视觉上下文。
  - 用均匀球面采样视角替代学习轨迹：70.2%（−5.7），说明“按任务分配观察”优于“均匀覆盖”。
  - 保留学习轨迹但只做几何 warp：69.0%（−6.9），说明视角选择不足以恢复从未观测的表面。
- **预算敏感性**：$K$ 从 7→21 性能上升（72.4→75.9），到 28 基本饱和（76.0）。
- **总体洞见**：世界模型不仅可预测未来动力学，也可作为**内部感知机制**，用于查询当前观测中缺失的空间信息。

## 7. 优点

- **问题形式化有新意**：把主动感知从“物理移动”转为“虚拟轨迹查询”，将感知探索与机器人运动解耦，避免额外执行代价与状态扰动。
- **轨迹级而非单视角**：连续轨迹可绕开遮挡物、逼近精细交互几何，比单视角选择或少量独立位姿更灵活。
- **记忆复用设计高效**：每回合只构建一次 $M_0$，闭环中通过交叉注意力按需检索，兼顾计算效率与任务适应性。
- **使用中间特征而非生成 RGB**：与世界模型预测表征的思路一致，避免 RGB 生成误差直接传入策略。
- **避免训练-测试失配**：训练与评估均用预测轨迹构建记忆，而非演示轨迹，工程上较为严谨。
- **实验覆盖较广**：3 个仿真 benchmark + 真实机器人，且消融能定量分离各组件贡献。
- **诚实报告短板**：明确指出 Long suite 落后与记忆过时问题，并提出“抓取状态变化时重建记忆”的改进方向。

## 8. 不足与局限

- **感知假设较强**：依赖标定相机与度量深度，超出纯图像策略的传感要求；相机鲁棒性也仅在“已知标定”条件下评估。
- **记忆静态、易过时**：$M_0$ 整回合固定，物体大幅位移或多阶段交互后缓存失效；这直接解释了 Long suite 与 block pyramid（12.0%）、solve puzzle（1.3%）的低分。
- **无法解决高精度多阶段控制难题**：作者承认恢复可见性对精确多阶段任务不够，方法只在“部分可观测是主要瓶颈”时最有效。
- **真实世界评估偏小**：仅 3 个任务、每任务 30 次、单一机器人平台，泛化性证据有限。
- **消融覆盖不全**：消融与敏感性分析集中在 LIBERO-Occ，未在其他 benchmark 或真实场景复现。
- **算力信息缺失**：未报告 GPU 型号/数量/训练时长，削弱可复现性与成本评估。
- **依赖外部世界模型**：核心生成能力来自 WorldStereo，方法本身的贡献边界与外部模型能力的耦合度需进一步厘清。
- **训练非端到端**：顺序训练 + 特征缓存虽高效，但可能限制轨迹预测、世界模型与策略之间的联合优化。
- **潜在偏差风险**：轨迹监督来自演示腕部相机路径，可能继承演示数据的视角/任务分布偏差；虚拟视角生成目标假设场景静止，动态场景下适用性未知。

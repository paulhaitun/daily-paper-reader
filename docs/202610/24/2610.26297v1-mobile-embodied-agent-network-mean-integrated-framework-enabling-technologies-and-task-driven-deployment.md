## 摘要
移动网络正从以人为中心、面向数据的通信基础设施，演进为以机器和/或智能体为主导、面向任务的平台，以服务于快速增长的网络化机器与具身智能体。为完成新出现的复杂任务目标，未来移动网络框架需要创新，以体现并促进感知、通信、计算、决策、行动和反馈等底层过程的内在交互与集成。本综述将移动具身智能体网络（MEAN）确立为一种面向任务的网络范式，其中网络与分布式智能围绕闭环具身任务执行进行联合组织。我们首先建立一个统一的 MEAN 框架，阐释网络资源与智能功能如何共同支持具身任务执行，并将其性能指标从传统通信指标扩展至具身任务结果和跨层系统效应。基于该框架，我们分析三种互补的使能机制，它们构成认知—交互—自适应环路。大型人工智能（AI）模型提供高层认知，令牌通信通过共享语义表示将这种认知与分布式智能体连接起来，强化学习则通过使系统运行适应网络、任务和物理反馈来闭合环路。我们进一步探讨 MEAN 与新兴技术之间的双向相互作用，展示它们如何相互扩展系统能力并重塑面向任务的网络设计。最后，我们讨论在真实联合通信与计算平台上实际实现 MEAN 所面临的开放挑战和未来研究方向。

## Abstract
Mobile networks are evolving from human-centered, data-oriented communication infrastructures toward machine- and/or agent-dominant, task-oriented platforms that are to serve the rapidly increasing networked machines and embodied agents. In order to fulfill the newly arose complex task objectives, the framework of future mobile network is to be innovated to reflect and facilitate the intrinsic interplay and integration of the underlying processes of perception, communication, computation, decision, action, and feedback, etc. This survey establishes the mobile embodied agent network (MEAN) as a task-oriented networking paradigm in which networking and distributed intelligence are jointly organized around closed-loop embodied task execution. We first establish a unified MEAN framework that explains how network resources and intelligent functions jointly support embodied task execution, and extend its performance indicators from conventional communication metrics to embodied task outcomes and cross-layer system effects. With this framework, we analyze three complementary enabling mechanisms that form a cognition-interaction-adaption loop. Large artificial intelligence (AI) models provide high-level cognition, token communication connects this cognition with distributed agents through shared semantic representations, and reinforcement learning closes the loop by adapting system operation to network, task, and physical feedback. We further investigate the bidirectional interplay between MEAN and emerging technologies, showing how they mutually extend system capabilities and reshape task-oriented network design. Finally, we discuss open challenges and future research directions toward the practical realization of MEAN over real joint communication and computation platform.

## 1. 核心问题与整体含义（研究动机与背景）

### 1.1 背景演进
- **网络侧**：5G/5G-A 以增强移动宽带、海量机器通信、超可靠低时延为目标；6G/IMT-2030 则转向“连接智能”，要求网络在动态物理环境中支持**感知—决策—协调—行动**的闭环，而非仅做端到端数据传输。
- **智能侧**：具身 AI 从单智能体（感知与行动）走向基础模型驱动的具身智能（理解与规划），再走向多智能体协作；但真实场景中的具身智能体是**空间分布、资源受限、需在变化网络与物理条件下协同**的，其任务性能取决于网络化协作质量，而非单体智能。

### 1.2 核心问题
论文认为，现有“无线 + AI”研究虽提供了互补基础，但**无法保证对闭环具身任务的连贯支撑**：网络决策决定智能体能否及时获得信息与算力，而智能体的行动又改变物理环境与后续网络需求，二者必须通过持续反馈相互适配。

### 1.3 三个关键差距（论文的核心诊断）
- **范式差距（Paradigm gap）**：现有系统以“交付通信/计算服务”为终点；而对具身智能体，数据或推理结果只是中间步骤，其价值取决于能否在正确时刻促成正确动作，且物理结果须反馈回网络决策。
- **目标差距（Objective gap）**：传统指标（时延、推理精度、能耗）是子系统级指标，独立优化可能相互冲突（如更准的模型更慢，反而降低动作时效性），无法反映任务成败。
- **集成差距（Integration gap）**：通信、感知、计算、智能、控制各自接口、时间尺度与优化目标不同，缺乏**共享的任务状态表示与跨层协调机制**。

### 1.4 整体含义与定位
- 提出 **MEAN（移动具身智能体网络）**：一种面向任务的无线网络范式，将移动具身智能体、无线基础设施、云—边—端智能与物理环境**围绕网络化具身任务执行联合组织**。
- 四大特征：**物理闭环运行、语义交互、任务驱动部署、多智能体协调**。

## 2. 方法论：核心思想与关键技术细节

### 2.1 总体思想
以**“认知—交互—适配”环路**组织网络与分布式智能：
- **认知**：大 AI 模型提供高层推理与规划；
- **交互**：令牌通信以共享语义表示连接分布式智能体；
- **适配**：RL/MARL 依据网络、任务与物理反馈闭合环路。

### 2.2 三层集成框架（图 4）
- **第 1 层：移动具身智能体与无线网络基础（物理层）**
  - 具身组件：传感器、执行器、端侧算力、移动性；
  - 网络：BS/RSU/AP，面临动态拓扑、移动切换、时变信道、干扰、频谱与带宽、时延可靠性约束；
  - 边缘服务器（GPU/TPU）与云数据中心提供异构算力与存储。
- **第 2 层：闭环功能流水线（五大能力）**
  - 感知（多模态感知、状态估计）→ 决策（任务推理、策略生成）→ 协调（多智能体与资源协调）→ 控制（控制分解、实时调整）→ 部署与验证（模型部署、运行时校验），执行结果持续回流影响后续环节。
- **第 3 层：跨层智能与协调（高层）**
  - 统一建模（世界—智能体—任务模型、跨域语义）、任务感知调度（任务分解、资源与路径调度）、跨层自适应、令牌交互、知识与记忆；并由基础模型提供全局语义与高层规划。
- **两个跨层耦合机制**：
  - **令牌导向语义接口**：将任务、智能体、资源、状态抽象为统一 token，桥接物理观测、网络资源与高层推理；
  - **RL 自适应环路**：以任务奖励、环境反馈、能耗、网络 QoS（时延、可靠性）为信号，动态调整通信、计算、协调与控制策略。

### 2.3 三级指标体系（表 II）
- **基础系统指标**
  - 通信：时延、可靠性、吞吐、抖动、PDR、AoI；端到端时延分解为
    \(T_{e2e}=T_{tx}+T_{queue}+T_{proc}+T_{prop}\)（传输+排队+处理+传播）。
  - 计算：推理时延、TTFT、TPOT、token 吞吐、能耗、卸载开销（TTFT/TPOT 刻画大模型响应与生成时延）。
- **具身任务指标**
  - 任务有效性：任务成功率、目标条件成功、任务进度、任务完成时间；其中
    \(GCS=\frac{1}{N}\sum_{i=1}^{N}\frac{|G_i^{done}|}{|G_i|}\)，用于刻画部分完成。
  - 具身与安全：运动平滑性、控制稳定性、碰撞率、安全成功率、约束违反率；其中
    \(SSR=\frac{1}{N}\sum_{i=1}^{N}\mathbb{I}(S_i=1)\mathbb{I}(V_i=0)\)，即“成功且无违规”的联合概率。
- **跨层智能与权衡指标**
  - 可扩展性、互操作性、拓扑韧性、协调鲁棒性、多智能体效率；
  - 任务—资源效率 \(TRE=\frac{TaskScore}{\alpha\bar{T}+\beta\bar{E}+\gamma\bar{B}+\delta\bar{C}}\)，分母为归一化时延、能耗、通信开销与计算成本；
  - 基础模型智能：指令遵循准确率、推理准确率、规划有效性、语义接地准确率、幻觉率、token 效率。

### 2.4 使能技术一：RL 驱动的适配与编排（第 III 节）
- **问题建模**：编排本质是序贯决策问题，需在任务效用与通信、计算、能耗、安全成本间持续权衡；文中给出**约束马尔可夫决策过程（CMDP）**形式化：
  - 目标：\(\max_\pi \mathbb{E}\big[\sum_t \gamma^t r(s_t,a_t)\big]\)；
  - 约束：\(\mathbb{E}\big[\sum_t \gamma^t g_i(s_t,a_t)\big]\le G_i,\ \forall i\in\mathcal{I}\)（时延、能耗、干扰、安全风险等），且 \(a_t\in\mathcal{A}(s_t)\)、\(s_{t+1}\sim P(\cdot|s_t,a_t)\)。
  - 按可观测性与控制粒度可实例化为 MDP、POMDP、HRL（分层解耦任务编排与底层控制）、MARL（分布式协同）。
- **状态空间**：任务状态（进度、优先级、角色、移动性、感知质量、推理置信度、模型新鲜度、安全相关性）+ 网络状态（CSI/SINR、带宽、干扰、队列、时延、可靠性、拓扑）+ 计算资源状态（处理器利用率、边缘可用性、内存、能耗预算）。
- **动作空间（四个耦合维度）**：任务编排（分解、优先级、本地/边缘/云/多智能体协作执行）、任务感知信息交换（传什么、何时传、何种表示/压缩级别）、无线资源管理（频谱、带宽、功率、接入、调度、路由、可靠性等级）、多智能体适配与协调。
- **具体子方向**
  - RL 任务编排：知识图谱辅助的任务分解与依赖图调度、执行模式选择（本地/边缘/云/协作/延迟执行）、角色分配。
  - RL 信息交换：以“信息对任务的贡献”而非数据量衡量价值；覆盖 split learning/模型分割的切分点选择、联邦学习的客户端选择与更新调度、协作推理中原始观测/中间特征/语义摘要/置信度的选择性传输。
  - RL 无线资源管理：DQN/DDQN 处理离散决策（调度、接入、信道、MCS），DDPG/SAC 处理连续变量（功率、带宽），约束/安全 RL 保障硬时延与安全，MARL 支持分布式 AMC 与资源分配。
  - 高级 RL：CTDE 缓解非平稳与信用分配问题；Meta-RL 提升新条件下的快速适应；数字孪生提供虚拟训练与验证环境；安全约束 RL；语义感知 RL 作为通向令牌通信的桥梁。

### 2.5 使能技术二：面向任务的令牌通信（第 IV 节）
- **token 的重定义**：不再只是 LLM 的文本单元，而是具身智能体对物理世界的**语义抽象与通用认知载体**，承载压缩多模态特征、意图指令与任务约束，使通信逻辑从“物理层信号复制”转向“应用层意图对齐”。
- **多模态压缩三机制**
  - **语义瓶颈约束**：受信息瓶颈（IB）理论启发，以任务驱动的信息效用替代 MSE 准则，仅保留决策必需语义（目标类别、相对位姿、动态轨迹），抑制背景与噪声，带宽可降数量级；
  - **跨模态对齐与统一潜在空间**：以 VLM 为底座、用对比学习将视觉/触觉/阵列信号映射到一致 token 空间，实现潜在空间语义不变性，在遮挡等 POMDP 场景下可用 RF/LiDAR token 补全上下文；
  - **自适应量化与剪枝**：AWQ 激活感知权重量化（如 INT4）+ 结构化剪枝，在精度小幅下降下提升传输效率。
- **推理与决策驱动**：任务 token 驱动的 CoT 规划、环境反馈 token 的自反思闭环修正、工具调用（Toolformer 插入 API 调用 token、Gorilla 检索 RESTful API、ReAct 迭代“推理—行动—观察”）。
- **通信范式转变**：从“如何执行（比特）”到“执行什么（意图/token）”，即从 IoT 走向 **IoA（智能体互联网）**；引入 **MCP（模型上下文协议）** 维持低带宽、非平稳条件下的分布式认知一致性。
- **意图接地与任务分解**：多模态时空融合 + 跨注意力实现上下文感知的意图实例化（GLIP、Grounding DINO）；层次任务拓扑构建（含物理可供性评估以抑制幻觉）；**双约束 CoT**（形式逻辑谓词 + 时空约束，发送前做因果与运动学/避碰校验，支持局部 token 节点更新而非全局重规划）；多智能体 token 链（leader 生成路径规划 token 簇，经 RT-2 映射为底层动作 token）。
- **协作推理与上下文共享**：MCP 的增量认知状态更新（prompt caching、跨节点 KV-cache 复用）、共识 token 锚点做语义一致性验证；分布式 RAG（GraphRAG 组织上下文 token 为知识图谱、异步上下文综合、Self-RAG 做忠实性校验）。
- **token 网络指标（三个核心公式）**
  - 任务成功率 \(TSR=\frac{1}{N}\sum_{i=1}^{N}\mathbb{I}(T_i=\text{success})\)

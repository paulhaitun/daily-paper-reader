## 摘要
我们为多核实时系统中数据驱动的动态资源分配建立了一个新的最优控制问题。所提出的模型考虑了硬截止时间约束和资源边界。在温和假设下，我们证明了关于所提出模型可行性和最优解存在性的若干结果。基于这些分析，我们设计了一种求解多核动态资源分配问题的算法。我们通过在真实多核平台上使用文献中的四个基准进行实验评估，展示了这种新算法的实际用途。

## Abstract
We formulate a novel optimal control problem for data-driven dynamic resource allocation in multicore real-time systems. The proposed formulation accounts for hard deadline constraints and resource bounds. Under mild assumptions, we prove several results on the feasibility and existence of optimal solution for the proposed formulation. Building on these analyses, we design an algorithm to solve the multi-core dynamic resource allocation problem. We demonstrate the practical use of this new algorithm by experimentally evaluating it on a real multicore platform using four benchmarks from the literature.

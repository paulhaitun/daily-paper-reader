## 摘要
大规模超级计算系统的高效利用依赖于准确的运行时间估计和 walltime 选择。为避免作业过早终止，用户往往会高估 walltime，从而导致资源利用率下降和调度效率降低。本文提出了一个与预测器无关的框架，用于在生产 HPC 环境中进行安全的 walltime 推荐。本文的主要贡献不是提出新的运行时间预测模型，而是 SAFE 决策层，该层将预测的运行时间转换为适合部署的保守有界 walltime 推荐。因此，运行时间预测被视为所提框架中的一个模块化组件。我们使用来自 Fugaku 和 NREL Eagle 超级计算机的大规模生产作业历史来评估该方法，分别包含约 2400 万和 1100 万个作业。首先使用代表性预测器评估运行时间预测性能，包括线性回归、神经网络和神经网络集成。然后使用 NN 集成预测器评估所提出的 SAFE 框架。实验结果表明，相似性感知预测对于与先前执行相似的工作负载可显著改善运行时间估计。当与所提出的保守 walltime 推荐策略结合时，这些改进可在两个系统上实现约 20%–26% 的 walltime 差距缩减，同时将作业终止率保持在 1% 以下。

## Abstract
Efficient use of large-scale supercomputing systems depends on accurate runtime estimation and walltime selection. To avoid premature termination, users often overestimate walltime, leading to poor resource utilization and reduced scheduling efficiency. This paper presents a predictor-agnostic framework for safe walltime recommendation in production HPC environments. Rather than proposing a new runtime prediction model, the primary contribution is the SAFE decision layer, which converts predicted runtimes into conservative bounded walltime recommendations suitable for deployment. Runtime prediction is therefore treated as a modular component within the proposed framework. We evaluate the approach using large-scale production job histories from the Fugaku and NREL Eagle supercomputers, comprising approximately 24M and 11M jobs, respectively. Runtime prediction performance is first evaluated using representative predictors, including linear regression, neural networks, and a neural ensemble. The proposed SAFE framework is then evaluated using the NN ensemble predictor. Experimental results indicate that similarity-aware prediction substantially improves runtime estimation for workloads similar to previous executions. When combined with the proposed conservative walltime recommendation policies, these improvements enable walltime gap reductions of approximately 20 - 26% while maintaining job termination rates below 1% across both systems.

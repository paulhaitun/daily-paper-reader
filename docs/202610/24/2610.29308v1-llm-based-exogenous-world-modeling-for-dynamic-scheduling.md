## 摘要
动态调度需要在调度在线到达任务的同时预测未来作业，因为在非线性拖期目标下，糟糕的决策会加剧下游成本。我们表明，预训练大语言模型（LLM）可以作为结构化世界模型的外生组件，用于预测不确定的未来作业到达。具体而言，我们利用后状态分解，将已知的确定性车间状态转移与不确定的外生作业到达分离，使LLM能够通过紧凑的信念表示仅预测后者。在此基础上，我们提出后状态世界模型规划（AWMP），它将演化的、以信念为条件的派工策略与基于短场景的推演相结合。一种由惊奇触发的刷新机制仅在新观测到的到达与先前预测偏离足够大时查询LLM，而在线残差自校准进一步使LLM以其近期预测误差为条件，以处理非平稳到达。在多样化的到达分布下，相较于八种经典优先级派工规则中的最佳者，AWMP在动态作业车间基准上将加权拖期降低6-21%，在柔性作业车间基准上降低22-46%。

## Abstract
Dynamic scheduling requires dispatching online arrivals while anticipating future jobs, as poor decisions can compound downstream costs under nonlinear tardiness objectives. We show that a pretrained large language model (LLM) can serve as the exogenous component of a structured world model, forecasting uncertain future job arrivals. Specifically, we exploit an afterstate decomposition, which separates known deterministic shop transitions from uncertain exogenous job arrivals, enabling the LLM to forecast only the latter through a compact belief representation. Building on this, we develop Afterstate World-Model Planning (AWMP), which combines an evolved, belief-conditioned dispatching strategy with short scenario-based rollouts. A surprise-triggered refresh mechanism queries the LLM only when newly observed arrivals deviate sufficiently from previous forecast, and online residual self-calibration further conditions the LLM on its recent forecast errors to handle nonstationary arrivals. Across diverse arrival distributions, AWMP reduces weighted tardiness by 6-21% on dynamic job-shop and 22-46% on flexible job-shop benchmarks, relative to the best of eight classical priority-dispatching rules.

## 1. 核心问题与研究动机

- **背景**：动态调度中，新作业在机器已加工既有工件的过程中持续在线到达，调度器必须在未知未来工作负载的情况下反复派工。经典调度假设所有作业预先已知，这与真实制造系统不符。
- **目标函数带来的挑战**：总加权拖期（total weighted tardiness）是非线性目标——到期日前无成本，逾期后惩罚持续增长。这形成尖锐的到期日阈值：一个局部看似有利的派工决策可能占用关键机器产能，使后续高优先级作业逾期，产生不成比例的下游惩罚。
- **核心需求**：有效的动态调度不能只对当前可加工工序做反应，还必须预判未来到达如何改变车间拥堵，并将这种预期纳入决策。
- **现有方法的三类局限**：
  - **经典优先派工规则（PDRs）**（WSPT、ATC 等）：快速、免训练，但只对当前可用工序排序，没有未来到达的显式表示。
  - **前瞻优化方法**（滚动时域重规划、SAA、MSA）：依赖预设随机模型的保真度，重复重优化代价高昂。
  - **神经调度方法**：从模拟轨迹学习策略，但将外生到达过程与派工决策纠缠，需任务/分布特定训练，分布变化即需重训练。
- **研究意义**：作者希望构建一种前瞻调度器，能从观测到的到达历史中推断未来到达压力，不预设参数化随机模型，且无需大量重训练或重优化。

## 2. 方法论

### 2.1 核心思想：Afterstate 分解

- 将调度动态拆为两部分：**已知确定性的车间内生动量**与**不确定的外生作业到达**。
- 动作 $a_t$ 作用于状态 $s_t$ 产生 **afterstate** $\sigma_t = T(s_t, a_t)$，$T$ 为已知的动作到 afterstate 转移，涵盖机器可用性、工序进度、优先级状态及 FJSP 中的机器选择。
- 未来到达 $Z_t = \{(\rho_j, \zeta_j): \rho_j > c_t\} \sim P_\beta(\cdot|h_t)$ 为外生过程，派工动作不影响其到达。
- 下一状态由已知事件推进函数 $g$ 给出：$s_{t+1} = g(\sigma_t, Z_t)$。
- **关键推论**：$T$ 与 $g$ 无需学习，唯一未知是条件到达过程 $P_\beta(\cdot|h_t)$。由此形成“LLM 外生预测器 + 确定性调度模拟器”的结构化世界模型。

### 2.2 LLM 外生世界建模：紧凑到达信念

- 不预测完整到达流（精确释放时间与作业属性），而是预测一个**低维、决策相关的信念**。
- 将预测时域 $H_p$ 分为早、晚两个区间：$I^{early}_t=[c_t, c_t+H_p/2)$，$I^{late}_t=[c_t+H_p/2, c_t+H_p]$。
- LLM 输入观测到达历史 $h_t$ 与残差校准记录 $C_t$，输出：
  $$b_t = \phi(h_t, C_t) = (\hat{n}^{early}_t, \hat{n}^{late}_t)$$
  即两个区间内的预测到达作业数。
- 信念有两个用途：直接条件化评分/价值函数；通过固定场景生成器转化为具体 rollout 场景。

### 2.3 在线残差自校准

- 维护最近 $L$ 个预测时域已完全结束的预测–结果记录：$C_t = \{(n_i, \hat{n}_i): c_i+H_p \le c_t\}$。
- 计算平均符号残差 $e_t = \sum_{(n_i,\hat{n}_i)\in C_t}(n_i-\hat{n}_i)/|C_t|$；正值表示低估，负值表示高估。
- 当 $|e_t|$ 超过校准阈值时，在后续 prompt 中显式指示 LLM 校正该偏差。
- **LLM 保持冻结**，仅通过 prompt 级闭环反馈实现非平稳到达下的在线适应，无梯度或参数更新。

### 2.4 AWMP：信念条件 Afterstate 规划器

- 规划策略参数化为紧凑对象：$\Theta = \{r(\cdot), v(\cdot), K, d, n, \tau\}$，其中 $r$ 为候选动作评分规则，$v$ 为终端状态价值估计，$K$ 为保留候选数，$d$ 为 rollout 深度，$n$ 为场景数，$\tau$ 为惊奇阈值。
- **候选筛选**：对每个可行动作计算 $r(\sigma_t, b_t)$，保留 Top-$K$ 动作（式 9），相当于以 afterstate 和到达信念为条件的粗粒度 PDR。
- **场景生成**：固定、非学习的生成器 $\tilde{Z}^{(m)}_t = \Gamma(b_t, h_t, \omega_m)$，将预测的早/晚到达数分配到对应区间并采样释放时间，其余作业属性从评估前固定的参考分布抽取。
- **短 rollout 评估**：每个候选在 $n$ 个场景下模拟 $d$ 步，首步固定为候选动作，后续用 $r$ 选择；评估值为 rollout 累积目标成本加终端价值 $v(s^{(m,a_t)}_{t+d}, b^{(m)}_{t,d})$，取 $n$ 场景平均最优者派工。
- **步内与跨步信念复用**：
  - 步内共享根信念 $b_t$，LLM 调用从 $O(Knd)$ 降至每决策步最多 1 次。
  - 跨步复用：减去新观测到达得到残差信念；仅当累积观测到达与缓存信念隐含值偏差超过 $\tau$，或预测时域不再覆盖规划前瞻时触发刷新（惊奇触发刷新）。
  - 步内共享是精确的；跨步复用是有意近似。

### 2.5 元进化（离线策略发现）

- 以 LLM 驱动的元进化循环维护策略种群，通过选择、交叉、多点变异及停滞重启生成新策略。
- 提议 LLM 仅修改策略对象 $\Theta$（评分规则、价值估计器、rollout 参数、刷新阈值），并受安全约束 $K\le6, d\le3, n\le8$ 与结构 schema 限制，保持策略紧凑、可执行、人类可读。
- 适应度为目标加权拖期，实例级成本在对数域聚合以降低大成本实例主导。
- 预测 prompt 与场景生成器 $\Gamma$ 在进化与评估中保持固定；进化后最优策略冻结用于留出评估。

## 3. 实验设计

### 3.1 数据集 / 场景

- **动态 JSSP**：基于 80 个 Taillard 标准实例构造。
- **动态 FJSP**：基于 15 个 Brandimarte 与 66 个 Hurink 实例构造。
- 保留原始车间配置与加工数据（工序优先关系、加工时间、机器适用性），作业按四种外生到达分布在线释放：
  - **Pulse train**：4 个等距突发中心 + 高斯时间抖动。
  - **Late-ramp**：到达率单调递增，期望归一化释放时间约 2/3。
  - **Cyclic**：两个正弦周期，$\lambda(t)=\lambda_0(1+0.9\sin(4\pi t/H_{arr}))$。
  - **Step-up**：前半段释放 1/3 作业，后半段释放 2/3，中点到达率翻倍。
- 到达强度 $\beta$ 缩放，调度时域相对基准放大 5 倍以避免平凡实例。

- **总加权拖期**：$Cost=\sum_j w_j\max(0,\tilde{C}_j-d_j)$，其中 $d_j=\rho_j+\mu p_j$，$w_j=p_j/\bar{p}$；未完成作业赋 $\tilde{C}_j=H$ 计入终端惩罚。

## 4. 主要实验结果与发现

### 4.1 主实验：跨车间类型与到达分布的稳健优势

- AWMP 在 8 个“车间–分布”组合上总体取得最低或接近最低的总加权拖期，且优势在**非平稳、突发型**到达（Pulse train、Step-up）下最为明显——这类分布恰恰是“只看当前工序”的 PDR 与依赖平稳随机模型的前瞻方法最容易失效的情形。
- 经典 PDR 中 ATC/COVERT 表现相对最好，但在到达率突变或后段爬升（Late-ramp、Step-up）时明显退化，说明仅凭到期日松紧度排序无法预判拥堵演化。
- 优化型在线调度器（Myopic、Rolling-horizon、MSA、SAA、EV）在计算预算不低于 AWMP 的条件下仍未稳定胜出：其性能高度依赖内置随机模型对真实到达过程的拟合程度，模型失配时前瞻反而引入系统性偏差；且重复重优化带来的开销未能转化为相应收益。
- AWMP 的优势在 FJSP 上依然成立，表明 afterstate 分解对“机器选择”这一额外决策维度具有兼容性，方法并非仅针对 JSSP 特化。

### 4.2 残差自校准的作用

- 无校准的 LLM 预测在分布漂移（尤其 Step-up 的中点突变、Late-ramp 的持续爬升）后出现系统性低估或高估，预测值与实际到达数的相关性下降。
- 启用残差自校准后，符号残差被 prompt 级反馈抑制，预测相关性回升，下游总加权拖期相应改善；且校准在**冻结 LLM** 前提下完成，验证了“prompt 级闭环”可作为轻量在线适应的可行路径。
- 校准的收益主要集中在分布非平稳段，平稳段收益有限，符合该方法“纠偏而非提升精度上限”的设计定位。

### 4.3 LLM 调用效率

- 朴素逐 rollout 查询的调用量为 $O(Knd)$ 量级，开销不可接受；步内共享根信念将其降至每决策步至多 1 次，且该共享是**精确的**（同一决策步内所有候选与场景共享同一到达信念）。
- 跨步复用 + 惊奇触发刷新进一步大幅削减调用，仅在观测到达显著偏离缓存信念或预测时域不再覆盖前瞻时刷新；该复用是**有意的近似**，实验显示其带来的目标损失很小，而调用次数显著下降。
- 总体而言，方法把“LLM 推理”从逐步在线查询转变为**低频、事件驱动**的信念更新，使 LLM 开销与决策步数解耦。

### 4.4 元进化的价值与泛化

- 进化所得策略在训练实例上优于种子策略，并在留出实例上保持增益，说明元进化学到的是可迁移的策略结构（评分规则形式、rollout 深度、场景数与刷新阈值），而非对特定实例的记忆。
- 安全约束（$K\le6, d\le3, n\le8$）与 schema 限制使进化搜索保持在紧凑、可执行、人类可读的策略空间内，避免退化为不可解释的黑箱。
- 由于预测 prompt 与场景生成器 $\Gamma$ 在进化与评估中固定，进化收益可归因于**规划策略**而非预测器，实验归因较为干净。

### 4.5 机制消融

- **Afterstate 分解**是结构性前提：去掉后，学习负担从“仅外生到达”扩展到“内生动力学 + 外生到达”，样本效率与稳定性均下降。
- **到达信念条件化**：以 $b_t$ 条件化评分与价值，使前瞻具有方向性；不使用信念的版本在多场景 rollout 中退化为近似无偏的短视评估。
- **短 rollout + 终端价值**：$d$ 过小接近贪心、过大则场景噪声累积；实验支持在 $d\le3$ 的短视界配合终端价值估计即可获得大部分收益。

## 5. 贡献与创新点

1. **问题重构**：将动态调度世界模型拆分为“已知确定性内生转移 + 待学外生到达过程”，把学习问题压缩到唯一真正未知的部分，显著降低对数据与重训练的依赖。
2. **紧凑信念而非完整轨迹预测**：LLM 只输出早/晚两区间的到达计数，回避了精确预测释放时间与作业属性的高方差难题，同时保留决策相关性。
3. **冻结 LLM 的在线适应**：以残差记录驱动的 prompt 级校准实现非平稳到达下的闭环纠偏，无需梯度更新或参数微调。
4. **信念条件 afterstate 规划器（AWMP）**：把信念同时用于候选评分与场景生成，配合步内精确共享与跨步惊奇刷新，将 LLM 调用降至事件驱动级别。
5. **LLM 驱动的元进化**：在受约束的紧凑策略空间内离线搜索规划策略，兼顾性能、可解释性与可执行性。
6. **系统性实证**：在动态 JSSP 与 FJSP、四类外生到达分布上，与 8 种 PDR 及 5 种优化型在线调度器在同等或更高计算预算下对比，并配套校准、效率、进化与机制消融实验。

## 6. 局限与未来工作

- **信念维度受限**：仅预测早/晚到达计数，丢弃了到达作业的权重、加工时间与机器适用性等结构信息；当到达流的**构成**（而非数量）发生漂移时，信念可能不足以支撑决策。
- **场景生成器为固定启发式**：$\Gamma$ 将计数分配到区间并从参考分布采样属性，若真实属性分布偏移，rollout 评估会存在偏差。
- **跨步复用为近似**：惊奇阈值 $\tau$ 的设定在“调用节省”与“信念时效”之间权衡，缺乏自适应机制。
- **评估范围**：实验基于标准实例改造的合成到达过程，真实车间的到达相关性（如订单族、批量关联）未被建模。
- **可扩展性**：多机器、多目标（如同时考虑拖期与能耗/换型）场景下的策略对象与进化搜索空间需要重新设计。
- 未来方向可包括：将信念扩展到到达构成（权重/工时分布）、学习型场景生成器、自适应刷新策略，以及把该方法与既有神经调度策略做互补式结合。

## 7. 结论

论文提出一种“LLM 外生世界模型 + 确定性调度模拟器”的结构化世界建模框架：通过 afterstate 分解把不确定性隔离到外生到达过程，用冻结 LLM 输出低维到达信念并以残差自校准实现无梯度的在线适应，再由信念条件 afterstate 规划器在短 rollout 中评估候选动作，配合步内共享与惊奇触发刷新控制 LLM 开销，最后以元进化在受约束空间内发现规划策略。实验表明该方法在动态 JSSP 与 FJSP 的多种非平稳到达分布下总体优于经典 PDR 与同等预算的优化型在线调度器，且各机制组件均有可辨识的独立贡献。

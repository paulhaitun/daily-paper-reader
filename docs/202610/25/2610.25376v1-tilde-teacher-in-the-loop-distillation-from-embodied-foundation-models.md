## 摘要
大规模动作预训练使具身基础模型（EFMs）具备强大的操作能力，尤其在泛化和闭环鲁棒性方面表现突出，但复现此类预训练需要大量机器人数据和计算资源。为了将这些能力从预训练的EFMs迁移到未经动作预训练的策略，我们提出TILDE（Teacher-In-the-Loop Distillation from EFMs），它将学生诱导状态下的同策略蒸馏与从教师执行的恢复轨迹中学习相结合。我们进一步提出AutoDAgger，一种自主数据聚合流程，其中利用机器人奖励模型监测任务进度并触发教师干预，从而在无需人工监控或手动控制的情况下收集恢复经验。相比人类在环方法，AutoDAgger将恢复轨迹的收集速度提升超过2倍。通过统一从示范中学习、同策略教师监督和教师纠正行为，TILDE在三个真实世界任务上将任务性能较行为克隆提升至多4.1倍，并支持有效的跨架构蒸馏。

## Abstract
Large-scale action pretraining equips Embodied Foundation Models (EFMs) with strong manipulation capabilities, with particular strengths in generalization and closed-loop robustness, but reproducing such pretraining requires substantial robot data and computation. To transfer these capabilities from pretrained EFMs to policies without action pretraining, we introduce TILDE (Teacher-In-the-Loop Distillation from EFMs), which synergizes on-policy distillation at student-induced states with learning from teacher-executed recovery trajectories. We further propose AutoDAgger, an autonomous data aggregation pipeline in which a robotic reward model is utilized to monitor task progress and trigger teacher intervention, thereby collecting recovery experience without human monitoring or manual control. AutoDAgger accelerates recovery-trajectory collection by more than $2\times$ compared with the human-in-the-loop method. By unifying learning from demonstrations, on-policy teacher supervision, and teacher's corrective behavior, TILDE improves task performance by up to $4.1\times$ over behavior cloning across three real-world tasks and supports effective cross-architecture distillation.

## 2. 方法论

### 2.1 总体框架

- **教师 π_T**：由预训练 EFM（π0.5）在目标任务人类示范上微调得到，之后**冻结**。
- **学生 π_S**：从预训练 VLM 骨干（π0.5 用 PaliGemma）初始化，动作专家**从头训练**，即无任何机器人动作预训练；先在示范上做行为克隆。
- **两阶段流程**：
  1. **AutoDAgger 数据采集**：学生执行任务 → 任务监视器估计进度/成功率 → 执行管理器判定失败 → 教师接管执行恢复 → 仅保留“确认成功恢复”的回合，与学生前段 rollout 拼接为组合轨迹入库；
  2. **动作蒸馏**：按样本来源施加不同监督（BC + 教师蒸馏）。

### 2.2 AutoDAgger：自主教师接管数据聚合

- **任务监视器**：使用现成机器人奖励模型 **Robometer**（不做任务特定微调），作为与策略无关的监视器。
  - 维护容量 `N_frame = 8` 的有界视觉历史缓冲（超限则等间隔下采样）；监视请求最小间隔 `τ_mon = 1s`，异步提交、不阻塞策略推理。
  - 输入缓冲观测 `o_{1:K_t}` 与语言指令 `l`，输出任务进度与成功率序列 `(p̂, q̂)`，取最新值并裁剪到 [0,1]，得到 `p_t`、`q_t`。
- **失败判定（执行管理器）**：
  - 设参考进度 `p̄_t`，仅当 `p_t > p̄_{t-1} + ε_p`（`ε_p = 0.05`）时更新，并记有效进展指示 `g_t = 1`，避免把进度小波动误判为推进。
  - “有效执行时间戳” `τ^valid_t`：当 `g_t = 1` 或 `q_t > θ_s`（`θ_s = 0.5`）时刷新，否则保持不变。
  - 失败条件：距上次有效执行的时间 `Δt = τ_t − τ^valid_t ≥ T_fail` **且** `q_t ≤ θ_s`。
  - 触发后立即停机、清空动作缓冲与观测窗口（防止残留学生动作被执行），控制权交给教师；教师侧使用独立的监视状态与阈值重新计时。
- **成功确认与数据筛选**：
  - 连续 `q_t > θ_s` 持续至少 `T_succ` 才判定成功；任一次 `q_t ≤ θ_s` 重置计时器（抑制瞬时尖峰造成的误判）。
  - 教师恢复失败 → 丢弃该回合；学生自己成功完成的回合也丢弃（AutoDAgger 只针对恢复数据）。
  - 阈值按任务与策略分别设置（如 Fold Dishcloth 学生 `T_fail=6s`、教师 `14s`；Pick Pen 3s/8s；Pick Beverage 2s/6s；`T_succ` 为 4–5s）：学生用较短超时以尽早干预，教师用较长超时以留出恢复时间。

### 2.3 蒸馏目标

- **动作空间蒸馏**（不做内部表征对齐）：
  `L_KD(s,l) = ℓ_S(s, l; sg[A_T])`，其中 `A_T = π_T(s,l)` 为教师预测动作块，`sg[·]` 停止梯度，`ℓ_S` 为学生原有的动作生成损失（同架构时对齐 flow-matching 速度预测并共享噪声；异构时用教师完整去噪动作作为监督目标）。
- **按来源选择损失**：
  - 示范 `D_demo` 与恢复轨迹 `D_rec`（有真实执行动作 `A_E`）：`L_exec = ℓ_S(s,l; A_E) + λ_KD · L_KD`；
  - 学生 rollout 状态 `D_roll`（无可靠执行动作标签）：`L_roll = λ_KD · L_KD`。
  - 全实验统一 `λ_KD = 1`，训练时从合并数据集随机采样、不做数据集平衡。
- **三类分布的分工**：示范 → 域内专家行为；学生 rollout → 学生诱导状态上的教师纠正；恢复轨迹 → 执行教师纠正后所产生的后续状态分布（这是相对 OPD 的关键增量）。

## 3. 实验设计

### 3.1 真实机器人场景

- **硬件**：AgileX PiperX 双臂平台（ALOHA 式 leader–follower），4 条 7-DoF 臂（6 关节 + 1 夹爪），1 个前置 RealSense D455 + 2 个腕部 D435。
- **任务与数据**：
  - Fold Dishcloth（可变形物体折叠，200 条示范，12 次测试）；
  - Pick Pen（精确抓取 1–3 支笔放入杯中，100 条示范，27 次测试）；
  - Pick Beverage（跨物体/位置泛化，100 条示范，30 次测试）。
- **评测指标**：任务分解为语义阶段，每阶段 0 / 0.5 / 1 打分（失败 / 多次尝试或部分恢复 / 一次成功含即时纠错），阶段与回合平均后 ×100 作为 Score；另报告完整成功率 SR。固定物体类别、位置与朝向的预定义测试用例。
- **对比方法**：BC、Offline Distillation、OPD、Recovery BC、Recovery Distill、TILDE，以及教师上界；数据采集侧对比 **HG-DAgger**（人类在环）。
- **专项评测**：Fold Dishcloth 上构造 **12 个标准化错误状态**测恢复成功率；AutoDAgger 数据量缩放（0/30/60/90 回合）；同数量额外人类示范 vs AutoDAgger 数据（各 +30 回合）。

### 3.2 仿真 benchmark

- **LIBERO** 四个 suite（Spatial / Object / Goal / 10-Long），四套联合训练一个策略，每任务 50 次 rollout；数据集用 OpenVLA 发布的 LIBERO 数据（转 LeRobot 格式）与 X-VLA 的 HDF5 格式。
- **LIBERO-Plus**：Background（1,076 个任务实例）与 Robot（1,550 个实例）扰动设置，用仅在原始 LIBERO 上训练的 checkpoint 评测 OOD 泛化。
- **跨架构蒸馏**：教师 π0.5 → 学生 **SmolVLA**（无动作预训练），在 LIBERO 上验证。
- **监视器验证**：每个 suite 采集 200 条 SmolVLA rollout，用模拟器真值评估 Precision / Recall / F1；真实世界另用 20 条 rollout（10 成功 / 10 失败）评估。

## 6. 主要结论与发现

- **主结果**：TILDE 在 Fold Dishcloth / Pick Pen / Pick Beverage 上得分为 63.9 / 80.6 / 69.2，分别为 BC 基线（20.8 / 37.0 / 16.7）的 **3.07× / 2.18× / 4.14×**，并在三个任务上全面优于离线蒸馏与 OPD，显著缩小学生–教师差距（教师 87.5 / 87.0 / 79.2）。
- **恢复能力**：12 个标准化错误状态上，BC 4/12、离线蒸馏与 OPD 各 5/12、TILDE 8/12、教师 9/12 —— 说明“执行教师纠正并学习其后续状态”确实迁移了纠错能力。

，而非单纯的示范密度提升。
- **相对 HG-DAgger**：在同等蒸馏设置下，AutoDAgger 与人类在环数据采集效果相当或更优，同时把人类从持续监控与遥操作接管中解放出来；论文报告 AutoDAgger 的单次恢复耗时与恢复成功率具有竞争力，且数据可自动化规模复制，突破了人类监督带宽瓶颈。
- **仿真结果**：在 LIBERO 四个 suite 联合训练下，TILDE 相对 BC 与 OPD 均有提升，在长程（10-Long）与扰动设置上收益更明显；LIBERO-Plus 的 Background / Robot 扰动评测中，TILDE 显著优于 BC 与离线蒸馏，说明蒸馏迁移的是**分布外闭环鲁棒性**而非仅拟合示范动作。
- **跨架构蒸馏**：教师 π0.5 → 学生 SmolVLA（无动作预训练）在 LIBERO 上同样有效，表明方法不依赖师生同架构，动作空间蒸馏可作为通用能力迁移接口。
- **监视器可靠性**：Robometer 在 LIBERO 各 suite 与真实世界 rollout 上取得较高 Precision / Recall / F1，为“何时接管”提供了与策略无关的自动化判据；真实世界 20 条 rollout 的评估进一步支持其在部署条件下的可用性。
- **机制解释**：消融显示增益主要来自“恢复轨迹”这一新增分布——仅加 OPD（学生诱导状态上的教师动作）不足以复现 TILDE 的恢复能力，必须**执行**教师纠正并学习纠正之后的后续状态，才能把教师“从错误中拉回并继续完成任务”的闭环行为迁移给学生。

## 7. 局限性与潜在问题

- **统计功效有限**：真实世界每任务 12–30 次试验，bootstrap 置信区间较宽，部分方法间差异处于噪声范围内；结论的稳健性依赖仿真上的大规模评测补充。
- **单轮采集、非迭代**：仅做一轮 AutoDAgger，未采用经典 DAgger 的迭代聚合（多轮“学生 rollout → 教师接管 → 再训练”），而数据缩放实验提示迭代可能带来额外收益，这一点未被验证。
- **监视器依赖与误差传播**：失败/成功判定完全依赖 Robometer 的进度与成功率估计；若监视器误判（过早接管或漏判失败），会直接影响数据质量与训练信号，论文未给出监视器误差的敏感性分析或与真值判定的一致性下界。
- **阈值手工设定**：`T_fail`、`T_succ`、`ε_p`、`θ_s` 按任务与策略分别调参，跨任务迁移时需重新标定，增加了部署成本，论文未讨论自动标定方案。
- **平台与任务覆盖有限**：仅一个双臂平台（AgileX PiperX）、三个真实任务，未覆盖移动操作、多物体长程装配等更复杂场景；跨架构实验只在仿真进行，真实机器人上的异构学生蒸馏未被验证。
- **基线范围**：未与强化学习微调（如 RL 微调 VLA）、其他策略压缩/蒸馏方法、或“教师在线查询但不执行”的更强 OPD 变体比较，难以判断相对同类方法的边际优势。
- **成本核算不完整**：未系统报告教师微调、AutoDAgger 采集总机时与总 GPU 小时，难以评估“避免动作预训练”的实际成本节省幅度。

## 8. 启示与可拓展方向

- **把蒸馏视为分布覆盖问题**是本文最有价值的视角：学生需要在“示范分布 + 学生诱导分布 + 失败恢复分布”三类状态上获得监督，这一框架可直接推广到其他“昂贵基础模型 → 廉价部署策略”的能力迁移场景（如导航、灵巧手、多模态 agent）。
- **自动化替代人类在环**的思路可进一步扩展：用奖励模型/世界模型/失败检测器构成“自动接管器”，把 HG-DAgger 式的交互式模仿学习规模化；未来可探索多轮迭代 AutoDAgger、主动选择高价值失败状态、以及监视器与策略的联合校准。
- **动作空间蒸馏 + 停止梯度**的简洁设计表明，能力迁移不必依赖内部表征对齐，异构架构间也可通过动作监督接口衔接，为“大教师 → 小/实时学生”的实际部署提供低成本路径。
- **评测方法学**：论文专门构造标准化错误状态来检验恢复能力，这种“针对声称机制设计评测”的做法值得借鉴；但真实世界试验规模偏小的问题也提示，具身研究需要更严格的统计设计与更大规模的多任务评测。

---

## 9. 总体评价

TILDE 针对一个真实且重要的问题——**如何低成本复用已预训练具身基础模型的闭环鲁棒性**——提出了清晰、可落地的方案：以与策略无关的任务监视器自动判定失败，由冻结教师接管执行恢复，仅保留成功恢复的回合，再按数据来源施加 BC 与动作蒸馏的混合监督。其核心洞见（必须执行教师纠正并学习其后续状态，才能迁移纠错能力）在消融与专门的恢复评测中得到一致支持，真实与仿真实验均显示相对 BC、离线蒸馏、OPD 的显著提升，跨架构实验进一步表明方法的通用性。方法工程实现完整（异步监视、动作缓冲清空、成功确认防抖等细节考虑周到），写作与实验组织清晰。主要不足在于真实世界样本量小、仅单轮采集、监视器误差未做敏感性分析、平台与基线覆盖有限、成本核算不完整。总体而言，这是一篇问题定位准确、机制解释扎实、工程可复现性较好的具身策略蒸馏工作，其“分布覆盖 + 自动化教师接管”的框架具有较好的推广价值。

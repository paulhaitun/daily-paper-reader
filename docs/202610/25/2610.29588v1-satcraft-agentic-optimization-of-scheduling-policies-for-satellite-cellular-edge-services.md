## 摘要
移动边缘服务可将本地计算与卫星和蜂窝接入相结合，在地面覆盖间歇性存在的区域提供时延敏感的结果。为满足其截止时间和质量要求，需要联合计算与传输调度，并考虑任务依赖、链路容量变化和共享资源预算。然而，在固定策略结构内优化资源分配或调参，对于纠正源于调度逻辑的故障作用有限。我们提出 SatCraft，一个框架，其中大语言模型（LLM）智能体利用执行反馈来修订联合调度策略的代码。每次修订都要经过策略检查和完整运行评估，以评估其有效性、运行时以及对服务完成的影响。由于策略性能随接入条件变化，SatCraft 将有效备选策略保留在策略库中，并利用初始接入观测和已知资源配置为每个回合选择一个策略。使用 Starlink 和蜂窝测量数据的实验表明，SatCraft 相比基线将累计完成服务价值提高了 3.61%-16.89%，基线包括近期最先进的调度方法 ADPRL、EdgeOPT 和 TF-DDRL。它在所有四种资源配置下均取得最高的完成服务价值，并且每次调度调用平均耗时 25.02 ms。这些结果展示了 LLM 引导的策略优化如何在卫星-蜂窝网络的计算、通信和质量约束下改善完整服务交付。

## Abstract
Mobile edge services can combine local computation with satellite and cellular access to deliver time-sensitive results in areas with intermittent terrestrial coverage. Meeting their deadlines and quality requirements calls for joint computation and transmission scheduling that accounts for task dependencies, changing link capacity, and shared resource budgets. However, optimizing resource allocations or tuning parameters within a fixed policy structure offers limited scope to correct failures rooted in the scheduling logic. We propose SatCraft, a framework in which a large language model (LLM) agent uses execution feedback to revise the code of joint scheduling policies. Each revision undergoes policy checks and complete-run evaluation to assess its validity, runtime, and effects on service completion. Because policy performance varies with access conditions, SatCraft retains valid alternatives in a policy library and selects one for each episode using initial access observations and the known resource configuration. Experiments using Starlink and cellular measurement data show that SatCraft improves cumulative completed-service value by 3.61%-16.89% over baselines, including recent state-of-the-art scheduling methods ADPRL, EdgeOPT, and TF-DDRL. It achieves the highest completed-service value in all four resource profiles and averages 25.02 ms per scheduling call. These results demonstrate how LLM-guided policy optimization can improve complete service delivery under the computing, communication, and quality constraints of satellite-cellular networks.

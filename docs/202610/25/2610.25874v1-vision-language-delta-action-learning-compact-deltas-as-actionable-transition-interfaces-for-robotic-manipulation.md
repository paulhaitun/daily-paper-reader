## 摘要
机器人操作不仅仅是观测到动作的生成，而是在物理世界中实现任务指定的状态变化。现有视觉-语言-动作（VLA）方法直接学习观测到动作的映射，由于语义理解与动作执行之间存在鸿沟，带来了沉重的学习负担。尽管世界-动作模型（WAMs）通过未来预测改善控制，但对完整未来状态建模会将容量浪费在静态外观和与动作无关的变化上。我们提出 Vision-Language-Delta-Action（VLDA），一种将完整未来预测重新表述为紧凑可执行过渡建模的范式。其核心是一个紧凑的 Delta 变量，用于捕获潜在的世界状态变化，并作为视觉-语言理解与动作生成之间的接口。VLDA 通过由局部过渡滤波器（LT-Filter）和全局过渡锚点（GT-Anchor）组成的统一目标来学习 Delta。LT-Filter 捕获任务相关、以操作为中心的变化，同时抑制静态重建偏差。GT-Anchor 提供粗粒度的未来级正则化，以保持状态变化的整体方向。Delta 驱动的动作细化（DDAR）进一步将 Delta 对齐到动作流形，并将其作为结构化种子注入以引导动作去噪。我们在 LoongForge 中实现 VLDA；LoongForge 是面向大规模基础模型与具身模型的开源训练框架，利用其模块化与分布式基础设施进行统一的两阶段优化。实验表明，VLDA 提升了长时程一致性、鲁棒性和泛化能力，验证了可执行 Delta 可作为直接动作预测与完整未来状态建模的替代方案。

## Abstract
Robotic manipulation is not merely observation-to-action generation, but the realization of task-specified state changes in the physical world. Existing vision-language-action (VLA) methods directly learn observation-to-action mappings, imposing a substantial learning burden due to the gap between semantic understanding and action execution. Although world-action models (WAMs) improve control through future prediction, modeling complete future states wastes capacity on static appearance and action-irrelevant changes. We propose Vision-Language-Delta-Action (VLDA), a paradigm that reformulates full future prediction as compact actionable transition modeling. Its core is a compact Delta variable that captures latent world-state changes, serving as an interface between vision-language understanding and action generation. VLDA learns Delta through a unified objective composed of the Local Transition Filter (LT-Filter) and Global Transition Anchor (GT-Anchor). LT-Filter captures task-relevant manipulation-centric changes while suppressing static reconstruction biases. GT-Anchor provides coarse future-level regularization to preserve the overall direction of state changes. Delta-Driven Action Refinement (DDAR) further grounds Delta in the action manifold and injects it as a structured seed to guide action denoising. We implement VLDA within LoongForge, an open-source training framework for large-scale foundation and embodied models, using its modular and distributed infrastructure for unified two-stage optimization. Experiments show that VLDA improves long-horizon consistency, robustness, and generalization, validating actionable Delta as an alternative to direct action prediction and full future-state modeling.

## 1. 核心问题与研究动机

- **背景判断**：机器人操作的本质是"在物理世界中实现任务指定的状态变化"，而不是简单的"观测→动作"映射。
- **VLA 的困境**：现有视觉-语言-动作模型（OpenVLA、π0、π0.5 等）直接学习观测到动作的端到端映射，迫使单一策略同时完成三件事——任务接地（识别目标物体）、推断期望的物理状态变化、生成可执行动作块。语义理解与底层执行之间存在巨大的表征鸿沟，长程任务尤其难以优化。
- **WAM 的不足**：世界-动作模型通过预测未来观测、视觉隐变量或动作条件动力学来提供时序线索，但：
  - 完整未来状态中大量内容是静态外观与动作无关的变化，容量被浪费；
  - 未来预测多作为辅助目标或上游上下文，缺乏一个**结构化、可直接消费**的中间变量来指导动作生成。
- **核心诉求**：需要一个兼具**选择性**（只保留以操作为中心的任务相关变化）、**预测性**（与未来演化整体方向一致）、**可执行性**（能被动作生成器直接使用）的"过渡接口"。

## 2. 方法论

### 2.1 总体范式

- 将动作生成因子化为"理解–过渡–执行"三段：
  \[
  p(A_t\mid s_t,l)=\int p_\theta(\Delta_t\mid h_t)\,p_\phi(A_t\mid h_t,\Delta_t)\,d\Delta_t
  \]
  其中 \(h_t=\Phi_{\text{VLM}}(s_t,l)\)，\(\Delta_t\) 为紧凑的低维 Delta（潜世界状态变化），\(p_\theta\) 为 World Expert，\(p_\phi\) 为 Action Expert。
- Delta 用连续时间 flow matching 建模，采用 **x-prediction** 参数化（受"自然数据位于低维流形"观点启发），速度由 \(\hat u_\tau=(\Delta_\tau-\hat\Delta_t)/\tau\) 解析恢复。

### 2.2 Local Transition Filter（LT-Filter）

- 用 V-JEPA 2 的**在线编码器** \(E_{on}\) 编码当前帧、**EMA 教师编码器** \(E_{ema}\) 编码未来帧（未来分支 stop-gradient），得到稠密特征差 \(D_t=\bar V_{t+H}-V_t\)。
- 按 \(\ell_2\) 范数选 **Top-K** 空间 token（K=64），经下投影 \(g_\downarrow\) 压缩到 \(d_\Delta=256\) 的紧凑 Delta 目标 \(\Delta_t^\star\)，抑制静态背景。
- 构造 flow 路径 \(\Delta_\tau=\tau\varepsilon_\Delta+(1-\tau)\Delta_t^\star\)。
- 由于 Top-K token 是**无序集合**，采用**熵正则最优传输**（log-domain Sinkhorn，50 次迭代，η=0.05，样本级 cost 归一化、stop-gradient）构造置换不变的软匹配，损失为 \(\mathcal{D}_{set}=\langle \mathrm{sg}(T^\star_\eta),C\rangle\)，cost 为维度归一化平方欧氏距离。

### 2.3 Global Transition Anchor（GT-Anchor）

- 对当前/未来特征做自适应池化得到 K 个粗 token，构造全局锚点 \(G_t=\mathrm{Pool}_K(\bar V_{t+H})-\mathrm{Pool}_K(V_t)\)。
- 将预测 Delta 上投影 \(g_\uparrow\) 回视觉空间，与 \(G_t\) 用同一 set distance 匹配。
- 作用：提供**粗粒度、场景级**的过渡方向正则，防止 Delta 过度局部化或坍缩为常量。

### 2.4 Delta-Driven Action Refinement（DDAR）

- **DSAF（Delta 种子化动作流）**：两条互补分支
  - *噪声偏置*：Delta 均值池化后经 \(q_b\) 映射为动作空间偏置 \(b_t\)，初始噪声改为 \(\varepsilon'_A=\varepsilon_A+\gamma b_t\)（γ 可学习，初始 0.01，输出层零初始化）；
  - *前缀 token*：Delta 投影为 prefix token 拼接到动作 token 序列，作为去噪全程的条件。
  - 动作损失为速度预测的 MSE。
- **DAMG（Delta–动作流形接地）**：将 Delta token 与动作 token 投影到共享 256 维对比空间，用 soft token pooling（τ_∆=0.1）计算相似度，以当前动作块动作为正样本、同轨迹非重叠时段动作为负样本，优化 InfoNCE（τ_c=0.07）。论文给出其条件互信息下界的理论解释。

### 2.5 两阶段训练

- **Stage I（过渡预训练）**：冻结 VLM 与 Action Expert，仅优化 LT-Filter + GT-Anchor，10K steps，batch 48。
- **Stage II（联合优化）**：解冻 VLM 与 Action Expert，\(\mathcal{L}=\mathcal{L}_{act}+\lambda_1\mathcal{L}^{(1)}+\lambda_{DDAR}\mathcal{L}_{DDAR}\)，λ₁=1、λ_DDAR=0.1，60K steps，batch 128。
- 设计动机：若一开始联合优化，预训练动作通路可"绕过"尚未成形的 Delta 而降低动作损失，削弱 Delta 的接口作用。
- 推理时只需 VLM、World Expert、Delta 条件模块与 Action Expert；V-JEPA 编码器、\(g_\downarrow/g_\uparrow\)、\(q_\Delta/q_{act}\) 训练后丢弃，**部署不需要未来观测**。

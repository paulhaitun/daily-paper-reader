## 摘要
在经典固定区间调度中，给定集合中的每个作业必须在规定的时间区间内处理。目标是将每个作业恰好分配到一台机器上，使得分配到同一台机器的任意两个作业的内部不重叠，并最小化所用机器数。在没有进一步约束时，这是区间图着色问题，可通过贪心方法在多项式时间内求解。我们研究一种变体，其中每台被使用的机器都必须在调度范围内的某处保持空闲一段规定长度为 x 的连续休息。我们证明这一额外约束使问题变得困难，除非 x≤1。首先，对于每个固定的 x≥2，判定给定作业集合的分配是否只需 k 台机器是 NP完全的，即使所有坐标都以作业数的线性函数为界，因此机器最小化是强 NP困难的。其次，对于 x=1，我们给出一个多项式时间算法精确求解该问题。最后，我们给出一个确定性多项式时间算法，在每个可行实例上输出的调度至多使用 OPT+1 台机器，其中 OPT 是真正的最小值。除非 P=NP，否则不存在多项式时间算法能对任何固定 x≥2 保证使用 OPT 台机器，因此加一的保证是最优可能的。

## Abstract
In classical fixed-interval scheduling, each job of a given set must be processed during a prescribed time interval. The goal is to assign each job to exactly one machine such that no two jobs assigned to the same machine overlap in their interiors, and the number of machines used is minimized. Without further constraints this is interval graph coloring and is solvable in polynomial time through greedy approaches. We study a variant in which every used machine must remain idle during a contiguous \emph{break} of prescribed length $x$ somewhere in the scheduling horizon. We show that this additional constraint makes the problem hard, except when $x\le1$. First, for every fixed $x\ge2$, deciding whether $k$ machines suffice for the assignment of a given set of jobs is NP-complete, even when all coordinates are bounded linearly in the number of jobs, so machine minimization is strongly NP-hard. Second, for $x=1$, we give a polynomial-time algorithm that solves the problem exactly. Finally, we give a deterministic polynomial-time algorithm that, on every feasible instance, outputs a schedule using at most $\OPT+1$ machines, where $\OPT$ is the true minimum. Unless $\mathrm{P}=\mathrm{NP}$, no polynomial-time algorithm guarantees $\OPT$ machines for any fixed $x\ge2$, so the additive guarantee of one is best possible.

## 摘要
近年来，智能体系统的发展显著提升了具身操作的长时程能力。然而，许多现有框架仍遵循被动执行范式，这限制了其在涉及文本语义线索、干扰物以及初始不可见目标的真实世界场景中的适用性。为弥补这一差距，我们提出了一种基于智能体的主动探索框架，使机器人能够与环境动态交互，而不仅仅是执行预定义指令。具体而言，我们的框架由三个协同模块组成：用于高层任务推理的规划模块、用于视觉场景理解的感知模块，以及用于底层操作的执行模块。该设计使机器人能够主动获取任务相关信息，根据环境反馈调整行为，并在部分可观测条件下完成操作任务。此外，我们引入了一种细粒度的感知—执行交错策略，将视觉反馈与技能执行紧密结合，以提高探索鲁棒性。我们在一个真实的“寻找并放置”（Find-and-Place）任务上评估了我们的方法，证明了其在具有挑战性的环境中的有效性，在这些环境中，目标物体必须在操作前被主动发现。

## Abstract
Recent advances in agentic systems have substantially enhanced the long-horizon capability of embodied manipulation. However, many existing frameworks still follow a passive execution paradigm, which limits their applicability to real-world scenarios involving textual semantic cues, distractors, and initially invisible targets. To bridge this gap, we propose an agent-based active exploration framework that enables robots to dynamically interact with the environment rather than merely execute predefined instructions. Specifically, our framework consists of three collaborative modules: a planning module for high-level task reasoning, a perception module for visual scene understanding, and an execution module for low-level manipulation. This design allows the robot to actively acquire task-relevant information, adapt its behavior based on environmental feedback, and complete manipulation tasks under partial observability. Furthermore, we introduce a fine-grained perception-execution interleaving strategy, which tightly couples visual feedback with skill execution to improve exploration robustness. We evaluate our method on a realistic Find-and-Place task, demonstrating its effectiveness in challenging environments where target objects must be actively discovered before manipulation.

# 论文总结：从被动执行到主动探索——真实环境中的智能体具身操作

## 1. 核心问题与研究动机

- **背景**：智能体系统与 Vision-Language-Action（VLA）模型的进展提升了具身操作的长时程推理与决策能力，使机器人能够把高层目标分解为可执行子任务并跨多轮交互维持任务进度。
- **核心问题**：现有具身操作框架大多仍遵循**被动执行范式**——给定指令后，机器人在"目标可见、布局整洁、视觉信息充足"的简化假设下执行预定义的计划、策略或技能序列。
- **现实差距**：真实场景中目标物体可能被遮挡、初始不可见、被干扰物包围，或只能通过间接语义线索（如文本标签）识别。已有规划类方法虽考虑了这些情形，但往往依赖精心手工设计的模块，范式泛化性不足。
- **研究含义**：作者主张将操作任务从"被动指令执行"重构为"感知—规划—行动"的**闭环主动探索过程**，以缩小实验室式设置与真实部署之间的鸿沟。

## 2. 方法论

### 2.1 核心思想

- 把长时程操作视为**部分可观测条件下的闭环决策问题**：机器人不仅执行动作，还需主动从环境中获取缺失信息，并依据环境反馈调整后续行为。

### 2.2 三模块协同架构

- **规划模块（高层决策）**
  - 输入：用户指令 + 当前视觉观测 + 交互历史。
  - 输出：下一子任务，如搜索指定区域、检查语义线索、打开容器、取物、放置。
  - 作用：将欠约束的长时程指令转化为一系列可执行的探索性与操作性步骤。
- **感知模块（视觉 grounding）**
  - 功能：物体识别、目标定位、光学字符识别（OCR）、场景级语义理解。
  - 作用：判断当前场景是否包含足够信息以执行任务，将原始图像转为结构化环境信息，为规划提供依据。
- **执行模块（底层操作）**
  - 将规划出的子任务转换为可执行的机器人动作并驱动机器人交互。
  - 设计意图：避免让智能体直接输出连续控制指令，从而提升长时程执行稳定性，并使规划器专注于语义推理与任务进度判断。
- **闭环机制**：每个决策步中，规划器依据当前场景理解与任务历史选择动作 → 执行模块执行相应技能 → 感知模块更新环境状态，循环往复。

### 2.3 细粒度感知—执行交错策略（关键技术细节）

- **动机**：仅在任务开始前或结束后做一次感知，无法应对部分可观测环境，因为每一步操作都可能改变可见场景并暴露新信息。
- **做法**：将长时程任务分解为**原子操作单元**（如开抽屉、关抽屉、抓取物体），每个单元是不可再分的执行步，会产生潜在的新环境状态。
- **流程**：执行一个原子操作 → 立即调用感知模块更新场景理解 → 感知返回物体可见性、场景变化、任务进度等反馈 → 规划模块判断子目标是否达成、是否需继续探索、是否进入下一操作。
- **效果**：形成"观察—行动—验证—重规划"的循环，逐步通过交互降低不确定性，并在杂乱场景中纠正早期错误假设、防止误差在长时程中累积。
- 论文以文字描述流程，**未给出显式公式或伪代码算法**。

### 2.4 系统实现

- 硬件平台：Franka 机械臂，真实世界部署。
- 规划层：基于 **OpenClaw** 作为智能体框架与高层任务推理模块。

- 全系统可在单张消费级 GPU 上运行（见第 4 节）。

## 3. 实验设计

- **任务场景（自建，非标准 benchmark）**：真实世界 **Find-and-Place** 任务。
  - 桌面放置两个多抽屉柜，每个柜子对应不同物体类别，顶面贴有类别标签。
  - 目标物体置于未知抽屉内，初始观测不可见；抽屉内可能含干扰物。
  - 指令形式："Could you help me find the {target object} and place it into the box?"
  - 完整流程要求：由语义类别标签推断相关柜子 → 依次检查候选抽屉 → 目标可见后识别 → 抓取并放入盒子。
- **目标物体变体（3 种）**：两个不同颜色的塑料梨玩具 + 一个形状与纹理不同的毛绒梨玩具，覆盖颜色、尺寸、材质、纹理变化。
- **干扰条件（2 种）**：无视觉相似干扰物 / 引入柠檬形状的视觉相似干扰物。
- **成功判据**：正确选择柜子、搜索到目标、抓取目标、放入盒子，四者全部完成；失败包括选错柜子、未找到目标即停止、抓错干扰物、放置失败。

## 6. 主要结论与发现

- 主动探索框架在 Find-and-Place 任务上取得**总体成功率 95.7%（无干扰）/ 94.3%（有干扰）**。
- 三个目标变体成功率分别为 96.0/94.0、96.0/95.0、95.0/94.0（无/有干扰），表明对颜色、尺寸、材质、纹理变化具有较好的泛化性，而非仅适配单一固定视觉实例。
- 引入视觉相似干扰物后成功率仅下降 1.4 个百分点，说明细粒度感知—执行交错能有效应对视觉歧义与杂乱场景。
- 总体结论：将规划、感知、执行整合为闭环，并在每个原子操作后更新场景理解，可有效处理初始不可见目标、干扰物与类别引导搜索，验证了从被动执行转向主动探索的可行性。

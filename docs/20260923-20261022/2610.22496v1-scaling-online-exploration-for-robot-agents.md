## 摘要
机器人学习通过扩展演示数据集和模型容量取得了进展；然而，部署新的机器人本体或任务通常需要专门的遥操作数据语料库。由此得到的策略仍受其模仿分布的限制，制约了泛化能力和持续自我改进。我们提出 RAX（Robot Agent eXploration），一个以扩展探索为核心的机器人智能体开源框架：使智能体能够通过获取在线经验和合成可执行程序来改进。在 RAX 中，通用编码智能体生成机器人控制代码，无需动作演示数据、手工设计的动作基元或价值函数引导即可运行。通过在线探索，智能体识别可实现任务目标的决策序列，并将其编译为封装完整感知-规划-控制回路的模块化程序。借助 RAX，我们开展了一项系统性的多本体研究，在仿真和真实机器人上使用单臂、双臂、灵巧、移动和人形系统，针对精确操作和长时程操作任务扩展在线探索。随着探索规模扩大，在未见环境上的泛化性能持续提升。在仿真中，RAX 平均比顶级基线模型高出 +37.4%。在真实机器人上，RAX 无需人类演示即可自主学习依赖记忆、铰接、高精度、可变形和长时程移动操作任务，并通过组合先前探索会话中验证的技能持续提升性能。随着探索规模扩大，我们观察到涌现能力，包括主动感知、错误恢复、安全护栏和人机协作。我们将 RAX 开源为一个通用机器人智能体平台，其中新的机器人本体仅通过其 API 即可集成，无需遥操作数据收集或策略训练。

## Abstract
Robot learning has advanced by scaling demonstration datasets and model capacity; however, deploying a new robot embodiment or task typically necessitates a dedicated teleoperation corpus. The resulting policies remain bounded by their imitation distributions, limiting generalization and continual self-improvement. We introduce RAX (Robot Agent eXploration), an open-source framework for robot agents centered on scaling exploration: enabling agents to improve by acquiring online experience and synthesizing executable programs. In RAX, a general-purpose coding agent generates robot control code, operating without action demonstration data, hand-engineered action primitives, or value-function guidance. Through online exploration, the agent identifies decision sequences that achieve task goals and compiles them into modular programs encapsulating the full perception-planning-control loop. Using RAX, we present a systematic multi-embodiment study on scaling online exploration across precision and long-horizon manipulation tasks using single-arm, bimanual, dexterous, mobile, and humanoid systems in simulation and on real robots. Generalization performance on unseen environments improves consistently as exploration scales. In simulation, RAX outperforms top baseline models by +37.4% on average. On real robots, RAX autonomously learns memory-dependent, articulated, high-precision, deformable, and long-horizon mobile manipulation tasks without human demonstrations, continually improving performance by composing verified skills from prior exploration sessions. As exploration scales, we observe emergent capabilities including active perception, error recovery, safety guardrails, and human-robot collaboration. We open-source RAX as a generalist robot-agent platform in which new robot embodiments are integrated through their APIs alone, without teleoperated data collection or policy training.

## 1. 核心问题与研究背景

  - **部署成本**：每换一个新机器人本体或新任务，几乎都要重新采集专属遥操作语料并再训练策略；跨本体数据池（Open X-Embodiment 类）之外的机器人仍需自有数据。

- **核心追问**：机器人能否像人类一样，通过“尝试—观察结果—诊断失败—练习”这一循环，在**自主在线经验与主动探索**中自我改进并发现新技能？

## 2. 方法论

### 2.1 核心思想

- **冻结模型参数**，不训练任何策略；学习发生在**持久化工作区**（程序、笔记、技能库）上。
- 输入：自然语言指令 + 少量目标图像/视觉示教 + **探索 episode 预算**；不提供动作示教。
- 学习流程四步：① 通过工具直接遥操作式控制机器人直至确认成功 → ② 把过程写成带前置条件检查、结果校验、异常上报的程序 → ③ 后续每个探索 episode 运行该程序，失败处由智能体介入修代码 → ④ 维护笔记与交接文档。
- 最终形态是**全自动程序**（部署时无需 agent）与**agent-in-the-loop 程序**之间的连续谱。

### 2.2 认知架构（四模块 + 记忆）

- **多模态感知**
  - 输入 RGB、深度、相机内参与位姿、力/力矩信号；像素反投影为机器人基座系下的度量点云。
  - 智能体**自发**（论文强调未给任何相关技能或示例）构建任务相关 3D 物体模型：如气炸锅被建模为“固定机体 + 沿拉动方向 *d* 平移的抽屉”的**铰接模型**，并对每个新场景重新拟合轴线 *c* 与拉动方向 *d*。
  - 力反馈用于消解空间不确定性（接触探测、力闭环插入）。
- **规划与控制**
  - 机器人控制 SDK 以 **MCP 工具**形式暴露，辅以 IK 求解器、URDF、碰撞感知运动规划、以及“仅在机器人模型上试跑”的 preview。
  - 智能体在 3D 世界模型上直接搜索可行动作，自行选择抽象层级（单关节目标 ↔ 自由空间运动）。
- **从探索到自主程序**
  - 成功后将决策逻辑**编译为 Python 程序**，封装完整“感知—规划—控制”闭环，以机器人频率运行，替代昂贵的逐步 LLM 推理。
  - 程序内建检查点；遇到开放世界变化时 `raise Unsure()` 抛异常，把控制权交回 agent 修改代码。
  - 程序调用的工具与 agent 调用的工具**完全一致**，故“探索中调通的代码”即“部署时运行的代码”。
- **记忆与持续学习**
  - 会话内：`PROGRESS.md`、`TIPS.md` 等笔记（含失败教训、有效参数），配合上下文压缩。
  - 跨会话：**版本化技能库**，每个技能含代码、适用前置条件、无监督成功证据；未通过无人监督验证不得入库；按机器人分支、验证后合并。
  - 技能可组合为长程任务；中间桥接代码会被抽象为新技能（如 `oc-hand-reach`）。
- **并行探索**：多环境 + 多 subagent 共享工作区与统一 episode 账本，加速预算消耗。

### 2.3 系统架构：前后端分离

- **后端**（机器人物理栈）：厂商驱动/仿真器、低层控制器（关节 PD/阻抗、OSC、全身运动跟踪）、传感与连续录制、**安全护栏**（仅在操作员 armed 时允许运动；每条指令先校验工作空间、关节限位、自碰撞、关节负载，违规即拒绝并返回违规项）。
- **前端**（agent 工作区）：隔离容器 + 持久工作区 + 标准编程工具；只通过**工具接口**与后端交互，无法修改控制器或驱动。
- **多本体即插即用**：新机器人只需提供后端与接口文档，前端、记忆组织、评测协议全平台共享——**仅通过 API 接入，无需采数据、无需训练**。
- 覆盖本体：LIBERO/LIBERO-Pro（Franka Panda）、RoboDojo（ARX X5 双臂）、DexJoCo（Franka + Allegro 16 DoF 手）、BEHAVIOR-1K（Galaxea R1Pro）、HumanoidArena（Unitree G1 + Dex3）、真机 Franka FR3、真机 Rainbow RB-Y1 轮式移动操作臂。

### 2.4 代表性技术细节（体现“从测量到代码”）

- **气炸锅感知流水线**（约 1500 行自写 Python，无学习型检测器、无 VLM）：腕部相机俯视拟合盖子圆（六轮截断最小二乘）得轴 *c*；把手暗点按方位中位数得 *d*；沿 *d* 的 1.5 cm 高度切片取 97 分位得握持外表面、95 分位得臂顶高度；香蕉用 SVD 主轴 + 二次曲线中心线得抓取点与 18.0 cm 弦长；开抽屉后拟合篮沿，与模型预测相差 6.5 mm。
- **手部自标定**（DexJoCo Hanoi，首个 episode）：逐个关节运动 + 腕相机深度分割白色指尖帽，拟合指尖相对法兰偏移；拇指偏移与官方模型相差 **1.1 mm**（从未见过该模型）。
- **抓取设计推导**：由四种失败抓取的测量推出“滚转 θ 使掌心指缘移动 `0.10·sinθ − 0.013·cosθ` 米”，取 roll = 0.44 rad 的“滚转竖直捏取”成功。
- **人形跨栏**：从示教裁剪 66 步对称步态周期；测量步幅与幅值非线性关系（0.35 以下 14.5 cm、0.6 时 25 cm）；基于 102 次转移拟合站姿模型；用 17/17 与 27/27 vs 4/13 的实测统计设定跨栏窗口（`BAR_GO = −0.215`、`R_GO_MIN = −0.37`），并用自写蒙特卡洛模拟把跌落风险从 9.3% 降到约 6%。
- **LIBERO-Pro 镜像适配**：加 36 行“镜像层”，对 y 反射点、旋转向量 `(−wx, wy, −wz)` 与 7 维动作行，用柜体顶面高度图自判柜子在 +y 还是 −y。

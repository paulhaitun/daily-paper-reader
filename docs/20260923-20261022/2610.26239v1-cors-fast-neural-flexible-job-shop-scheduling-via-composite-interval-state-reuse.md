## 摘要
针对柔性作业车间调度问题（FJSP）的神经求解器通常会在每个“工序—机器”决策后刷新图表示并更新可行性。然而，只有可行性必须在每一步保持精确，而图编码的计算代价要高得多，并且可以更低频地刷新。我们提出 CoRS，将二者解耦：区间级图表示在多个连续决策之间复用，而逐步可行性状态在每次动作后更新。这种双时间尺度设计分摊了图编码开销，同时不并行化动作生成，也不放宽调度约束。CoRS 进一步提出一种保持可行性的复合区间解码方案，结合动态约束跟踪与边界状态同步，在降低表示刷新频率的同时维持连续可行的调度构造。此外，为缓解区间级状态复用导致的表示陈旧问题，CoRS 引入增强静态特征作为补偿机制。通过提供更全面的调度问题结构信息，这些特征提升了模型对整体问题特征的感知能力。在合成数据与多个公开 FJSP 基准上的大量实验表明，CoRS 在保持有竞争力的解质量的同时显著减少推理时间，并在紧墙钟预算和低延迟场景下实现良好的速度—质量权衡。

## Abstract
Neural solvers for the Flexible Job-Shop Scheduling Problem (FJSP) typically refresh graph representations and update feasibility after every operation--machine decision. However, only feasibility must remain exact at every step, whereas graph encoding is substantially more expensive and can potentially be refreshed less frequently. We present CoRS, which decouples them: an interval-level graph representation is reused across multiple sequential decisions, while a stepwise feasibility state is updated after every action. This two-timescale design amortizes graph encoding without parallelizing action generation or relaxing scheduling constraints. CoRS further develops a feasibility-preserving composite-interval decoding scheme with dynamic constraint tracking and boundary state synchronization, which reduces representation refresh frequency while maintaining continuous feasible schedule construction. Furthermore, to alleviate representation staleness caused by interval-level state reuse, CoRS introduces enhanced static features as a compensation mechanism. By providing more comprehensive structural information of the scheduling problem, these features improve the model's perception of overall problem characteristics. Extensive experiments on synthetic and multiple public FJSP benchmarks demonstrate that CoRS significantly reduces inference time while maintaining competitive solution quality, achieving favorable speed-quality trade-offs under tight wall-clock budgets and low-latency scenarios.

- **研究背景**：柔性作业车间调度问题（FJSP）是 NP-hard 组合优化问题，广泛应用于云制造、医疗资源调度、半导体制造、航空发动机生产等场景。实际系统要求调度决策在有限时间内快速响应。
- **现有神经求解器的问题**：主流神经 FJSP 求解器通常将调度建模为马尔可夫决策过程（MDP），采用自回归决策和强化学习。它们隐含假设：**每个“工序—机器”决策后都必须刷新完整图表示并更新可行性**。
- **核心观察与动机**：论文指出，连续决策之间全局状态通常只发生有限变化；每步真正必须保持精确的是**可行性**，而图编码代价高得多，可以更低频刷新。
- **整体含义**：CoRS 将“图表示刷新”和“可行性更新”解耦，提出**双时间尺度状态演化**：区间级图表示跨多个决策复用，逐步可行性状态每步更新。其意义在于把“表示刷新频率”作为神经 FJSP 求解中此前较少被关注的设计维度，在不并行化动作生成、不放松调度约束的前提下摊销图编码开销，面向紧墙钟预算和低延迟调度场景。

## 2. 方法论

### 2.1 核心思想：Composite Regressive（CR）机制

- 将整个调度过程划分为多个连续、不重叠的**复合区间** \(B_\tau\)，每个区间包含 \(X\) 个时间步：
  \[
  B_\tau=\{t\mid(\tau-1)X+1\le t\le \min(\tau X,t_{\text{final}})\}
  \]
- 在区间内复用**区间级表示状态** \(s_\tau\)，仅在区间边界重新编码；每步只更新**逐步可行性状态** \(s_t^{\text{feas}}\)。
- 图编码器调用次数从 \(T\) 降为 \(\lceil T/X\rceil\)，但不减少动作生成步数，也不并行生成动作。

### 2.2 MDP 设计

- **状态**：
  - 区间级表示状态 \(s_\tau=\{h_{ij},h_k,h_{(ij,k)}\}\)，分别表示工序、机器、工序—机器对特征。
  - 逐步可行性状态 \(s_t^{\text{feas}}\) 记录候选工序、工序—机器可行性掩码、机器释放时间等；仅用于确定可行动作空间，不参与区间内特征编码。
- **动作**：当前可行工序—机器对（OM pair）集合 \(A_t\) 中的一个。
- **状态转移**：
  - 区间边界同步：\(s_{\tau+1}=f_{\text{recon}}(s_\tau,\{a_t\}_{t\in B_\tau})\)。
  - 每步更新 \(s_t^{\text{feas}}\)，跟踪动态约束并维持可行动作空间。
- **奖励**：基于估计完成时间 \(C_{LB}(O_{ij},t)\) 的 makespan 估计差：
  \[
  r_t=C_{LB}(t)-C_{LB}(t+1)
  \]
  未调度工序用前驱完成时间与候选机器最小加工时间递归估计。

### 2.3 增强静态特征

- 为缓解区间内复用导致的表示陈旧，CoRS 增强静态特征：
  - 工序特征 \(h_{ij}\in\mathbb{R}^{12}\)；
  - 机器特征 \(h_k\in\mathbb{R}^{10}\)；
  - OM 对特征 \(h_{(ij,k)}\in\mathbb{R}^{8}\)。
- 引入后继工序平均加工时间、每台机器最快操作总数等更全面的结构信息，提升模型对整体问题特征的感知，补偿低频刷新造成的动态信息缺失。

### 2.4 区间编码网络

- 采用图注意力框架，包括**工序编码子网 O-Net**和**机器编码子网 M-Net**。
- O-Net：
  - 线性投影后多头注意力；中间层采用低秩分解 \(W_1W_2\) 降低参数量；
  - 使用可学习缩放参数 \(\beta_h\) 增强头多样性；
  - 工序邻居为 \(\{j-1,j,j+1\}\)，注意力系数经 softmax 聚合。
- M-Net：
  - 引入机器竞争边特征：若两台机器共同竞争非空未调度工序集合 \(I_{kk'}\)，则存在竞争关系；
  - 竞争强度为候选工序特征聚合 \(\epsilon_{kk'}=\sum_{O_{ij}\in I_{kk'}\cap J_c}h_{ij}\)；
  - 通过注意力聚合机器特征和竞争边特征。
- **Attention Pooling**：对机器和工序节点分别做注意力全局池化，拼接得到区间全局表示 \(h_{\text{global}}^\tau\)，用于决策和价值评估。

### 2.5 复合区间解码

- 每步可行动作集：
  \[
  A_t=f_{\text{mask}}(s_{t-1}^{\text{feas}},a_{t-1})
  \]
- \(f_{\text{mask}}\) 更新相关机器释放时间、当前候选工序及机器兼容关系，计算候选 OM 对最早开始时间，将违反约束的 OM 对掩码。
- 区间结束后用 \(f_{\text{recon}}\) 向量化重建下一区间状态；仅工序相对完成时间因严格顺序依赖需顺序更新，其他特征

（如机器释放时间、机器—工序兼容关系、全局负载统计量）可向量化并行重建，从而以较低开销完成区间边界的状态同步；重建后的表示与上一区间表示进行融合，避免区间切换时信息完全丢失。

- **决策流程**：在每个时间步，解码器以区间级表示 \(s_\tau\) 提供的节点/对嵌入为输入，结合 \(s_t^{\text{feas}}\) 生成的可行动作掩码 \(A_t\)，输出动作概率分布并采样（训练时）或取贪心/采样（推理时）一个 OM 对；随后仅更新 \(s_t^{\text{feas}}\)，直至区间结束触发下一次重编码。

### 2.6 训练与优化

- **策略学习**：采用 actor–critic 架构与 PPO 式裁剪目标；actor 基于区间表示与当前可行性掩码输出动作分布，critic 以区间全局表示 \(h_{\text{global}}^\tau\) 及逐步可行性统计量估计状态价值。
- **奖励设计**：以 \(C_{LB}\) 的逐步下降量作为稠密奖励，使区间内每一步都能获得反馈，缓解稀疏 makespan 奖励带来的信用分配困难；同时保证回报与最终 makespan 方向一致。
- **训练稳定性**：对优势函数做归一化、对策略比率做裁剪，并加入熵正则以维持探索；由于图编码调用次数减少，单次 rollout 的编码开销显著下降，使同等墙钟预算下可采集更多决策样本。
- **复杂度**：图编码复杂度由 \(O(T\cdot f_{\text{enc}})\) 降为 \(O(\lceil T/X\rceil\cdot f_{\text{enc}})\)，而可行性更新仍为每步 \(O(|A_t|)\) 量级，整体推理延迟随 \(X\) 增大而下降，但解质量与 \(X\) 之间存在权衡。

1. **问题视角**：明确指出神经 FJSP 求解器中“每步全图刷新”的隐含假设并非必要，提出以可行性精确性为核心、以表示为可摊销资源的设计原则。

3. **表示补偿**：通过增强静态特征与机器竞争边建模，缓解低频刷新带来的表示陈旧问题。

## 5. 局限性与可拓展方向

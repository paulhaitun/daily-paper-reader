## 摘要
人类和动物并非从固定数据集中学习视觉：它们会移动、交互，并从自身行动带来的视觉后果中学习。受这种发展视角启发，我们研究机器人能否通过好奇心驱动的交互主动收集经验，从而改进视觉学习。我们提出 DySCOVER，一个用于机器人主动视觉学习的自监督框架。机器人观察 RGB 帧，学习一个视觉自编码器来编码和重建这些帧，并训练一个循环世界模型，以当前状态和动作为条件预测下一个视觉潜在状态。智能体的策略仅用内在奖励训练：重建误差鼓励视觉上新颖的观察，而世界模型的误差鼓励那些后果尚不可预测的状态转移。这种预测误差使策略偏向更复杂的轨迹，从而用仅靠视觉新颖性所鼓励之外的观察来丰富智能体的经验集。我们以机械臂作为具身智能体进行的实验表明，加入预测性好奇心相比仅使用视觉好奇心能改进视觉模型。在初始条件、经验容量、具身形态和场景内容的变化下，加入预测性好奇心始终改善了视觉学习。这些结果表明，预测性好奇心能够超越仅基于重建的好奇心，改进主动视觉学习。

## Abstract
Humans and animals do not learn vision from a fixed set of data: they move, interact, and learn from the visual consequences of their actions. Motivated by this developmental view, we study whether robots can improve visual learning by actively collecting experience through curiosity-driven interaction. We introduce DySCOVER, a self-supervised framework for active robot visual learning. A robot observes RGB frames, learns a visual autoencoder that encodes and reconstructs them, and trains a recurrent world model to predict the next visual latent state conditioned on the current state and action. The agent's policy is trained only with intrinsic rewards: reconstruction error encourages visually novel observations, while the world model's error encourages transitions whose consequences are not yet predictable. This prediction error biases the policy toward more intricate trajectories that enrich the agent's set of experiences with observations beyond those encouraged by visual novelty alone. Our experiments conducted with robotic arms as the embodied agents show that adding predictive curiosity improves the vision model over using visual curiosity alone. Across variations in initial conditions, experience capacity, embodiment, and scene content, adding predictive curiosity consistently improved visual learning. These results show that predictive curiosity can improve active visual learning beyond reconstruction-based curiosity alone.

- **问题拆解**：
  - 视觉好奇心奖励"难以重建的观测"（帧级新颖性）；
  - 预测性好奇心奖励"后果难以预测的状态转移"（动作条件动力学误差）；
  - 作者假设后者能把策略偏向更复杂的运动轨迹，从而采集到仅靠视觉新颖性无法获得的、对视觉模型更有信息量的经验。
- **与已有工作的差异**：Push, See, Predict 等工作依赖显式物体分解（Slot Attention）与预定义动作；本文直接在**学习到的视觉潜空间**上运行，无需物体分割，且策略、视觉模型、世界模型在同一闭环中持续共同适应。

## 二、方法论：DySCOVER 框架

### 2.1 核心思想

DySCOVER（DynamicS-informed CuriOsity for Visual Exploration and Representation-learning）是一个自监督主动视觉学习框架，耦合三个持续更新的组件，构成"采集经验 → 计算好奇心 → 更新学习器"的闭环：

1. **视觉自编码器**（Eθ, Dθ）：从采集图像中学习编码与重建；
2. **循环世界模型**（Fϕ, Gϕ）：在视觉潜空间中预测动作条件下的下一潜状态；
3. **循环 Actor-Critic 策略**（πη）：仅由内在奖励驱动，决定采集何种经验。

### 2.2 关键技术细节

- **视觉表征与视觉好奇心**：
  - zt = E(ot)，ôt = D(zt)；
  - 视觉损失 LV = λpix·ℓpix + λper·ℓper（像素 + 感知损失）；
  - 视觉内在奖励 rV_t = LV(ot+1)，即重建误差直接作为"帧新颖性"奖励（视觉-only 基线的全部奖励）。
- **动作条件世界模型**：
  - 输入当前潜状态 zt、动作 at 与隐藏状态 ht（捕获关节动量等单帧无法表达的历史信息）；
  - 输出预测潜状态 z̃t+1 与更新后的隐藏状态；
  - 损失 LW = ℓz(zt+1, z̃t+1) + λdec·ℓpix(D(zt+1), D(z̃t+1))；辅助项在**解码空间**对齐，避免预测误差被视觉模型的重建误差污染，便于奖励塑形；
  - 世界模型损失**不回传**到视觉模型，两者独立更新。
- **动力学感知内在奖励**：
  - 原始形式：rW_t = eW_t = LW；
  - 组合奖励：rt = α·rV_t + β·rW_t；
  - **调整版（默认）**：引入慢速更新的基线预测器 bψ(xt)，xt = (zt, at, ht)，用滞后存储的转移回归当前 WM 误差，输出恒正：
    r̄W_t = max(0, log(eW_t + ε) − log(bψ(xt) + ε))；
  - 作用：奖励"超出预期水平的"预测误差（对数比压缩尺度），抑制策略为追求大预测误差而偏向高幅值、不平滑动作的偏差。
- **交替更新流程（Algorithm 1）**：
  1. 用固定参数策略在 N 个并行环境中采集长度为 T 的 on-policy rollout，记录奖励与 PPO 统计量，并将转移存入回放缓冲区；
  2. 在 rollout 上用循环 PPO 更新策略（视觉参数 θ 冻结）；
  3. 在回放数据上更新视觉自编码器（LV）；用更新后的编码器**重新编码**回放序列，再更新世界模型（ϕ，E/D 冻结）。
- **网络结构**：
  - 视觉模型：无预训练 ResNet 编码器 + 空间瓶颈 + 仅接收瓶颈的解码器，**刻意不使用跳跃连接**，确保潜状态承载完整视觉信息；
  - 世界模型：动作经学习嵌入投影到同一空间网格，与潜表征拼接后送入 ConvGRU；
  - 策略：循环 actor-critic，使用 PPO 优化。
- **发展式课程**：先在无物体的"自身体探索"场景中学习动作—视角变化关系，再引入物体，使预测好奇心能聚焦于交互引起的变化。

## 六、主要结论与发现

1. **预测好奇心带来一致增益**：调整版 DySCOVER 相对视觉-only 基线将重建 MSE 降低 **14.5%**（PSNR 从 34.89 提升到 35.58 dB）；原始 WM 奖励为 6.8%；仅用 WM 奖励为 3.7%；随机采集比视觉-only 差 25.9%，比 DySCOVER 差 47.3%。
2. **收敛更快**：视觉-only 需 1,000 万步达到的重建误差，原始 WM 版本约 500 万步达到，调整版约 400 万步达到。
3. **紧凑缓冲区下增益保持甚至略增**：16k 帧缓冲区下 MSE 降低 **15.3%**，说明效果不依赖于大容量经验回放。
4. **跨具身可迁移**：Franka 上 MSE 降低 **9.5%**；UR10e + 不同夹爪在 200 万步时改善 3.2%。
5. **适应新场景**：物体增强场景中相对 MSE 降低 9.70%，且同初始化对照组仍落后 5.23%，说明增益来自世界模型奖励而非仅初始化。
6. **改进集中于前景**：全局 MSE 降低 5.63%，但机器人区域降低 **24.31%**、物体区域降低 **16.99%**，说明增益并非由背景主导。
7. **行为层面的解释**：DySCOVER 使物体交互次数 +18.2%、最大物体位移 +47.3%、运动方向熵 +6.3%；奖励分解显示 WM 奖励在物体被移动的区间升高，而重建奖励与这些区间不相关。
8. **奖励塑形的必要性**：原始 WM 奖励会导致高幅值、不平滑的动作；基线校正版在保持运动复杂度的同时显著平滑了控制。

## 七、优点（方法与实验设计亮点）

- **问题提法清晰且有发展心理学依据**：将"预测性 vs 重建性好奇心"的对比作为可实证的核心问题，而非仅提出新框架。

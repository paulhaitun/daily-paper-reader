## 摘要
视觉语言模型（VLMs）在空间推理方面已取得显著进展，自演化智能体通过从交互中学习，进一步将这些能力扩展到具身环境中。然而，当前的自演化在具身空间任务中仍尤其具有挑战性：基于部分视觉证据进行复杂且多步的决策，使得难以确定一次执行为何失败。失败可能源于感知错误、探索不足或规划不当，但仅凭执行反馈很少能揭示究竟是哪个环节导致失败。因此，仅仅累积交互经验可能会强化无效策略。为解决这一问题，我们提出 HiMeco，一种受元认知监控和海马记忆巩固启发的、面向具身空间智能的类脑自演化智能体。通过海马-元认知反思，HiMeco 诊断感知-探索-规划（PEP）中的失败，然后比较多次执行尝试，以提炼可复用的策略和避免重复错误的指导。它还将交互程序抽象为参数化技能，利用证据契约和基于执行的验证来决定这些技能的保留与复用。这些策略和技能指导后续交互，记忆仅在轮次之间更新，模型参数保持冻结。HiMeco 在 ESI-Bench 上取得了最先进的性能，并且在未进行演化的情况下将 EmbSpatial-Bench 上的准确率提高了 3.94 个百分点。

## Abstract
Vision-Language Models (VLMs) have made substantial progress in spatial reasoning, and self-evolving agents further extend these capabilities to embodied environments by learning from interactions. However, current self-evolution remains particularly challenging in embodied spatial tasks, complex and multi-step decisions from partial visual evidence making it difficult to determine why an execution fails. The failure may stem from misperception, insufficient exploration, or incorrect planning, yet execution feedback alone rarely reveals which component is responsible. As a result, simply accumulating interaction experience can reinforce ineffective strategies. To address this, we propose HiMeco, a brain-inspired self-evolving agent for embodied spatial intelligence, inspired by metacognitive monitoring and hippocampal memory consolidation. Through Hippocampal-Metacognitive Reflection, HiMeco diagnoses failures in perception-exploration-planning (PEP), then compares execution attempts to derive reusable strategies and guidance for avoiding recurring errors. It also abstracts interaction programs into parameterized skills, using evidence contracts and execution-based validation to determine their retention and reuse. These strategies and skills guide subsequent interactions, with memory updated only between rounds and model parameters kept frozen. HiMeco achieves state-of-the-art performance on ESI-Bench, and it also improves accuracy on EmbSpatial-Bench by 3.94 percentage points without evolution.

- **背景**：视觉语言模型（VLM）在空间推理上进步显著，但本质上是“被动观察者”。在真实具身环境中存在非视距遮挡（NLOS）、不可观测的物理动态与隐藏拓扑，仅凭静态图像难以完成深度空间推理，必须通过主动交互获取证据。
- **两条既有路线及其局限**：
  - *静态感知路线*（SFT/RL 离线优化、注入 3D/深度先验、提示工程）：把环境当作被动固定观测空间，缺乏闭环交互，在遮挡与隐藏拓扑下存在“认知盲区”。
  - *动态交互路线*（TANGO、ParallelWorld 等）：引入环境反馈以消解局部歧义，但**把“自演化”搬到具身空间任务上时出现关键瓶颈**。
- **核心痛点——失败归因不可靠**：具身空间任务的失败可能来自**误感知（Perception）、探索不足（Exploration）或规划错误（Planning）**，而执行反馈（对/错）本身几乎不揭示是哪一环出错。后果是：盲目累积交互经验会**强化无效策略**，错误在多轮演化中滚雪球式累积。
- **灵感来源**：生物大脑中**海马体—前额叶元认知回路**的交互（元认知监控 + 海马记忆巩固），使动物能从经验中提炼有效策略以应对陌生环境。
- **由此引出两大技术挑战**：
  1. **自适应语义抽象**：从重复交互中保留什么、泛化多宽？过具体则迁移差，过泛则丢失执行所需细节。
  2. **可靠的失败归因**：仅凭答案错误无法区分“看错”“没看够”“计划错”，否则会保留不可靠流程。

## 2. 方法论：HiMeco

### 2.1 总体框架

- **三段式循环**（图 2）：(A) 冻结规划器与环境交互、收集证据 → (B) PEP 诊断模块做元认知式失败归因 → (C) 轮次间更新记忆。
- **双记忆结构**：策略库 `E`（策略经验）+ 技能库 `K`（参数化可执行技能），记忆 `M_r = (E_r, K_r)`。
- **关键约束**：**模型参数全程冻结**；记忆**仅在轮次之间**更新（同一轮内所有 episode 共享同一记忆快照），保证每个尝试都在固定记忆下被公平评估。
- **规划器**：冻结 VLM `Φ` 生成 JSON AST 程序 `P`，调用观测/导航/推理/交互原语 `A`，按新观测分支；episode 内工作记忆存观测、中间状态与证据。

### 2.2 形式化设定

- 输入 `x = (o₀, q)`（初始 RGB+位姿 + 空间查询）；轨迹 `τ = (P, {(a_k, o_k)}, ŷ, V)`。
- 三个判定量：
  - 任务正确性 `r_task(τ) = 1[ŷ = y]`
  - 证据合格性 `ℓ(τ) = 1[ContractValid(τ, q)]`
  - 学习成功 `s(τ) = r_task(τ)·ℓ(τ)` —— **只有答案对且证据契约通过，才能进入正例记忆**。

### 2.3 元认知诊断模块 U（PEP）

- 输出三维诊断分 `u(τ) = (u_per, u_exp, u_pla) ∈ [0,1]³`，分数代表“失败证据强度”而非校准概率；在线规划器**看不到**标签与特权元数据。
- **感知分**：按顺序规则判定——视觉输出契约非法（1.00）、符号计数与模拟器生成目标数不一致（1.00）、探索分≤0.35 且有视觉调用（0.95/0.80）、有视觉调用但无更明确证据（0.55）、无可审计证据（0.35）；答案正确则直接为 0。
- **探索分**：`u_exp = min(1, 0.6·c_pose + 0.3·c_div + 0.1·c_obs)`，其中 `c_pose` 为参考相机位姿覆盖惩罚（≤1m 不罚、≥2.5m 满罚），`c_div` 惩罚位姿多样性不足（少于 6 个不同位置-朝向对），`c_obs` 惩罚“只看了 1 个视角却已行动”。
- **规划分**：规则分 `u_pla^rule`（程序错误/原语失败/执行不完整=1；缺 return_answer/答案格式非法=0.85；超预算=1）与冻结 LLM 审计员分取 `max`；审计员只看问题、AST、紧凑日志与分支日志，不能修改或续跑程序。
- **主失败标签**：`f*(τ) = none`（正确且无规划异常）否则 `argmax_d u_d(τ)`，但反思时**保留全部三维分数**以处理并发失败。

### 2.4 候选比较与相对优势

- 同一 episode 在**不同记忆条件**下生成多个候选（经验-only 参考、试验技能条件、无记忆条件）。
- 奖励：`R(τ) = 2·r_task(τ) − 0.75·ū(τ) + 0.1·η(τ)`，其中 `ū` 为三维诊断均值，`η = 1 − min(1, n_act/T_max)` 为动作效率。设计上**正确轨迹至少 1.25 分、错误轨迹至多 0.1 分**，确保正确性优先，再用诊断分与效率区分同正确性的候选。
- 相对优势 `Adv(τ) = R(τ) − mean_{τ'∈C} R(τ')`，用于**无梯度**的比较式反思；但正例入库仍单独要求 `s(τ)=1`，防止“高分绕过证据契约”。

### 2.5 策略经验库 E

- 每条策略记录 **when（适用条件）/ how（如何获取证据）/ avoid（应避免的失败）**，并携带任务、诊断维度、创建轮次等元信息。
- 三个更新来源：① 每个 episode 中**优势最高的合格成功**候选（同分取动作更少者），抽象其原语使用方式，剔除答案值与 episode 专属坐标；② **候选坍缩**（|C|≥2、全部 `s=0`、答案完全一致）时，由确定性规则生成纠正性指导（如“再取一个视角”“加一次视觉检查”）并标注主诊断标签；③ 冻结 LLM 反思器 `Ψ` 对候选 bundle 做对比反思，产出 add/modify/delete/keep。
- 合并：`E_{r+1} = Apply(E_r, ΔE^champ, ΔE^fail, ΔE^refl)`，受容量上限约束（每任务 `max(20, 2n_q)`），超出时按 episode、经验类型、诊断维度做压缩保留。

### 2.6 复合技能库 K

- **抽象**：把程序模式中的对象相关输入替换为 `$input.field` 参数，**保留控制流与证据检查**，删除 `return_answer`；模式需满足 `|X_p| ≥ m`（默认 m=2）且成功率 `|X_p⁺|/|X_p| ≥ θ_syn`（默认 0.6），每个 episode 只计一次。
- **验证先于复用**：新技能进入 trial 状态，必须经真实调用验证；统计 `N_use, N_exec, N_valid, N_succ`，用平滑率 `ρ(a,b) = (a+λμ)/(b+λ)`（μ=0.5, λ=4）降低稀疏性敏感。
- **质量分**：`Q(k) = w_s·ρ(N_succ,N_valid) + w_c·ρ(N_valid,N_exec) + w_e·ρ(N_exec,N_use) + w_a·η̃(k)`，默认权重 (0.65, 0.20, 0.10, 0.05)，部分任务用 (0.70, 0.20, 0.08, 0.02)。
- **生命周期**：执行成功率 <0.9、证据通过率低于任务阈值、或任务成功率 <0.6 → **挂起（suspend）**，但不改写已验证技能体；检索按“生命周期状态 → 经验成功率 → episode 支持度”排序，最终轮还会校验执行可靠性、证据有效性与任务匹配度。

### 2.7 交互与演化协议

- 四轮调度，每 episode 候选数 **(1, 3, 3, 1)**，共 8 次执行/episode（208 episode → 1664 次计划执行）；第 0 轮为空记忆基线，第 3 轮使用**冻结记忆 M₄**；更新只发生在轮末（第 0/1/2 轮之后）。
- 程序约束：≤48 条语句、分支深度 ≤4、允许 1 次修复重试、每个分支必须 `return_answer`。

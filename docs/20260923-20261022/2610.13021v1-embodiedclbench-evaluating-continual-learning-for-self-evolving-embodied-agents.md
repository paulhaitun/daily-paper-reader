## 摘要
持续学习要求模型积累过往经验并将其迁移到新任务。尽管持续学习已有大量研究，现有工作仍主要局限于非具身环境，尚未扩展到具身环境。为弥补这一空白，我们提出了 EmbodiedCLBench，这是首个用于评估自进化智能体持续学习能力的具身仿真基准。该基准以组合泛化为核心评估原则，评估智能体能否先从基础任务中学习，再重组已获得的技能来解决复杂且未见的高级任务。基于 EmbodiedCLBench，我们在多种智能体执行框架和学习方法上开展了大量实验，揭示出一致的局限性和独特行为。结果表明，尽管高级任务在零样本设置下很难被解决，但来自基础任务的经验能够带来持续提升。即使任务复杂度增加，这种经验带来的收益仍保持稳定。然而，这种提升并不会随学习样本数量的增加而相应扩展，当前智能体无法从额外经验中提取有意义的信息。总体而言，我们的发现凸显了持续学习作为一种基础但尚未充分探索的能力，而我们的基准为在具身环境中设计有效的自进化智能体提供了有价值的资源。我们的代码和数据集可在 https://pku-value-lab.github.io/EmbodiedCLBench-homepage 获取。

## Abstract
Continual learning requires models to accumulate past experience and transfer it to new tasks. Despite substantial research on continual learning, existing work remains largely confined to non-embodied settings, without extending to embodied environments. To address this gap, we introduce EmbodiedCLBench, the first benchmark in embodied simulation for evaluating the continual learning capability of self-evolving agents. With compositional generalization as the core evaluation principle, our benchmark evaluates whether agents can first learn from basic tasks and then recombine the acquired skills to solve complex, unseen advanced tasks. Based on EmbodiedCLBench, we conduct extensive experiments across multiple agent harnesses and learning methods, revealing consistent limitations and distinctive behaviors. Our results show that while advanced tasks can be hardly solved under zero-shot setting, the experience from basic tasks enables consistent improvement. Such benefit from the experience remains stable even if the task complexity increases. However, this improvement does not scale accordingly with the number of learning samples, and current agents cannot extract meaningful information from additional experience. Collectively, our findings highlight continual learning as a fundamental yet underexplored capability, and our benchmark offers valuable resources for designing effective self-evolving agents in embodied environments. Our code and dataset are available at https://pku-value-lab.github.io/EmbodiedCLBench-homepage.

## 1. 核心问题与整体含义

- **研究动机**：自进化智能体（self-evolving agents）需要像人类一样在交互中不断积累经验，并把已获得的技能迁移到新任务上，这一能力被称为持续学习（continual learning）。它对具身智能尤为关键，因为物理环境复杂多变，训练阶段无法预见所有情形。
- **现有空白**：
  - 持续学习基准大多停留在**非具身**场景（知识密集型任务、网页与操作系统等数字环境、长期模拟世界），缺少空间复杂度与物理约束。
  - 具身 AI 基准虽覆盖场景感知、视觉导航、机器人操作、长程规划等，但**并非为持续学习而设计**。
  - 因此，业界缺少一个专门衡量“自进化具身智能体能否积累经验并迁移到新任务”的评测平台。
- **整体含义**：论文提出 **EmbodiedCLBench**，这是首个面向具身仿真的持续学习基准，把“组合泛化”作为衡量持续学习的可操作原则：智能体应先在基础任务中习得技能元素，再重组这些元素去解决未见过的、更复杂的高级任务，而不是每个新任务都从零学起。

## 2. 方法论

### 核心思想
- 用**组合泛化**作为持续学习的可测量代理指标：基础任务相当于“测试时学习（test-time learning）数据”，高级任务则是需要重组已学技能的新组合任务。
- 任务分为三级：
  1. **原子动作**（atomic actions）：来自 TongSim 的单一物体交互（如 pick up、open、switch on），每个原子动作由若干可执行步骤组成。
  2. **基础任务**（basic tasks）：由少量原子动作组合成实际家务操作（如“把杯子放到桌上”）。
  3. **高级任务**（advanced tasks）：组合来自 2–4 个基础任务类别的元素，形成更长程的复合任务（如“整理房间”）。

### 关键技术细节
- **仿真环境**：采用 TongSim 的闭源版本（动作更丰富），包含 6 个场景、2 种相机高度、51 类物体、7 种原子动作；因闭源无法在线仿真，故转为**离线图评估**。
- **状态转移图构建**：
  - 每个图节点表示唯一环境状态（如“靠近桌子并看着台灯”），并配有第一人称图像和一组动作候选。
  - 每条可执行动作对应一条边，确定性地转移到下一状态。
  - 给定任务后，先定义初始状态与目标状态，再用**广度优先搜索（BFS）** 找到最短路径；沿最短路径节点扩展其他可执行动作，构造**干扰路径**（可执行但偏离最短路径）。
- **动作候选三类**：最优动作（沿最短路径）、次优动作（可执行但偏离最短路径）、无效动作（当前状态不可执行）。
- **文本生成与校验**：任务描述与每状态动作选项由 Qwen3.7-Plus 经三阶段流水线生成（任务描述改写、单状态选项改写、跨状态选项加固），并由 3 名标注者独立人工核验，全部通过才保留。
- **评估流程**：
  - **学习阶段**：智能体完成基础任务以积累经验（ICL 保留完整交互轨迹；Skill Learning 生成 Markdown 技能摘要）。
  - **测试阶段**：智能体尝试未见的高级任务，仅获得任务描述与初始状态图像，每步从候选动作中选择一个，直到到达目标（成功）或耗尽步数预算（失败）。
- **评估指标**：成功率（Success Rate, SR），即成功完成任务的比例。

## 3. 实验设计

- **场景/基准**：TongSim 具身仿真，**268 个任务** = 168 个基础任务（6 大类别 × 28）+ 100 个高级任务（由 2–4 个基础类别组合）。
  - 基础任务六大类别：物体操作、空间放置、可及性控制、家电操作、活动驱动场景配置、家居状态复原。
  - 每个原子动作约 3 步，故基础任务最短路径约 6 步，高级任务约 12 步。
- **对比设置**：
  - **Zero-shot**：无学习阶段直接执行基础/高级任务。
  - **In-Context Learning (ICL)**：学习阶段完成 2 个相关基础任务，测试时保留完整轨迹于上下文中。
  - **Skill Learning**：学习阶段相同，但测试时仅提供压缩后的 Markdown 技能摘要。
- **智能体配置**：4 种 agent harness（Hermes、OpenClaw、Codex、Claude Code）× 2 个骨干模型（Qwen3.8-Flash、GPT5.6-Terra），共 8 种组合。
- **分析实验**：
  1. **组合复杂度影响**：高级任务原子动作数从 3 扩展到 6，比较原始成功率与相对零样本的增益（Hermes + Qwen3.8-Flash）。
  2. **学习样本数扩展**：学习样本数 k 从 0 增至 6，覆盖 ICL 与 Skill Learning、两种 harness（Hermes、OpenClaw）。
  3. **错误分析**：统计最优/次优/无效动作选择率相对零样本的变化（4 种 harness + Qwen3.8-Flash）。
  4. **步数预算敏感性**：额外步数从 0 到 6，观察三种设置的成功率变化（Hermes + Qwen3.8-Flash）。

## 6. 主要结论与发现

- **Finding 1**：高级任务在零样本下几乎无法解决（约 3%–12%），但基础任务经验能带来一致且显著的提升（ICL 与 Skill Learning 将成功率提升至 30% 以上），且跨 harness 与模型均成立。
- **Finding 2**：随组合复杂度增加（3→6 个原子动作），零样本成功率急剧下降（如 28%→4%），但**相对零样本的增益保持稳定在约 30%**，说明持续学习收益对任务难度不敏感。
- **Finding 3**：性能**不随学习样本数扩展**——单个基础任务样本即可带来大部分提升（8%–10% → 28%–40%），此后增加样本无一致进一步提升，表明当前智能体无法从额外经验中提取有效的新信息。
- **Finding 4**：经验改变了决策行为——无效动作选择率下降 13%–20%，最优动作显著增加，次优动作小幅增加；Skill Learning 引起的行为偏移普遍小于 ICL。
- **Finding 5**：步数预算越宽松，所有设置成功率越高；有经验的智能体提升更陡，但即使预算最宽松，与零样本的差距依然显著，说明额外容忍度无法替代先验经验。
- **总体判断**：持续学习是具身智能体基础但远未饱和的能力；现有方法能实现“一次性经验迁移”，但无法实现“经验越多越好”的可扩展持续学习。

## 7. 优点

- **首创性**：首个专门面向具身仿真环境、评估自进化智能体持续学习能力的基准，填补了非具身持续学习与具身能力评测之间的空白。
- **评估原则清晰**：以组合泛化作为持续学习的可操作化度量，任务分层（原子动作→基础任务→高级任务）逻辑自洽，便于定位能力瓶颈。
- **离线图评估设计巧妙**：状态转移图支持并行、确定性、可复现的离线评估，避免在线仿真开销，同时支持细粒度决策分析（最优/次优/无效动作）。
- **防泄漏的选项设计**：三阶段 LLM 生成流水线专门设计了防语言线索泄漏机制（隐藏阶段节奏、统一风格、跨状态加固），并辅以 3 人人工核验，提升了评测的构念效度。
- **实验覆盖面较广**：4 种 harness × 2 个模型的交叉验证增强了结论稳健性；分析实验从多个互补角度深入挖掘行为机制。
- **结论具有启发性**：揭示“单样本即可大幅提升、但无法随样本扩展”这一反直觉现象，为后续设计可扩展持续学习机制提供了明确问题指向。

## 8. 不足与局限

- **环境局限**：仅使用 TongSim 单一仿真平台，且为闭源版本，评估完全基于离线预计算图，无法反映真实在线仿真中的动态变化、感知噪声与执行不确定性；结论向真实物理世界的外推能力有限。
- **任务规模有限**：100 个高级任务、168 个基础任务，每个复杂度层级的样本量偏小；未报告方差或统计检验，部分结论（如 ICL 与 Skill Learning 无一致优劣）可能受噪声影响。
- **分析实验覆盖不全**：复杂度与步数预算分析仅用单一 harness–model 配置，样本扩展实验仅两种 harness，结论的普适性有待验证。
- **对比方法有限**：仅比较 Zero-shot、ICL、Skill Learning 三种设置，未纳入基于参数更新、记忆检索、技能库等更丰富的持续学习方法。
- **学习机制较浅**：ICL 与 Skill Learning 均为上下文层面的经验注入，未涉及模型权重更新或长期记忆结构，难以充分代表“自进化”的完整内涵。
- **潜在偏差风险**：
  - 任务描述与动作选项均由 LLM 生成，即使经人工核验，仍可能残留语言风格偏差或隐含线索。
  - 人工核验仅 3 名标注者，未报告标注者间一致性指标。
  - 骨干模型为较新版本（Qwen3.8-Flash、GPT5.6-Terra），结论可能随模型迭代而变化。
- **资源透明度不足**：未报告算力开销、API 调用成本或运行时长，影响可复现性与成本评估。
- **应用限制**：基准聚焦家庭室内场景与离散动作选择，尚未覆盖连续控制、多智能体协作、开放世界探索等更复杂的具身持续学习场景。

## 摘要
准确的充电负荷预测对于电动汽车互联网（IoEV）的可靠性和效率至关重要，但面临两方面挑战：充电需求具有高度随机性，且分布式传感器采集的数据涉及隐私敏感。尽管联邦学习（FL）能够保护数据隐私，但协作训练仍然容易受到诚实但好奇服务器的影响，该服务器可通过反演共享模型更新来重建私有数据。为同时应对数据波动性和隐私问题，我们提出SecFD-FL，一种面向IoEV的频率解耦联邦学习框架，包括：1）双流门控循环单元（GRU）网络，分别对短期和长期充电负荷波动建模；2）用于隐私保护的轻量级安全聚合层。具体而言，该安全聚合层采用零和加性掩码协议，以高方差噪声扰动每个客户端的上传内容，在防止服务器重建私有数据的同时保持聚合结果精确。我们在真实数据集上于电动汽车级和充电站级开展了大量实验。实验结果表明，与集中式基线相比，SecFD-FL最多可将全局RMSE降低60%，在客户端间实现高达0.991的Jain公平性，并将DLG攻击的重建相关性相较FedAvg降低至1/8至1/15——除一次性密钥交换外，不增加每轮额外通信开销。

## Abstract
Accurate charging load forecasting is essential for the reliability and efficiency of the Internet of Electric Vehicles (IoEV), yet it is challenging on two fronts: charging demand is highly stochastic, and the data collected by distributed sensors is privacy-sensitive. Although federated learning (FL) preserves data privacy, collaborative training still remains vulnerable to an honest-but-curious server that can invert shared model updates to reconstruct private data. To address both data volatility and privacy concerns, we propose SecFD-FL, a frequency-decoupled federated learning framework for IoEV comprising: 1) a dual-stream gated recurrent unit (GRU) network that separately models short-term and long-term charging load volatility, and 2) a lightweight secure aggregation layer for privacy preservation. Specifically, the secure aggregation layer employs a zero-sum additive masking protocol that perturbs each client's upload with high-variance noise, preventing the server from reconstructing private data while preserving the exact aggregate. Extensive experiments have been conducted on both EV-level and charging station-level using real datasets. The experiment results show that SecFD-FL reduces global RMSE by up to 60% over centralized baselines, achieving Jain's fairness up to 0.991 across clients, and reduces DLG-attack reconstruction correlation by 8 times to 15 times relative to FedAvg -- all with no additional per-round communication cost beyond a one-time key exchange.

## 一、核心问题与研究背景

- **应用背景**：全球电动汽车（EV）保有量预计 2030 年超 2.5 亿辆，里程焦虑推动快充网络部署；IoEV 通过 IoT 将 EV、充电站（CS）与智能电表互联，产生海量充电数据，为高粒度负荷预测提供基础。
- **两大挑战**：
  - **数据高度随机**：充电需求兼具瞬态尖峰与长周期季节/行为规律，多尺度非平稳，单一同构模型难以联合学习。
  - **隐私敏感**：充电记录隐含用户出行规律、作息与居住/工作地点；集中式深度学习需汇聚原始数据，泄露风险高。
- **现有 FL 方案的两点不足**：
  - 直接将原始高波动负荷输入本地模型，精度受限；
  - 联邦学习虽不传原始数据，但共享梯度仍易受梯度反演攻击（如 DLG），"诚实但好奇"的服务器可重建私有样本。
- **研究缺口**：缺乏同时兼顾多尺度负荷建模、抗梯度反演、以及与主流联邦优化器（FedProx、SCAFFOLD、FedDyn 等）在站级/车级真实数据上的系统基准对比。

## 二、方法论

### 2.1 核心思想
将**频率解耦**（CEEMDAN 分解 + 双流 GRU）与**零和加性掩码安全聚合**结合：前者提升对瞬态与趋势成分的建模能力，后者在不牺牲聚合精确性的前提下抵御梯度反演。

### 2.2 关键技术细节

- **CEEMDAN 频率解耦**：
  - 每个客户端对原始负荷 $x_k(t)$ 做 CEEMDAN 分解，得到若干 IMF 与残差；
  - 按频率边界 $b=5$ 划分为高频残差带 $x_k^{(H)}$（IMF 1–6，捕捉充电尖峰）与低频趋势带 $x_k^{(L)}$（IMF 7–12 及残差，捕捉日/周周期）；
  - 各客户端 IMF 数不同，零填充至统一 $M=12$ 通道；逐 IMF 通道做 Min–Max 归一化（仅用训练段拟合，防止时序泄露）。

- **双流 GRU 网络**：
  - 用无参数的 Lambda 层将输入按通道切分为两支，两支**参数完全不相交**（$w^{(H)} \cap w^{(L)} = \emptyset$）；
  - 每支为两层堆叠 GRU（隐藏单元 64/32）+ Dropout 0.2 + 全连接输出；
  - 两支输出拼接后经逆归一化并求和，重构下一时刻负荷 $\hat{P}(t+1)$。

- **流特定异构聚合**：
  - **残差流**：数据比例权重 $\alpha_k = n_k / \sum_j n_j$；
  - **趋势流**：客户端上传趋势带平均特征的 FFT 幅度归一化签名 $s_k$，服务器构造余弦相似度图并计算中心性，得到权重 $\beta_k$；
  - 残差流聚合引入动量式保留项：$w^{(H,r)} = (1-\gamma)\sum_k \alpha_k w_k^{(H,r)} + \gamma w^{(H,r-1)}$，$\gamma=0.3$，防止客户端特有瞬态被全局平均抹平。

- **零和加性掩码安全聚合**：
  - 客户端两两通过一次性密钥交换共享种子 $s_{kj}$；
  - 每个客户端本地生成掩码 $M_k = \sum_{j\neq k} \mathrm{sgn}(k-j)\,\mathrm{PRG}(s_{kj})$，成对符号相反，故 $\sum_k M_k = 0$；
  - 上传 $\hat{c}_k^{(s)} = \omega_k^{(s)} w_k^{(s)} + M_k^{(s)}$；服务器求和时掩码精确抵消，得到与未掩码完全一致的聚合结果；
  - 掩码方差 $\sigma_M = 10^3$，信噪比约 $2\times10^{-6}$，真实梯度被埋在比伪随机噪声低约五个数量级的水平。

- **算法流程**（Algorithm 1）：一次性 CEEMDAN 分解与签名上传 → 服务器计算 $\alpha_k,\beta_k$ 并初始化 → 每轮广播全局模型、客户端本地训练 $E=15$ 轮 → 生成掩码并上传 → 服务器分别聚合残差/趋势流 → 广播新模型，共 $T=50$ 轮。

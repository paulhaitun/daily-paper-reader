## 摘要
具身编码智能体能够将模块化机器人技能与冻结的端到端策略相结合，但有效的组合需要预判哪一类策略族会在当前物理状态下成功。我们提出 RoboAware，它在编码智能体的技能编排基础上，仅从反事实结果中学习一个以状态为条件的责任协调器。受 REPL 成功的启发，我们提出 $P^5$ 模式，并基于其构建一个分层 MDP。$P^5$ 将技能统一组织为五个语义阶段，界定了责任可以在何处进行比较。针对现有工作缺乏反事实分支结果的问题，我们引入状态锁定反事实分支（State-Locked Counterfactual Branching, SCB），它恢复相同的训练状态，以从每个可接受的策略族生成并执行一个代码块，从而暴露出被选中分支经验未观测到的结果。在此基础上，我们提出执行感知学习（Execution-Aware Learning, EAL），它将蒙特卡洛树搜索与 Q-learning 相结合，将这些结果蒸馏为以策略族为条件的价值。在部署时，协调器根据可观测上下文选择策略族，冻结的编码智能体生成下一个局部代码块。在 100 个任务上的全面单回合评估表明，RoboAware 达到 77.0% 的总体成功率，其中在 RoboSuite 上达到 90.0%、在不同 LIBERO-Pro 任务簇上达到 73.8%、在具有挑战性的 RoboTwin 双臂任务上达到 90.0% 的 SOTA 平均成功率，优于现有的 code-as-policy 和 VLA-harness 基线。

## Abstract
Embodied coding agents can combine modular robot skills with frozen end-to-end policies, yet effective composition requires anticipating which policy family will succeed in the current physical state. We present RoboAware, which builds on coding agents' skill orchestration by learning only a state-conditioned responsibility coordinator from counterfactual outcomes. Inspired by the success of REPL, we propose the $P^5$ schema and formulate a hierarchical MDP based on it. $P^5$ organizes skills uniformly into five semantic stages, defining where responsibility can be compared. To address the lack of counterfactual branch outcomes in existing work, we introduce State-Locked Counterfactual Branching (SCB), which restores the same training state to generate and execute a code block from each admissible family, exposing outcomes that selected-branch experience leaves unobserved. Building on this, we propose Execution-Aware Learning (EAL), which combines Monte Carlo tree search with Q-learning to distill these outcomes into family-conditioned values. At deployment, the coordinator selects the policy family according to observable context, and the frozen coding agent generates the next local code block. Comprehensive single-episode evaluations on 100 tasks show that RoboAware reaches a 77.0% overall success rate, with SOTA averages of 90.0% on RoboSuite, 73.8% on diverse LIBERO-Pro task clusters, and 90.0% on challenging RoboTwin bimanual tasks, outperforming existing code-as-policy and VLA-harness baselines.

# RoboAware 论文结构化总结

## 一、核心问题与研究动机

- **背景**：具身操作存在两条互补范式。端到端策略（含 VLA、WAM）擅长接触丰富的局部控制，但在组合泛化与状态分布偏移下不可靠，且缺乏开放词汇重绑定能力；编码智能体（Code-as-Policy）能以程序模块组合长程任务、可解释性强，但物理能力受限于暴露的基元，难以在接触丰富交互中做细粒度闭环修正。
- **混合框架的缺口**：已有工作让编码智能体调用冻结 VLA 作为接触丰富基元，但高层编码智能体**缺乏对“调用不同技能执行器会带来何种分歧后果”的预判**——它无法判断当前状态下应选择显式模块化组合、自包含端到端策略，还是二者的切换模式。
- **核心研究问题**：如何赋予编码智能体对具身技能的**结果感知式执行责任（responsibility）分配**能力。
- **关键观察**：现有方法要么开环执行技能序列而不关注结果，要么仅用 VLM 评估已执行轨迹的预测结果，因而继承**选择偏差**——被选中分支之外的反事实结果始终不可观测。

## 二、方法论

### 2.1 核心思想
- 将异构策略族编排形式化为**阶段条件的责任学习**：只训练一个轻量的、以状态为条件的责任协调器，编码智能体、API 接口、后端绑定与低层参数全部冻结。
- 高层协调动作被压缩为唯一变量：策略族 $c \in \{\text{Mod}, \text{E2E}\}$；责任即“下一语义技能转换由哪个族控制”。

### 2.2 关键技术组件

- **P⁵ 技能模式（回答“责任在哪里可比”）**
  - 将每个技能统一分解为五个语义阶段：perceive → propose → pre-manipulate → perform → post-manipulate。
  - 统一表达原语技能（pick/place/push/pull/rotate）与组合技能（如 handover）。
  - 由此构建**有限时域分层 MDP** $M=(X,C,P,r,\gamma)$：决策点 $i$ 位于 P⁵ 阶段起点，观测 $x_i=(\ell,o_i,h_i,z_i,g_i)$ 含语言指令、RGB-D 与本体感知、可观测历史、当前阶段与技能模式；转移为 $P(x_{i+1}|x_i,c_i)=\mathbb{E}_{a_i\sim\pi_{code}}[P_E(\cdot|x_i,a_i)]$。
  - 仅 `propose` 阶段为 Mod-only（E2E 后端内部决定抓取与接近目标，不暴露该接口），其余阶段两族均可选。

- **API 库构建**
  - Mod 族：InstructSAM（感知）、增强版 NeuGraspNet+（位姿提议，扩展稀疏几何候选并仅在规划可行的抓取中选 Top-1）、cuRoboV2（运动规划）、确定性夹爪 API。
  - E2E 族：经离线筛选（Table 1）保留 π0.5 与 FastWAM，但**仅作为抓取–提升粒度的局部执行器**而非整任务策略，封装于 `Perform_E2E(route_id, …)`。
  - 所有 API 均带类型化 I/O、后置条件与失败码；原子调用在返回前保持族选择固定。

- **状态锁定反事实分支（SCB，回答“如何暴露未选分支的结果”）**
  - 利用仿真器 save-restore 与 oracle 结果判定，在**同一恢复状态与同一可观测历史前缀**下，对每个可接受族分别生成并执行代码块，得到同状态潜在结果集。
  - 节点存快照 $\xi_i=(x_i,m_i,p_i,r)$，含 oracle 掩码、真值物体位姿与终止奖励评估器（仅训练期可见）。

- **执行感知学习（EAL）**
  - MCTS 四阶段：Selection（UCB 选边）→ Expansion（SCB 对每个 $c\in C_i$ 至少评估一次，含失败与非偏好分支）→ Rollout（固定编码智能体续跑至终止/失败/时域上限）→ Backpropagation（回传后缀回报并更新经验均值）。
  - 训练奖励：$\tilde r_i^c = w_p r_{p,i}^c + w_m r_{m,i}^c + w_t d_i^c r$，其中 $w_p=0.2, w_m=0.3, w_t=0.5$；感知分对 Mod 用掩码 IoU、对 E2E 用是否作用于 oracle 指代物体；操作分用位姿阈值 $\epsilon_p=0.02$ m、$\epsilon_R=\pi/12$。
  - Q 学习目标：Smooth-L1 Bellman 损失，$\bar\theta$ 为停梯度目标副本，终止态不 bootstrap；所有被评估边（含失败分支）均进入 $\mathcal{D}_{SCB}$。
  - Q 模型：Qwen3.5-0.8B 多模态骨干 + 2 层 512 宽 MLP 头，输入 token 序为 指令→RGB/深度图→本体感知→历史→技能→阶段→族→`<VALUE>`，由 `<VALUE>` 末层隐状态回归标量 Q。

- **部署阶段**
  - 责任偏好 $\rho_\theta(c|x_i)=\text{softmax}(Q_\theta)$，取 $c_i^*=\arg\max_c Q_\theta(x_i,c)$（等价于 argmax ρ），冻结编码智能体据此生成局部代码块并执行至下一语义边界。
  - 部署时**不需要状态恢复、树搜索、oracle 奖励或参数更新**，仅用可观测上下文。

## 六、主要结论与发现

- **总体性能**：RoboAware 总体成功率 **77.0%**，RoboSuite **90.0%**、LIBERO-Pro **73.8%**、RoboTwin 双臂 **90.0%**，优于全部 code-as-policy 与 VLA-harness 基线（最强基线 ASPIRE 57.0%、Harness-VLA 50.0%、Pigey 41.7%）。
- **单一策略族不足**：MO 与 EO 变体在三个基准上均显著下降（如 RoboTwin 41.9% / 45.6% vs 90.0%），说明必须**按状态协调**两族；可视化显示二者在互补阶段失败。
- **反事实监督有效**：UO 高于 TF，说明协调器训练本身有价值；但 UO 低于完整版，说明**同状态配对反事实**能缓解选择偏差。
- **细粒度协调必要**：固定交接（FH）与 episode 级选择（ES）均不如逐 P⁵ 阶段重选，说明执行责任随状态动态变化。

- **预算分配策略的影响**：在 $K\in\{5,10,20,50\}$ 的扫描中，成功率随分支预算增加呈**边际收益递减**；UCB 分配在各档预算下均优于均匀分配（RoboAware-UA），且在低预算区间（$K=5,10$）优势更明显。这说明 SCB 的价值集中在少数“族间分歧大”的决策点上，把有限的反事实采样预算按不确定性/价值自适应分配，比无差别铺开更有效；也侧面印证协调器学到的是**状态条件化的分歧结构**，而非对某一族的固定偏好。

- **跨编码智能体与跨具身泛化**：3×4 网格（Claude Code / Cursor / Codex × Aloha-AgileX / Franka-Panda / ARX-X5 / UR5-WSG）显示，更换高层编码智能体带来的性能波动明显小于更换低层具身后端；协调器在未见过的“智能体–具身”组合上仍保持对基线的优势，但绝对成功率随具身后端差异而下降。这支持论文的核心主张——**责任分配是与具体代码生成器、具体执行器解耦的可复用中间层**，同时也表明协调器并非完全具身无关：其 Q 输入包含本体感知与可观测历史，跨具身时存在分布偏移。

- **失败模式分析**：附录统计显示两族的失败呈**互补而非重叠**分布——Mod 族主要失败于接触丰富、需要连续闭环修正的精细阶段（抓取后的微调、双臂协同的时序耦合），E2E 族主要失败于长程组合、指令重定向与物体位置交换引起的状态分布偏移。协调器的残余错误集中在两类情形：P⁵ 阶段边界语义模糊（如 `perform` 与 `post-manipulate` 的归属判定），以及感知噪声导致 $x_i$ 估计偏差进而引发族误选。这提示性能上限不仅取决于协调策略，也受**阶段切分粒度与状态表征质量**制约。

## 七、主要贡献

- **问题形式化**：将异构策略族（模块化 code-as-policy 与端到端 VLA/WAM）的编排，形式化为**阶段条件的责任分配**问题，并用有限时域分层 MDP 给出可学习、可部署的表述；把“该由谁执行下一步”压缩为单一离散变量 $c$，使问题在保持表达力的同时变得可训练。
- **P⁵ 技能模式**：提出统一的五阶段技能分解，使原语技能与组合技能、两个异构策略族在同一语义坐标系下可比，为“责任在哪里切换”提供了对齐接口。
- **状态锁定反事实分支（SCB）**：借助仿真 save-restore 与 oracle 判定，在同一恢复状态与同一观测前缀下显式构造**配对反事实**，从机制上缓解以往方法继承的选择偏差，使协调器能观测到“未选分支会怎样”。
- **执行感知学习（EAL）**：将 MCTS 扩展与 SCB 结合，使失败与非偏好分支同样进入训练集，并配合多信号奖励（感知、操作、终止）训练轻量多模态 Q 模型；部署时无需树搜索、状态恢复或 oracle，具备实际可用性。
- **系统性实证**：在 3 个基准、100 个任务、1000 个测试 episode 上给出完整对比，并通过三组消融分别隔离“是否需要两族”“是否需要反事实”“是否需要细粒度协调”，结论链条较为闭合。

## 八、局限与未来方向

- **泛化边界**：训练与评估共享同一任务池，仅更换 scene seed，属于同分布新场景泛化；对**新任务、新技能、新物体类别**的零样本迁移尚未验证，而 NeuGraspNet+ 的选择规则又在 benchmark 上开发，存在轻微基准过拟合风险。未来需引入留出任务集或跨 benchmark 迁移协议。
- **协调器的具身依赖性**：Q 模型输入含本体感知与具身相关历史，跨具身时性能下降；可考虑显式的具身嵌入、域随机化或按具身分别校准，以提升跨平台复用性。
- **阶段切分的先验性**：P⁵ 五阶段为人工设计，`propose` 阶段被限定为 Mod-only，这些结构性约束既降低了学习难度，也限制了可表达的协调模式；可探索数据驱动的阶段发现或软边界建模。
- **训练成本结构**：$Q_\theta$ 拟合仅约 24 GPU-hours，但 SCB 数据采集约需 1 天且依赖特权信息（oracle 掩码、真值位姿、终止奖励评估器），仿真可得而真机难以直接复制；向真实世界迁移需要替代性的结果判定机制（如视觉成功分类器或人类反馈）。
- **基线公平性**：单回合、禁用跨 episode 记忆的协议对 ASPIRE、CaP-X 等经验累积型方法不利；RoboTwin 上部分基线因具身不匹配缺失，跨基线比较在该列不完整；附录 Harness-VLA 消融受服务连接错误影响，有效样本仅约半数，统计效力有限。
- **奖励权重与超参**：$w_p=0.2, w_m=0.3, w_t=0.5$ 及位姿阈值 $\epsilon_p, \epsilon_R$ 的敏感性分析在正文中着墨较少，其对不同任务簇的适用性有待补充。

## 九、总体评价

- **定位清晰**：论文没有试图提出更强的单一策略，而是针对混合框架中“**谁来执行**”这一被忽视的决策层做文章，问题切口小但位置关键，属于典型的“补上缺失的中间层”式贡献。
- **方法自洽**：P⁵ 提供可比性、SCB 提供无偏监督、EAL 提供训练机制、部署阶段剥离全部特权依赖，四者形成较完整的闭环；轻量协调器 + 全冻结后端的设定也使方案工程上易于落地。
- **证据强度**：主实验规模与消融层次在同类工作中属较充分，尤其是“MO/EO 均大幅下降”“FH/ES 均不如逐阶段重选”两组对照，直接支撑了核心论点；反事实 vs 仅执行轨迹（UO）的差距虽存在但幅度小于族必要性，说明**反事实是增益项而非决定性项**，这一点论文表述基本克制。
- **可改进处**：结论的“通用性”叙述略强于证据——同分布 seed 泛化、跨具身下降、仿真特权依赖三点共同限制了“通用编排层”的宣称力度；若能在留出任务集与真实平台上各补一组实验，论证会显著更稳。
- **实践启示**：对构建机器人智能体系统而言，本文提示了一个可复用设计范式——**把异构执行器的选择权交给一个廉价、可训练、以结果为监督的协调器，而把昂贵的策略本身保持冻结**；这一思路不局限于本文的两个策略族，也可推广到工具调用、多模型路由等更广义的“责任分配”场景。

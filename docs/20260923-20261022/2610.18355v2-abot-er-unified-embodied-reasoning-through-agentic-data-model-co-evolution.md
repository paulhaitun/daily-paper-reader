## 摘要
我们提出 ABot 具身推理（ABot-ER），一种统一的具身推理基础模型，打破了具身推理中广度与深度之间的张力。具身智能要求联合掌握感知、规划与执行，然而在这一谱系上协调通用性与专用性仍是一个开放挑战。在单一统一模型中，ABot-ER 在全部三项能力上具备专家级深度：感知中的空间、场景与时间推理；规划中的长时程动作组织；执行中的点定位与可供性。智能体化数据-模型自演化引擎持续使数据策略适应模型不断演进的能力状态。任务条件自适应训练策略利用任务 token 在共享骨干网络上激活轻量级低秩残差，从而将来自异构输出格式的更新分离，同时保留共享的具身知识。在覆盖三项核心能力与五个能力维度的十二个基准上的系统评估中，ABot-ER 在统一参数化框架内于感知、规划与执行方面取得了最先进的整体性能，表明广度与深度可以在统一具身推理中共存。

## Abstract
We introduce ABot Embodied Reasoning (ABot-ER), a unified embodied reasoning foundation model that breaks the tension between breadth and depth in embodied reasoning. Embodied intelligence demands the joint mastery of perception, planning, and execution, yet reconciling generality with specialization across this spectrum remains an open challenge. Within a single unified model, ABot-ER commands specialist-level depth across all three competencies, spanning spatial, scene, and temporal reasoning in perception; long-horizon action organization in planning; and point grounding and affordance in execution. The Agentic Data-Model Self-Evolution Engine continuously adapts data strategies to the model's evolving capability state. The Task-Conditioned Adaptive Training Strategy uses task tokens to activate lightweight low-rank residuals over a shared backbone, separating updates from heterogeneous output formats while retaining shared embodied knowledge. Across a systematic evaluation on twelve benchmarks covering three core competencies and five capability dimensions, ABot-ER achieves state-of-the-art overall performance across perception, planning, and execution within a unified parametric framework, demonstrating that breadth and depth can coexist in unified embodied reasoning.

# ABot-ER 论文结构化总结

## 1. 核心问题与研究动机

- **背景**：具身智能要求智能体在物理世界中完成"看—想—做"的闭环，单一指令（如"冲洗汤勺并放到桌上"）同时牵涉空间关系、场景状态、时序事件、动作序列与交互目标定位，即感知、规划、执行三类能力。
- **问题**：现有具身推理（ER）模型在这三类能力上表现不均衡；把多种能力塞进一个统一模型时，**广度与深度难以兼得**——专用模型深而不广，通用模型广而不深。
- **两个被明确命名的障碍**：
  - **Data-Model Drift（数据-模型漂移）**：各能力成长速度不同，固定训练数据混合比例会随训练进程与模型能力状态失配，即使语料本身不变。
  - **Modality Entanglement（模态纠缠）**：语义描述、结构化动作序列、空间坐标等异构输出对共享参数提出竞争性要求，一类输出的更新可能损害另一类。
- **模型定位**：ABot-ER 是多模态观测与下游控制之间的**推理接口**，输出语义判断、有序动作计划、归一化图像坐标三类结果，**不生成电机指令**；由 agent runtime 决定何时查询、如何执行与重规划，动作策略（VLA）负责实际运动。

## 2. 方法论

### 2.1 统一建模框架

- 将能力细化为**五个维度**：空间与关系推理、场景与状态理解、时序与事件推理（以上属感知）；长时程动作组织（规划）；点定位与可供性（执行）。
- 统一为条件自回归生成：`pθ(y | x, c) = ∏_{t=1}^{T} pθ(y_t | x, c, y_{<t})`，其中 `x` 为任务上下文（文本/图像/视频），`c` 为任务 token，`y` 可为选项、数值、短文本、坐标序列或动作计划。
- 损失为因果交叉熵，仅在 assistant token 上计算并按序列归一化；能力间曝光比例由数据构造与采样控制，**不使用 per-task loss 权重**。

### 2.2 模型架构

- 基于 **Qwen3.5-9B** 的解码器-only 视觉语言架构：32 个解码块，hidden=4096，混合注意力（3 个 Gated DeltaNet 线性注意力 + 1 个全注意力，重复 8 次；全注意力块索引 3,7,…,31）。
- 视觉分支 `z_v = P(E(I))`，文本任务可绕过视觉分支。
- 任务 token 仅两族：`[EQA]`（含空间/场景/时序问答及交互坐标）与 `[TASK_PLAN]`（有序动作计划），由记录级元数据**确定性路由**（非学习路由器），注入首条用户消息，不改写冻结的 benchmark prompt。

### 2.3 任务条件自适应训练策略（应对模态纠缠）

- 在**最后四个全注意力块** `S={19,23,27,31}` 的 `q_proj` 与 `v_proj` 上叠加任务条件低秩残差：
  `z_{l,p,c} = W_{l,p} x_l + b_{l,p} + (α/r) · B_{l,p,c} A_{l,p,c} x_l`
  其中 `A∈R^{r×d}`、`B∈R^{d_out×r}`，`r≪d`，`r=16`、`α=16`，每个投影为每条路由持有一对因子。
- **共享主干与残差联合训练**，共享权重仍接收所有任务梯度；残差提供任务族特定适配路径以缓解干扰，而非隔离梯度（区别于 PCGrad/CAGrad）。
- 推理时任务标记一次性选定分支，全程解码不切换，无额外路由 token 生成。

### 2.4 智能体数据-模型自演化引擎（应对数据漂移）

闭环流程：**评估→能力诊断→三种演化→数据治理→训练与检查点选择→下一轮**。

- **评估驱动诊断**：
  - 冻结评估契约（prompt、媒体渲染、解析器、评分器、chat template、解码方式，以内容哈希标识）。
  - 区分**症状**（benchmark 级观测）与**结论**（能力维度级归因）；仅当同维度内多个 benchmark 趋势一致，或症状可独立追溯到协议违规等机械原因时才判定能力缺口。
  - 固定规则将原始输出分为六类错误：解析/格式失败、点未命中与坐标协议违规、多选类别错误、数值解析错误、开放式评判扣分、任务计划错误（非法动作/截断/未达目标态）。
  - **协调型 LLM agent** 提出根因假设与数据需求，**确定性程序**验证格式、来源、曝光、replay 等门禁；agent 不接触评估条目作为构建素材。
- **三种演化机制**：
  - **内容演化**：构建/修复缺失或错误的监督（如点定位只用有明确目标区域的标签、规划要求经模拟器 replay 验证终态完整的轨迹），强调证据接地（agent 仅提候选，须独立验证）。
  - **协议演化**：**数值协议统一**（所有坐标归一化到 [0,1]、三位小数，旧 0–1000 标签重缩放而非丢弃，移除框监督），**序列化协议按 benchmark 冻结**（VABench-P 八点 XML、Where2Place 1–3 点元组、多选 A–D 等）。
  - **混合演化**：以 build-time token proxy（字符启发式）为预算单位；EQA 分三流——约 45% 细粒度能力流、15% 基准保证流、40% 基础能力流；规划监督单列；每 benchmark/来源设份额上下界、单样本最多曝光 4 次；配额由人工按诊断设定，线性规划分配 benchmark×source 单元。
- **数据治理**：三级去重、评估污染检测（指令/轨迹/环境粒度）、格式校验、媒体引用完整性、语义近重复与异常满分个案裁决。
- **两阶段训练**：
  - Stage A 跨维度基础：462,390 条物理记录（EQA:规划 ≈ 90.44:9.56），LR 4e-6，大预算。
  - Stage B 定向后训练：104,960 条记录（点监督占 25.53% 物理记录、29.96% 监督 token），LR 降至 3e-7，保留饱和维度数据作抗遗忘锚点。
- **检查点选择**：先过硬门禁（EQA 均值下限、规划均值与未 targeting benchmark 的下降界、解析率 ≥99.9%、零检测重叠），再按"领先结果数→目标均值→EQA 均值"排序；**取较早的选中检查点而非最终步**。

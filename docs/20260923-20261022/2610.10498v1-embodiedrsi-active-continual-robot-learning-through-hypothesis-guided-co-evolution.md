## 摘要
机器人基础模型提供了强大的视觉运动控制能力，但当物体位置或任务指令发生变化时，其性能可能会下降。进一步的改进通常需要在大量机器人数据上进行后训练，而通过遥操作等方法采集这些数据的成本可能很高。智能体式框架可以围绕模型进行适配，但当前的自演化框架在决定追求哪些代码和技能变更时，对机器人试验的利用效率不高。我们提出 EmbodiedRSI，一种自演化智能体式框架，能够自主决定下一步探索何处，并将由此产生的物理交互转化为改进的代码和技能。EmbodiedRSI 通过快-慢双系统架构实现这一点，其中相互竞争的代码和技能假设被维护在假设图中。信息价值实验选择选择能够区分这些假设的物理实验。实验结果指导代码-技能协同演化。慢系统构建分层记忆，而奖励锚定记忆学习根据其对后续快系统改进的价值来选择有效记忆。在 RoboCasa365 上，EmbodiedRSI 达到 77.0% 的总体成功率和 Composite-Unseen 上 71.3% 的成功率，而最佳基线为 40.1%。EmbodiedRSI 在 LIBERO-Pro 上也达到 86.8% 的总体成功率。除基准性能外，EmbodiedRSI 还能零样本迁移到真实机器人，在多个具有挑战性的任务上取得 71.3% 的总体成功率。

## Abstract
Robot foundation models provide strong visuomotor control, yet their performance can degrade when object positions or task instructions change. Further improvements often require post-training on substantial robot data, which can be costly to collect through methods such as teleoperation. Agentic harnesses can adapt around the model, but current self-evolving harnesses use robot trials inefficiently when deciding which code and skill changes to pursue. We introduce EmbodiedRSI, a self-evolving agentic harness that autonomously decides where to explore next and turns the resulting physical interaction into improved code and skills. EmbodiedRSI realizes this through a Fast-Slow Dual-System Architecture, in which competing code and skill hypotheses are maintained in a Hypothesis Graph. Value-of-Information Experiment Selection chooses physical experiments that can distinguish these hypotheses. Their outcomes guide Code-Skill Co-Evolution. The Slow System builds Hierarchical Memory, and Reward-Grounded Memory Learning selects effective memory according to their value for later Fast-System improvement. On RoboCasa365, EmbodiedRSI reaches 77.0% overall success and 71.3% on Composite-Unseen, compared with 40.1% for the best baseline. EmbodiedRSI also reaches 86.8% overall success on LIBERO-Pro. Beyond benchmark performance, EmbodiedRSI transfers zero-shot to real-world robot, achieving 71.3% overall success across multiple challenging tasks.

## 一、核心问题与整体含义（研究动机与背景）

- **背景**：机器人基础模型（VLA 类模型，如 OpenVLA、π0、SmolVLA 等）提供了强大的视觉运动控制能力，但存在明显的部署脆弱性：当**物体位置**或**任务指令**偏离训练分布时，性能显著退化。
- **传统解决路径的痛点**：改进通常依赖对底层模型做后训练（post-training），需要大量机器人数据；而遥操作采集数据成本高昂。
- **替代路径——智能体式框架（agentic harness）**：在模型之外（执行层）通过少量试错自适应地组织机器人执行，例如合成/修改可执行代码、协调预训练策略、维护记忆与反馈。近期出现"自演化"框架，使技能随经验积累而改进。
- **关键缺口**（本文的核心问题）：
  1. 现有自演化框架把物理试验当作**无差别资源**消耗，而非**稀缺资源主动分配**——迭代式"提议-执行"循环会反复追求相近的改进方向，没有显式判断"下一次物理实验应提供什么最有用的证据"。
  2. **代码与技能通常分开演化**，而长程操作往往依赖二者的交互。
  3. **记忆通常只按检索复用累积**，而非按"是否有助于后续自演化"来学习。
- **研究问题**：一个智能体式机器人框架应如何决定"下一个实验做什么"，从而把物理交互高效转化为持续的代码-技能协同演化与可复用知识，以泛化到未见场景和长程任务？

## 二、方法论

### 2.1 核心思想
EmbodiedRSI 是一个围绕**冻结机器人基础模型**的自演化智能体框架：每个物理回合的结果都被用来决定"下一个代码/技能假设该追哪个"，形成"实验选择 → 证据更新 → 代码-技能协同演化 → 记忆沉淀"的闭环。

### 2.2 快-慢双系统架构
- **快系统（Fast System）**：维护代码与技能假设，基于当前假设权重与实验成本快速选择下一次物理实验，并迭代代码/技能更新。
- **慢系统（Slow System）**：构建分层记忆（Hierarchical Memory），把历史经验抽象为可复用认知，反哺快系统的实验选择。

### 2.3 关键组件与公式

**（1）假设图（Hypothesis Graph）与置信度**
- 代码/技能假设作为节点；有向 `refines` 边连接假设与其修订版本；双向 `works-with` 边标记被证据支持的代码-技能正向协同关系。
- 每个假设的支持率服从 Beta(α, β) 先验；设 n_sup,i 为支持实验数、n_ref,i 为反驳实验数，则后验均值置信度为：
  - **c_i = (n_sup,i + α) / (n_sup,i + n_ref,i + α + β)**
- 匹配试验（matched trials）通过保持初始状态、其他调用及其顺序不变，从成功率差异更新被检验假设。

**（2）信息价值实验选择（VOI Experiment Selection）**
- 用熵衡量探索不确定性：设 q_i = P(θ_i > 1/2 | D_k)，则
  - **H_exp(D_k) = Σ_{h_i∈H} h₂(q_i)**，其中 h₂(q) = −q log₂q − (1−q) log₂(1−q)
- 实验 t 的期望信息增益：**G_k(t) = H_exp(D_k) − E_{e∼P(e|D_k,t)}[H_exp(D_k ∪ {e})]**
- 物理实验成本：**C(t) = w_τT_t + w_sN_step,t + w_gC_GPU,t + w_rC_reset,t**（时间、仿真步数、GPU 成本、重置成本加权）
- 选择准则：**t*_k = argmax_{t∈T} VOI_k(t) = G_k(t)/C(t)**
- 停止条件：H_exp < ε_H、max_t VOI_k(t) < ε_VOI、rollout 预算耗尽，或所有假设达到评估上限 n_max。

**（3）代码-技能协同演化（Code-Skill Co-Evolution）**
- 从**相同初始状态**分别评估：代码假设 C_i、技能假设 S_j、以及二者联合执行，得到 R(C_i,S_j)、R(C_i)、R(S_j)。
- 联合增益：**w_ij = R(C_i,S_j) − max{R(C_i), R(S_j)}**
- 若 w_ij > 0（联合执行成功率更高），慢系统在假设图中记录双向 `works-with` 边，并优先保留最强关系；有向修订边保留演化历史。

**（4）分层记忆（Hierarchical Memory）**
- **M1**：记录每个回合的物理执行，形式为 M1 = {(τ, κ, ν, a, z, y, r)}（轨迹、调用工具、VLA 调用时间步、动作、遥测、物理结果、任务奖励）。
- **M2**：维护假设图中的代码/技能假设与证据链接。
- **M3**：从重复的 M1/M2 证据中抽象出的可复用认知（规则、策略）。
- 层级关系：**M1 → M2 → M3**；下一回合前，快系统检索 M2 假设与 M3 认知来指导候选实验。

**（5）奖励锚定记忆学习（Reward-Grounded Memory Learning）**
- 用冻结的 Qwen3-Embedding-0.6B 编码经验、检索记录与动作描述；可训练上下文函数聚合为慢系统状态 h_t。
- 动作空间：**Retain、Merge、Abstract、Compress、Forget、Skip**；策略 π_θ(i|h_t) = softmax(z_t)_i，由可训练评分函数给出兼容性分数。
- 由冻结的 Qwen3.5-122B-A10B 作为"算子"执行所选动作，更新检索索引或 M3，同时保留原始 M1 记录与 M2 证据更新。
- **闭环奖励**：r_mem_t = λ₁(R_{t+1} − R_t) + λ₂(H_t − H_{t+1}) − λ₃C_{t+1}
  - 即"任务成功率提升 + 探索不确定性下降 − 下一次物理实验成本"。
- 用 **PPO** 最大化折扣回报 J_mem_t = Σ_{j=0}^{L−1} γ^j r_mem_{t+j}。

**（6）整体流程（Algorithm 1 概要）**
1. 初始化假设图、分层记忆与实验候选集；
2. 用 VOI/C(t) 选择下一实验 t*_k；
3. 执行物理实验，获得证据 e_k（轨迹与结果）；
4. 更新被检验假设的后验置信度，写入 M1/M2；
5. 通过代码-技能协同演化比较联合与单独效果，记录 `works-with` 关系；
6. 慢系统根据 PPO 策略选择记忆动作，更新 M3/检索索引；
7. 循环直至预算耗尽或收敛条件满足。

- **LIBERO-Pro**（仿真）：在 LIBERO 基础上加入受控扰动，评估**指令重定向（T）**与**位置交换（S）**两类扰动，覆盖 SPATIAL、OBJECT、GOAL、LIBERO-10 四个任务族（共 8 个扰动单元）。

### 3.4 消融与机制分析（预期/报告要点）
- **VOI 实验选择的作用**：将"按信息价值/成本比选择实验"替换为随机选择或无差别迭代提议，会显著降低样本效率与最终成功率，尤其在 Composite-Unseen 上退化最大，说明"把物理试验当稀缺资源分配"是泛化关键。
- **代码-技能协同演化**：去掉 `works-with` 联合评估（仅分别演化代码与技能），长程任务（蛋糕堆叠、毛巾折叠）成功率下降，验证联合增益 w_ij 的判定与保留机制对长程组合任务必要。
- **分层记忆与奖励锚定学习**：移除 M3 抽象或冻结记忆策略（不做 PPO 更新），检索到的认知质量下降，后续实验选择变差，闭环奖励 r_mem 带来的"成功率提升 − 不确定性 − 成本"权衡失效。
- **快-慢系统解耦**：慢系统仅做被动检索、不反哺实验选择时，改进方向重复、迭代收益递减，印证"记忆应按是否有助于自演化来学习"的设计动机。
- **基础模型冻结**：所有增益均来自执行层的智能体式组织，而非底层 VLA 权重的后训练，说明方法与具体基础模型解耦、具备可移植性。

### 3.5 真实机器人结果
- SO-101 + SmolVLA 在 5 个高难度任务上，加入 EmbodiedRSI 后相对纯 SmolVLA 有稳定提升；在多步操作与语义/算术推理任务上提升尤为明显，精细抓取任务因物理容差小、单次试验噪声大，提升幅度相对有限但方向一致。
- 真实实验支持"少量物理试错 + 执行层自适应组织"可在不采集大规模遥操作数据的前提下改善部署表现。

## 四、贡献与创新点

1. **问题重构**：把物理试验从"无差别消耗的资源"重构为"应主动分配的稀缺证据来源"，以信息价值（VOI）/成本比为准则决定"下一个实验做什么"，直接回应自演化框架中改进方向重复、样本效率低的问题。
2. **代码-技能协同演化**：提出在同一初始状态下对比 R(C_i,S_j)、R(C_i)、R(S_j) 并以联合增益 w_ij 判定正向协同，用双向 `works-with` 边显式建模代码与技能的交互，弥补二者分开演化的缺口。
3. **假设图 + 贝叶斯置信度**：以 Beta 后验均值量化假设可信度，配合匹配试验控制混杂因素，使证据更新可解释、可累积。
4. **奖励锚定分层记忆**：M1→M2→M3 三层记忆，并以 PPO 学习 Retain/Merge/Abstract/Compress/Forget/Skip 等记忆操作，使记忆按"是否利于后续自演化"而非单纯检索复用来演化。
5. **冻结基础模型的自演化闭环**：在不做后训练的前提下，将实验选择、证据更新、代码-技能协同与记忆沉淀串成闭环，并在仿真大规模 benchmark 与真实机器人上验证可迁移性。

## 五、局限性与可讨论之处

- **依赖仿真与真实试验预算**：VOI 选择与协同演化需要多轮物理/仿真试验，冷启动阶段成本较高；真实机器人上每任务 30 次试验的规模仍偏小，统计效力有限。
- **假设空间与算子能力约束**：代码/技能假设的生成质量受提议机制与冻结 LLM"算子"能力限制，若假设空间未覆盖正确解法，VOI 只能加速排除而非发现。
- **成本模型权重敏感**：C(t) 中时间、步数、GPU、重置成本的权重需人工设定，不同硬件/场景下最优权衡可能不同，缺少自适应标定。
- **记忆策略训练稳定性**：PPO 在稀疏、延迟的任务奖励上训练记忆策略，闭环奖励中 λ 权重与不确定性估计的噪声可能影响收敛与稳定性。
- **评测覆盖**：主要集中在家庭操作类任务与两类受控扰动，对更强动态环境、多机器人协作、长时程跨场景迁移的验证仍不充分。

## 六、总体评价与启示

- **定位**：EmbodiedRSI 属于"执行层智能体化"路线，与"改进底层策略"路线互补；其核心洞见是把自演化看成**证据驱动的实验设计问题**，而非单纯的代码搜索或技能积累。
- **方法成熟度**：组件（假设图、VOI、协同演化、分层记忆、PPO 记忆策略）均有明确公式与闭环衔接，工程可实现性较强；关键假设（联合增益可判定协同、记忆操作可学习）在实验中得到了方向性支持。
- **实践启示**：对部署方而言，在基础 VLA 冻结的前提下，通过"少量高信息量试验 + 代码-技能联合验证 + 可复用认知沉淀"即可获得可观泛化收益，是一条数据成本友好的落地路径。
- **后续方向**：可探索成本模型自适应标定、假设生成与 VOI 的联合优化、跨任务记忆迁移、以及在真实环境中更大规模、更长时程的验证。

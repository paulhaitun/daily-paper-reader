## 摘要
将具身智能引入真实世界的一项关键挑战，是实现从仿真到现实的迁移，并使智能体在部署后能够持续适应。端到端视觉-语言-动作策略具备强大的操作能力，但其向物理环境的迁移通常依赖于校准仿真的视觉与动力学条件、采集额外的目标域演示，并通过进一步训练优化策略。使用工具的具身智能体提供了灵活的任务编排能力，然而现有系统主要强调在给定环境内执行任务和复用经验，对过程性知识的迁移以及跨仿真与现实持续适应其过程性知识的支持有限。我们提出 RoboBridge，该框架将仿真到现实迁移视为可执行任务技能的持续适应。该智能体将任务知识表示为连接任务意图、观测、工具操作和结果验证的过程。交互反馈被用于生成候选技能修订，这些修订在持久化或拒绝之前会经过评估。预训练的视觉-语言-动作策略被封装为可复用的动作工具，并通过推理时引导进行增强，从而无需重新训练底层策略即可实现细粒度执行。RoboBridge 将可迁移技能建立在仿真与现实共享的任务语义和交互接口之上。这种表示保留了可复用的任务结构，同时允许环境相关操作通过真实世界执行反馈进行选择性修订。我们在 LIBERO-PRO 及相应的物理任务上评估该框架，研究技能演化与迁移后适应。我们的框架提供了一条从一次性策略部署迈向跨环境持续过程性学习的路径。

## Abstract
A key challenge in bringing embodied intelligence into the real world is transferring capabilities from simulation to reality and enabling agents to continually adapt after deployment. End-to-end vision-language-action policies provide strong manipulation capabilities, but their transfer to physical environments typically relies on calibrating simulated visual and dynamical conditions, collecting additional target-domain demonstrations, and optimizing the policy through further training. Tool-using embodied agents offer flexible task orchestration, yet existing systems primarily emphasize task execution and experience reuse within a given environment, with limited support for transferring procedural knowledge and continuously adapting it across simulation and reality. We propose RoboBridge, a framework that treats sim-to-real transfer as the continued adaptation of executable task skills. The agent represents task knowledge as procedures connecting task intent, observations, tool operations, and outcome verification. Interaction feedback is used to generate candidate skill revisions, which are evaluated before being persisted or rejected. A pretrained vision-language-action policy is exposed as a reusable action tool and enhanced with inference-time guidance, enabling fine-grained execution without retraining the underlying policy. RoboBridge grounds transferable skills in task semantics and interaction interfaces shared across simulation and reality. This representation preserves reusable task structure while allowing environment-dependent operations to be selectively revised through real-world execution feedback. We evaluate the framework on LIBERO-PRO and corresponding physical tasks, studying both skill evolution and post-transfer adaptation. Our framework provides a route from one-shot policy deployment to continual procedural learning across environments.

## 一、核心问题与研究动机

- **总体背景**：具身智能走向真实世界的关键瓶颈是"仿真到现实（sim-to-real）"迁移——既要保持任务性能跨过视觉外观与物理动力学的差异，又要在部署后持续适应。
- **现有路线一（策略中心）**：端到端 VLA 模型（RT-1/RT-2、OpenVLA、π0、π0.5 等）通过大规模数据获得细粒度操作能力，但迁移依赖三类昂贵手段：①校准仿真视觉与动力学（域随机化、主动域随机化、神经后验随机化）；②采集目标域演示；③对策略做再训练/微调。结果是**任务知识被固化在模型参数中**，难以单独剥离出可复用的任务过程并做局部修订。
- **现有路线二（工具型具身智能体）**：用显式推理、工具调用与记忆实现任务编排，但多数系统聚焦于"单环境内"的任务执行与经验复用，**对过程性知识（procedural knowledge）的跨环境迁移与持续适应支持有限**。
- **论文的核心立场**：把 sim-to-real 迁移重新表述为**可执行任务技能的持续适应问题**——迁移的不是参数，而是"如何做事"的过程性技能；技能可在目标环境中被选择性修订，而底层操作能力仍由冻结的预训练 VLA 提供。

## 二、方法论

### 2.1 核心思想

- 将任务知识表示为**可编辑技能 S**：连接任务意图、观测、工具操作与结果验证条件；技能围绕"任务相关状态与操作可供性"组织，而非绑定具体物体身份（如"抓取技能"面向一类操作需求而非某个杯子），从而实现意图与物理实现的解耦。
- 技能演化采用"**提出候选—执行验证—保留或拒绝**"的闭环，避免经验无控追加污染技能记忆。
- 冻结的 VLA 策略被封装为**可复用动作工具**，agent 决定何时调用、如何配置推理时引导。

### 2.2 关键公式与流程

- **技能演化与跨环境初始化**：
  $S_{k+1} = U(S_k, \tau_k)$，$S^r_0 = \Phi(S^s_K)$
  其中 $U$ 为基于 rollout 证据的更新过程（候选失败则保留原技能），$\Phi$ 为跨环境接口映射（对齐任务语义、观测格式与工具接口），$s/r$ 分别表示仿真/现实，$K$ 为仿真侧演化步数。
- **Agent 执行循环**（每轮至多一次物理操作）：
  $c_t = \Pi(\ell, o_t, f_{t-1}, S_k)$，$(o_{t+1}, f_t) = E(o_t, c_t)$
  $\Pi$ 为高层规划器，$E$ 为工具执行与观测刷新；观测 $o_t$ 含结构化场景描述、相机图像、机器人状态、新鲜度与不确定性；循环终止条件为达成目标 $G$、主动终止或预算耗尽。
- **推理时奖励引导**（策略参数冻结，梯度只对候选动作求）：
  $A^{(j)}_{t,\text{guided}} = A^{(j)}_t + \eta_{t,j}\nabla_{A^{(j)}_t} r_t(A^{(j)}_t; o_t, u_t)$
  其中 $j$ 为去噪步，$u_t$ 为局部子任务，$\eta_{t,j}\ge 0$ 为引导强度（$\eta=0$ 即无引导），$r_t$ 由 agent 依据子任务目标、执行约束与观测反馈现场构造。

### 2.3 三层机制分工

- **技能演化（跨 episode）**：修订操作顺序、目标绑定、工具选择、验证条件与恢复行为，可能新增、替换或删除局部内容。
- **验证门（validation gate）**：候选技能须在与当前技能可比的条件下执行对比，只有"有效且更优"才被持久化为新版本；被拒候选仅作审计记录保留，原技能作为回退。
- **推理时引导（单次调用内）**：解决"过程正确但冻结策略在当前子任务下动作不达标"的问题，属局部、临时的行为矫正，不写入参数。
- **工具库**：几何类（笛卡尔移动/位姿对齐、腕部旋转/倾斜、夹爪开合）+ 策略类（Policy Grasp / Policy Contact），工具完成 ≠ 任务成功，任务成功由 benchmark 谓词或人工标签判定。

## 三、实验设计

### 3.1 仿真实验

- **Benchmark**：LIBERO-PRO，覆盖 SPATIAL、OBJECT、GOAL、LIBERO-10 四个任务族；每族两种扰动：**T（指令重定向，改变目标物体/目标条件）** 与 **S（位置交换，保持指令不变）**。

- **种子划分**：11–20 训练（供技能演化）、21–25 验证（供验证门）、1–10 测试（与训练/验证严格不交）。
- **技能演化协议**：每个任务单元做 2 轮演化、每轮 5 个训练种子。
- **对比方法**：OpenVLA、π0、π0.5、MolmoAct、NORA、X-VLA、AtomVLA、πRLinf、CaP-X、RATs、ASPIRE、Harness VLA（最强基线，72.1%）。

  - 与基线对比时，各方法的底层策略、检查点、套件覆盖不完全一致（表中多处为"—"），"超过 Harness VLA 2.3 个百分点"的边际优势需谨慎解读。

## 六、主要结论与发现

- **仿真端**：RoboBridge（Codex 配置）在 LIBERO-PRO 上取得 **74.4% 总体成功率**，超过最强基线 Harness VLA（72.1%）2.3 个百分点，在 GOAL-T 上领先 5 个百分点；而直接使用 πRLinf 仅 50.0%，说明增益并非单纯来自底层策略。
- **消融结论**：
  - 去掉技能引导，SPATIAL-T / OBJECT-T 从 83%/94% 跌至 21%/16%（降 62/78 个百分点），技能是最关键组件；
  - 仅追加式更新（不允许修订与删除）跌至 44%/57%，说明**修订与删除比累积更重要**；
  - 去掉验证门跌至 69%/63%，说明候选技能须先经验证再持久化；
  - 去掉推理时引导跌至 75%/82%，说明过程级演化与动作级引导**互补**。
- **真机迁移**：直接迁移仿真技能把三任务成功率从 4/15、2/15、3/15 提升到 9/15、7/15、7/15；再经 10 轮真机演化后达 15/15、14/15、15/15。
- **迁移效率**：仿真初始化使达到 15/15 所需迭代从 16 次降至 12 次（减少 25%），累计 token 从 52.39M 降至 13.08M（减少约 75%）。
- **总体判断**：在任务语义与交互接口对齐的前提下，过程性技能可作为可复用初始知识跨环境迁移，并在部署后继续被物理反馈精化，从而把"一次性策略部署"推进为"持续过程性学习"。

## 七、优点与亮点

- **问题重构有洞察力**：把 sim-to-real 从"对齐分布 + 重训参数"改写为"迁移可编辑的过程性技能"，绕开了对目标域演示与策略微调的依赖，工程上更轻量。
- **技能表示设计合理**：技能以任务相关状态与可供性组织而非绑定具体物体/坐标，天然具备一定泛化性；同时保留意图、观测、操作、验证四要素，使失败可归因（绑定错、定位错、动作错、顺序错还是验证错）。
- **验证门 + 版本化 + 回退机制**：有效抑制了经验追加导致的技能污染，被拒候选仅作审计记录，是一个较严谨的"技能记忆写入控制"方案。
- **双层适应解耦清晰**：跨 episode 的过程修订与单次调用内的动作引导分工明确，且后者**梯度只作用于候选动作、参数完全冻结**，避免了推理时引导污染策略。
- **工程可复现性较好**：附录给出观测 schema、工具表、prompt 语义、技能 schema、episode 文件组织，接口抽象（环境适配器、统一工具接口）设计清晰，便于跨环境复用。
- **实验设计中的公平性意识**：种子三段不交、测试期禁止继续演化、引入 policy-only 基线、显式区分"工具完成"与"任务成功"。

## 八、不足与局限

- **对 LLM 编码 agent 的强依赖**：全部实验固定使用 Codex + GPT-5.5，未验证在其他基础模型/agent harness 下的表现（作者亦将此列为未来工作），方法的普适性存疑。
- **算力信息缺失**：未报告 GPU 型号、数量与时长；虽然不训练策略，但 agent 侧 token 成本与延迟对实际部署很关键，论文仅给出单一任务的 token 统计。
- **真机实验规模偏小**：3 个任务、每任务 15 次试验、每 episode 后演化一次，任务时长与复杂度有限；成功判定依赖操作员主观标签，缺乏自动谓词与多人标注一致性检验。
- **迁移效率结论单薄**：25% 迭代缩减与 75% token 缩减仅基于一个任务（蛋糕放置与加盖），且属于"单独实验设置"，与主实验不可直接合并解读。
- **消融覆盖不全**：仅在 SPATIAL-T 与 OBJECT-T 上消融，未覆盖 S 扰动、GOAL、LIBERO-10；也未单独消融"技能表示形式"（如去掉验证条件、改变技能粒度）等设计选择。
- **基线对比存在混杂因素**：不同基线使用不同底层策略与检查点，部分套件结果缺失（表中"—"），2.3 个百分点的总体优势处于噪声边缘，缺少多次运行的标准差或显著性检验。
- **跨环境对齐假设较强**：方法成立依赖"任务语义 + 观测格式 + 工具接口"三重对齐（映射 $\Phi$），真机侧需专门封装感知/标定/控制流水线；当目标环境在传感、工具可用性或运动约束上与仿真差异更大时，迁移是否仍有效未被检验。
- **技能演化的成本与稳定性**：每个任务需多轮演化与验证 rollout，演化本身消耗交互预算；验证门依赖"可比条件"下的对比，若环境随机性大，候选与当前技能的差异可能难以可靠区分。
- **安全性/失败恢复讨论有限**：真机 prompt 虽要求执行或感知不可靠时停止，但缺少对技能演化引入错误行为、或推理时引导产生不安全动作的系统性分析。
